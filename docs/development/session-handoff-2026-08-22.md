## 🔴 やらないと決めたこと(理由つき ── 再発明しないこと)

- ❌ **許可を「偽造できない場所」に置く** → **そんな場所は存在しない**。
  localStorage / IndexedDB / OPFS はもちろん **sqlite も書ける**
  (`storage/store-proxy.ts` の `case 'req'` が**送り主を検めない**)。別 origin も取れない
  (`sm06224.github.io` は user site なので、repo を分けても 1 origin である)。
  🔑 **置き場で安全は買えない。**買えるのは「**中身が変わったら外れる**」と
  「**取り消せる**」の 2 つだけで、両方入れた。
- ❌ **タイルを許可の入口にする** → 一覧から 1 クリックで押せる場所なので、
  「押しただけで全ノートを渡すか聞かれる」形になる(`ui/render/detail.ts:1364-1370` が
  「対象の素性が見えている画面からだけ入れる」と決めた理由)。
  🔑 **与えるのは添付の画面で 1 回。使うのはタイル**、に分けた。
- ❌ **ダイアログを常に待ち行列へ入れる** → 開くのが 1 マイクロタスク遅れる =
  **押した瞬間に開かない**。素のまま起動は `window.open` を user の操作の続きで
  呼ぶ必要がある(transient activation)ので、**空いているときは同期**に倒した。
- ❌ **「N 件以上」で pin する** → **減る方向に空振りする**。実数 7 件に対する
  `toBeGreaterThanOrEqual(5)` は **2 件落としても緑**だった。→ **等値表**に替えた。
- ❌ **`--disable-*` 系の期待を確かめる前に assert へ固める**(既出。#158 の型)。
