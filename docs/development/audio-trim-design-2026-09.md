# 録った音の前後を削る(#683 段②a)── 設計

> user 裁定 2026-09-14:**録った音の前後を削ったら、元と同じ形(opus)で保存する。**
> 切り出した結果は**新しい添付として 1 つ増え**、元のものは残る。
> ⚠ WAV だと 1 分 10MB になり「削ったのに元より重くなる」ので、それは避ける。

⚠ この doc は**裁定を仰ぐため**のものです(doc-first)。量が L なので、実装の前に出します。

---

## 1. 画面で何が起きるか

1. **音/動画** の面で、録ったものを**聞く**(いまも聞ける)
2. 聞きながら「**ここから**」「**ここまで**」を押す ── 押した所に**時刻が出る**
3. 「**この範囲で切り出す**」を押すと、**新しい添付が 1 つ増える**
4. **元のものはそのまま残る**(⚠ 上書きしない)

⚠ **波形は出しません**(裁定どおり)── 「前後を削る」だけなら聞きながら印を付けるほうが
手数が少なく、作るものも小さいためです。波形が要るのは「真ん中を抜く」「細かく合わせる」で、
それは別の段です。

---

## 2. 🔴 いちばん大きい発見 ── **符号化し直す必要が無い**

裁定のときに「**音を符号化する部品を 1 つ足す**(数百 KB)」と書きましたが、⚠ **2 段階で違いました。**

### ① 部品は要らない(実測 2026-09-14)

ブラウザが **WebCodecs** で opus を持っています:

```
AudioEncoder: function / AudioDecoder: function
isConfigSupported({codec:'opus', 48kHz, 1ch, 64kbps}) → true
1 秒ぶん符号化 → packet 51 本 / 8371 バイト(≒ 67 kbps)
```

⚠ **測り方で 1 度外しかけました** ── 1 回目は `about:blank` で測って `AudioEncoder` が
`undefined` でした。真因は **WebCodecs が `[SecureContext]`** であることで、`https:` の文脈で
測り直したら**両方のビルドに在りました**。
⚠ `AudioData` と `EncodedAudioChunk` は `about:blank` でも見えるので、
**「一部だけ在る」が嘘の結論を後押しします**(CLAUDE.md §4 観測点)。

### ② 🔑 そもそも**復号も符号化もしない**で済む

録ったものは **webm の中の opus** です(`MediaRecorder` の既定)。
🔑 **opus の packet はそれ自体で完結している**ので、

> **要る範囲の packet を、そのまま新しい入れ物へ移すだけ**

で切り出せます。⚠ **音は 1 ビットも作り直しません**(劣化ゼロ・速い・記憶をほとんど使わない)。

| | 復号 → 符号化 | 🔑 **packet を移すだけ** |
|---|---|---|
| 音の劣化 | 有る(2 回目の符号化) | **無い**(bit そのまま) |
| 速さ | 実時間の数分の 1 | **ほぼ file を読む速さ** |
| 記憶 | 下の §3 のとおり重い | **切り出した範囲の圧縮済みバイトだけ** |
| ブラウザ | WebCodecs が要る | **要らない**(素の JS で足りる) |

⚠ **WebCodecs が要らない**のは大きい ── Safari / Firefox で「押せるのに使えない」を作らずに済みます。

## 3. ⚠ 丸ごと PCM にする道は採れない(なぜ書くか)

いちばん素直な道は `decodeAudioData` で丸ごと PCM にしてから切ることですが、**採れません**:

| 録ったものの長さ | 丸ごと PCM(48kHz / f32 / 1ch) |
|---|---|
| 5 分 | 約 57 MB |
| 30 分 | 約 345 MB |
| 12 時間(いまの上限 `MAX_CAPTURE_MS`) | **論外** |

⚠ 「ゼロコピー・生成物のライフサイクル終端での即破棄」(不可侵指示 2026-07-27)と正面から反します。
🔑 §2② の道なら、記憶に載るのは**切り出した範囲の圧縮済みバイトだけ**です
(1 分の切り出し ≒ 0.5 MB)。

## 4. 段取り(3 段)

```
元の添付(webm/opus)            切り出した添付(ogg/opus)
        │                                 ▲
        │ ① ほどく(WebM/EBML)            │ ③ 詰める(Ogg)
        ▼                                 │
   packet の列 + OpusHead  ──② 選ぶ──▶  要る packet だけ
                            （範囲）
```

### ① ほどく(WebM / Matroska)

読むのは**必要な所だけ**です:

| 何を | どこから |
|---|---|
| `TimestampScale`(既定 1ms) | Segment → Info |
| `TrackNumber` / `CodecID`(`A_OPUS` か) | Segment → Tracks → TrackEntry |
| 🔑 **`CodecPrivate` = 元の `OpusHead` そのもの** | 同上 |
| packet と時刻 | Segment → Cluster(`Timestamp`)→ `SimpleBlock` |

⚠ **`A_OPUS` でなければ、この道は使いません**(→ §6 の梯子)。
⚠ **lacing(1 つの block に複数 frame)は受けない** ── `MediaRecorder` は使いませんが、
**受けないことを声に出して**断ります(黙って壊れた file を作らない)。

### ② 選ぶ

- 範囲の**始まり以前で、いちばん近い packet 境界**から取る
- 🔑 **80ms ぶん余分に前から取る** ── opus の復号器は立ち上がりに前の音を要るので、
  いきなり切ると**頭が濁ります**(仕様が 80ms 以上を推奨)
- 余分に取ったぶんと、境界と範囲のずれは **`pre-skip` で捨てさせる**(下の §5)

### ③ 詰める(Ogg / Opus)

Ogg のページを組みます(素の JS。外の部品は使いません):

| ページ | 中身 |
|---|---|
| 1 枚目 | **`OpusHead`** ── 🔑 **元の `CodecPrivate` を写して `pre-skip` だけ書き換える** |
| 2 枚目 | `OpusTags`(作った物の名前だけ) |
| 以降 | packet を順に。最後のページの `granulepos` で**終わりを詰める** |

⚠ ページごとに **CRC32**(Ogg 独自の多項式 `0x04c11db7`、初期値 0)が要ります。

---

## 5. 端の合わせ方(⚠ ここが唯一の細かい所)

opus の 1 packet は普通 **20ms**(録り方によって 2.5〜120ms)です。
packet の境目でしか切れないと、**最大 20ms ずれます** ── それを 2 つの仕掛けで消します:

| 端 | 仕掛け | 効き方 |
|---|---|---|
| **始まり** | `OpusHead` の **`pre-skip`** を増やす | 復号器が頭の N サンプルを**捨てて**から出す |
| **終わり** | 最後のページの **`granulepos`** を望む位置にする | 復号器が尻の余りを**出さない** |

- `pre-skip` は **u16**(最大 65535 サンプル = 1.365 秒)── 余分に取る 80ms(3840)と
  境界のずれ(最大 5760)を足しても**収まります**
- 🔑 だから **サンプル 1 つの精度で切れます**(符号化し直さずに)

## 6. 受けられない形のときは(梯子)

| その file が | どうするか |
|---|---|
| **webm の中の opus**(いまの録音は全部これ) | 🟢 §4 の道(packet を移すだけ) |
| webm だが opus でない / lacing 有り | ⏸ **WebCodecs が在れば**復号 → 符号化(§2①)。⚠ 無ければ**押し所を出さない** |
| mp4 / その他 | ⏸ 同上 |

🔴 **押せるのに何も起きない口を作らない** ── 切り出せない形のときは
**ボタンを出さず、理由を 1 行その場に書きます**(「この形はまだ切り出せません」)。
⚠ 「押したら断る」ではなく「**出さない + 理由**」にするのは、この repo の既定です。

---

## 7. どこに置くか

| もの | 置き場 | 理由 |
|---|---|---|
| ほどく / 選ぶ / 詰める | `src/features/audio/`(純関数) | browser API を持たない ── **node の unit で全部殺せる** |
| 走らせる | 🔴 **ワーカー**(`WorkerLease`) | 「重い処理はワーカーへ・使い終わったら捨てる」(不可侵指示 2026-08-03)。⚠ 形は `asset-client.ts` と同じ |
| 元の bytes を読む | `AssetLender.getBlob(key)` | 既に在る口 |
| 新しい添付にする | 🔑 **`attachOne()`** | 既に在る口 ── **新しい取込口を作らない** |
| 押し所 | `captures.ts` の行 | `capture-play` と同じ並び |

⚠ ワーカーへ渡すのは **`ArrayBuffer` を transfer**(ゼロコピー)。
⚠ 出来た bytes も transfer で返し、**ObjectURL は寿命の終端で revoke**。

## 8. 門(test)

| 何を | どう見るか |
|---|---|
| ほどけたか | 自作の最小 webm を組んで、packet の数と時刻が合う |
| 🔴 **空振り防止** | ⚠ **opus でない webm**・**lacing 有り**を入れたら**断る**ことを見る |
| 端の精度 | `pre-skip` と最後の `granulepos` が**計算どおりの値**になる |
| 🔴 **入れ物が本物か** | 組んだ ogg を**ブラウザの `<audio>` に食わせて `duration` が合う**(実ブラウザ smoke) |
| 記憶 | ⚠ 元が長くても、**読んだバイト数が範囲に比例する**ことを数える |
| 動線 | 「ここから → ここまで → 切り出す → 一覧に 1 件増える → 元も残っている」 |

⚠ **`duration` だけでは足りません** ── 中身が無音でも合います。
🔑 **音が入っていること**まで見る(復号して振幅の合計が 0 でない)。

## 10. 裁定をお願いしたいこと

⚠ **実装の作り方は裁定の外**(委任の内側)なので、聞きたいのは**画面の見え方**だけです。

| | 画面で何が起きるか |
|---|---|
| **A(推薦)** | 切り出したものは**新しい添付**として増え、名前は元の名前 + 範囲(例:`録音-0912-1430 (0:12〜1:05).webm`) |
| B | 名前は聞かれる(小窓が出る) |
| C | 元の添付を**置き換える** ── ⚠ 裁定と反する(元は残す)ので出しません |

**推薦は A** です ── 手数が 1 つ少なく、名前を見れば**どこを切ったか**が分かるためです
(直したければ、いつもの改名でできます)。

🔑 **これが分かったら覆ります**:切り出しを**何度も繰り返す**使い方が主なら、
名前が長くなるので B(聞く)のほうがよくなります。
