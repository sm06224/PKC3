# 用語の総直しの記録(2026-10-06)

2026-10-06 の用語の総直しの記録。画面・マニュアル・お知らせからは旧語を消した。
旧 → 新の対応表は、ここだけに置く(user に見える所へは旧語の一覧を出さない)。

正本は `src/features/ui-terms.ts`(`STANDARD_TERMS` = 使う語、`BANNED_TERMS` = 使わない語と言い換え)と
`docs/manual.md`「言葉の意味」。画面に書く名詞が用語集に無いときは、先に用語集へ足す。

## 使わない語の表(`BANNED_TERMS` から機械で作る)

🔑 **この表は手で書かない。** `src/features/ui-terms.ts` の `BANNED_TERMS` から作り、

## 言い換えの補足(文脈で選ぶ語)

| 旧 | 補足 |
|---|---|
| 面 | 左・中央・右の領域は「ペイン」。中央に出る 1 枚(本文 / 集計 / システム …)は「画面」 |
| 印 | チェック / 目印(位置の意味だけ)/ アイコン / 既読 を文脈で選ぶ |
| 器 | 枠 / 保存データ を文脈で選ぶ |
| 箱 | 埋め込み枠 / 確認ダイアログ / 入力欄 / チェックボックス を文脈で選ぶ |
| 札 | 予定の札 → カード / タグの札 → バッジ |
| 小窓 | 表の ▾ で出るものは「メニュー」 |
| 入れ物 | データの置き場の意味は「保存領域」。スマートフォルダ・スタック・データベースなどの意味は文脈で言い換えた |
| 留め | 「ピン留め」「横に留めた枠」も「スタック」に統一。場所を残す意味は「ブックマーク」 |
| 落と | ドロップする / ダウンロードする を文脈で選ぶ |
| 引く(SQL) | 調べる = データが対象 / 実行する = SQL が対象 |
| 鍵 | アイコン名の「鍵」は残す |
| 版 | アプリの「版」は「バージョン」。履歴の「版」はそのまま |
