## 節の型

```
### 〈動詞で終わる見出し・日付を入れない〉

> 一行で:  この節で何ができるか(1 文・40 字以内)

**手順**
1. …

**覚えること**            ← 0〜3 個。4 個目が出たら節を割る

**つまずきやすい点**      ← 無ければ枠ごと省く

関連: 〈節〉 / 早見表: 〈表〉 / 仕組み: D-n
```

🔑 **型が効く理由は 3 つ**(user レポート §6-1):

1. **足す場所が一意に決まる** ──「一行で」が書けるなら既存節の改稿。書けないなら新設。
   判定が機械的になるので、**「そのほか」へ足す動機が消える**
2. **節の適正サイズが枠の数で分かる** ──「覚えること」が 4 個を超えたら太りすぎ
3. **読み飛ばせる** ── 全節が同じ順序なら、2 節目からは「手順だけ見る」ができる

## 規約 11 条(user レポート §6-2。**原文のまま**)

1. **見出しに日付を入れない。** 悪い「数式(2026-09-06 に足しました)」/
   良い「数式を書く」+ 変更履歴に 1 行。⚠ 日付は 1 か月で意味を失い、見出しだけが長く残る
2. **節番号を振らない。** ⚠ 前に挿入したくなったとき `4-0b` / `4-8b` が生まれる。順序は目次が示す
3. **見出しは動詞で終える。** 悪い「録音・画面収録」「そのほか」/ 良い「録音・画面収録を入れる」
4. **「そのほか」という見出しを作らない。** 行き先が無いものは、名前を付けて節にするか既存節へ吸収する
5. **見出しは 3 段まで**(章 H2 / 節 H3 / 小節 H4)。H5 は使わない。
   H4 を作りたくなったら、まず「覚えること」に吸収できないか考える
6. **同じ名前の見出しを 2 つ作らない。** ⚠ 検索で引いたとき区別できない
7. **新機能は「追記」ではなく「該当節の改稿」。** 型の「一行で」が書けるなら既存節に収める。
   書けないときだけ節を新設し、**章の流れ順に挿入する。末尾に足さない**
8. **ガイドに一覧を書かない。早見表に説明を書かない。**
9. **1 節 = 1 画面(600〜800 字)。**「覚えること」が 4 個を超えたら割る
10. **記号は 🔴 ⚠ 💡 の 3 種のみ。** 凡例を各巻の先頭に置く
    (🔴 データを失う恐れ / ⚠ 片道(戻せない)/ 💡 知っておくと速い)
11. **独自の語**(解放・居場所・参照元・雛形・紙面・面・板・札・小窓)は
    **用語集に登録してから使う。本文で言い換えない**

## ⚠ 規約と、いまの本文が食い違っている 1 点

**条 10 は `🔴 ⚠ 💡` の 3 種**だが、`docs/manual.md` がいま使っているのは
**`🔴 ⚠ 🔑` の 3 種**である(`💡` は 0 件)。`🔑` は「知っておくと速い」に当たるので、
**役割は同じで字が違う**。⚠ どちらへ揃えるかは**見え方が変わる**ので、
user の裁定を待つ(CLAUDE.md「見え方を変える判断は user のもの」)。
