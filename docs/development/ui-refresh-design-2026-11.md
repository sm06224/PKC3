## 1. なぜ改めたか(実測の要約)

PKC3 v3.8.0 と PKC2 を同じ本文のノートで並べて実ブラウザで測った(#1982 §1)。

- 枠を持つ要素は PKC2 111 / PKC3 40 ── **原因は枠の多さではなかった**
- 原因は 5 つ:
  - (a) `gap: 1px` に線の色を透かせた**格子**で画面を敷き詰めている
  - (b) ボタンが「反転の主 1 個 + 同じ見た目の残り全部」の 2 段しかない
  - (c) 地が灰色と白だけで、hover(`#fafbfc` on `#fff`)がほぼ見えない
  - (d) 字の大きさ・影に段が無い(素の px が 242 か所、影トークン 1 本、`--shadow-sm` は未定義)
  - (e) 「隠さない」を「副次の操作も全部文字ボタンで出す」と読んでいた(右ペインに 15 個)
- (a)〜(e) は方針の**意図**ではなく**表現**から来ている → 表現の規則だけを書き換える

## 2. 規則(改定後)

| # | 規則 | 旧い規則 |
|---|---|---|
| ① | **色は意味にだけ**。地は無彩色に近い色で背景の段差で分ける。意味の色 = アクセント 1 色(各テーマの `--accent`。主の操作・フォーカス)+ 状態 4 色(`--ok` / `--warn` / `--danger` / `--info`)。**現在地・選択は形**(左端の線・太字) | 彩度は 3 か所だけ(最上部のバー / 選択 / 種別チップ) |
| ② | **常用は出す、副次は 1 段奥**(「その他 ▾」・hover)。基準は使う頻度と取り消せるか。配置は固定 | 隠さない |
| ③ | 同じものが常に同じ場所 | (不変) |
| ④ | 1 画面で完結。過密は見出しの段と余白で解く | (不変) |
| ⑤ | **区切りは背景の段差と余白**。枠は入力欄・浮いた物・表のセルだけ | 区切りは枠 / 境界線を共有して 1px の格子 |
| ⑥ | 操作は対象の隣。**ボタンは 4 型**(主 / 標準 / ゴースト / 危険)、主は 1 画面に 1 つ | 主は `--fg` 反転で色を使わない |
| ⑦ | **字の大きさ・角丸・影・動きはトークンの段から選ぶ** | (規定なし) |

### 残す核(変えない)

同じ場所 / 補助は中央の本文を奪わない / `app.css` はテーマで分岐しない(変えるのはトークンだけ)/ 全テーマのコントラスト検算 / 機能セレクタは `data-pkc-*` / 標準の日本語 IT 用語 / ボタンの高さを揃える・指で押せる下限 / 1 画面に主は 1 つ / フラグ予算 / 図はラスタ / `prefers-reduced-motion`。

## 3. トークンの段(段 0 で導入)

| 種類 | トークン | 値 |
|---|---|---|
| 字の大きさ | `--fs-2xs` … `--fs-2xl` | 10 / 11 / 12 / 13 / 14 / 16 / 18px |
| 角丸 | `--radius-sm` / `--radius` / `--radius-lg` / `--radius-pill` | 2 / 3 / 6 / 999px |
| 影(テーマごと) | `--shadow-sm` / `--shadow` / `--shadow-lg` | 0 1px 2px / 0 2px 6px / 0 8px 24px(濃さはテーマの `--shadow` から) |
| 動き | `--dur-fast` / `--dur` / `--ease` | 120ms / 180ms / cubic-bezier(.2,.8,.2,1)。reduced-motion では 0 |
| 状態 | `--info` | 各テーマの `--code-key`(新しい色相を足さない) |

- 素の px の字の大きさは**増やさない**(`tests/adapter/design-tokens-css.test.ts` の上限)。残りの例外(12.5px の打つ欄など)は段 2 で畳む
- `var(--x)` で使うトークンは**必ずどこかで定義する**(同 test。`--shadow-sm` の定義漏れの再発を防ぐ)

## 5. 判断の記録(user 裁定 2026-11-19)
