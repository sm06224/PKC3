## やらないと決めたこと(理由つき)

- **「ノートに付ける目印」を本文側へ出す** ── 🔴 **やらない。** 書き出した HTML と
  焼いたマニュアルには `@font-face` が 1 行も入らないので、私用領域の符号位置は
  **豆腐(□)**で出る。しかも user のお言葉は「アプリで使えるアイコン」であって、
  「ノートの目印」は**こちらが書いた言葉**だった
- **夜に全量 smoke を戻す** ── 🚫 user 指示。`tests/workflow-steps.test.ts` が
  `on:` の全数走査(`push` / `pull_request` / **`schedule`**)で機械的に止める
