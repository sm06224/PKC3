## 3. 古今東西から採るもの(R6)

### 3.1 🔴 HIG 4 つが揃って言っている 1 行

> **畳める面・隠せる面・カスタマイズできる面は、その操作の唯一の置き場になってはならない。**

| | 明文 |

⚠ **数値の閾値は採らない**(Material「モバイル 3 / タブレット 4」、Fluent「320epx で 4 個」)──

### 3.2 🔴 この研究でいちばん効いた発見 ── 私の前提が覆った

> **体系を薄めるのは「入口の数」ではなく「登記簿の数」である。**

VS Code は 1 つの操作を **パレット / メニュー / ツールバー / キー割当**の 4 面に同時に出すが、
体系は薄まらない ── **4 面とも同じ 1 つの登記簿への問い合わせ**だからである。
Emacs も AutoCAD も同じ形。

🔑 **PKC3 に足りないのは入口の抑制ではなく、登記簿の統合。**
⚠ だから #500 案 C(2 本目の道を足す)は**方向として間違ってはいなかった** ──
間違っていたのは、**登記簿を作らずに 1 件ずつ手で複製したこと**である。

## 4. 🔴 推薦(1 つ)

### 型:**「操作表は 1 つ。面はその射影であって、面は操作を所有しない」**

操作 1 件を 1 行で宣言する:

| 列 | 中身 |
|---|---|
| `id` | `data-pkc-action` と**同綴り**(= 実行の受け手と等値で pin できる) |
| `label` | **字の正本**(面ごとに別の字を書かない) |
| `scope` | **何に効くか** ── `app` / `collection` / `view` / `entry` / `selection` / `block` |
| `when` | いつ出るか(**閉じた union**。`folder` / `linked` のような既存の形) |
| `keys?` | 鍵 |

**落ちてくる規則(この型を選べば、以下は発明ではなく導出である)**:

1. 🔴 **置き場は `scope` が決める。頻度は決めない。**
   頻度が決めてよいのは**面の中の順位だけ**。
   ⚠ いま `commands.ts` は「押す頻度」で左帯と設定を分けており(#239)、**これは軸違い**である
   ── 同じ `collection` の物が 2 つの面に分かれている
2. 🔴 **パレットは既定 ON、他の面は opt-in**(VS Code)。
   「すべての操作は名前で呼べる」が**規律ではなくフィールドの初期値**になる
3. 🔴 **畳めるペインが唯一の入口になってはならない** ── ⚠ 規則 2 を入れると**自動的に満たされる**。
   🔑 **「畳んだら操作はどこへ行くのか」の答えは「どこへも行かない。最初からパレットに在った」**
4. **文脈は行を足すだけ。既存の順位を動かさず、現在地も移さない**(Office)
5. 🔴 **`scope` を持つ面は空にならない。次に大きい `scope` へ落ちる**(Figma)──
   情報ペインは選択が無いとき `collection` を出す(件数 / タグ / 取り込む / バックアップ / 最近)。
   ⚠ いまは「左の一覧から選ぶと、ここに情報が出ます。」という**死んだ 1 文**が常設の幅を占めている
6. **ボタンは自分の名前と鍵を名乗る**(Emacs のエコー)── 機構は `shortcut-hint.ts` に既に在る。被覆 **7/30**

### 4.1 ⚠ 「パレット中心」は user 指示と衝突しないか

user 指示 2026-08-03「**マウスだけで完結し、キーボードは近道**」──

**衝突しない。ただし明記が要る**:
🔑 **パレットは「保証」であって「主動線」ではない。**
主動線は**空間的なまま**(ペイン・帯・右クリック)で、パレットは
**①どの操作にも必ず 1 つは入口がある ②畳んでも消えない**を保証する**床**である。
⚠ PKC3 のパレットは既に**マウスで開ける**(`shell.ts:514` に「操作を探す」ボタンが在る)ので、
キーボード必須にはならない。

### 4.2 ⚠ この推薦が**やらない**こと

- **ボタンを減らさない。** user 指示 2026-08-07「記法を減らすことは、user の動線を減らすこと」の同型
  ── 減らすのは**登記簿の数**であって、押せる場所ではない
- **配置を今すぐ変えない。** 登記簿を作り、いまの配置を**そこから配る**のが先
  (見え方が変わらないので、裁定を待たずに進められる部分がある ── §5 の段①)

## 6. R7 ── 決まった規則を test で pin する形

⚠ **規則を doc に書くだけだと、次の PR で崩れる**(この repo が何度も踏んでいる形 ── §1.4 ②がまさにそれ)。

### 7.1 🔴 R1 ── 183 の受け手を全数で仕分けた(2026-08-29)

**問い**:「その操作は、**画面のどこかを指さないと**始められないか」。
指さずに始められるなら、パレット(名前で呼ぶ口)が床になれる。

| 種別 | 数 | 何が要るか | パレットから呼べるか |
|---|---|---|---|
| **P1 真の点** | **40**(22%) | 同時に見えている兄弟のうち**押した 1 つ**(表のセル / 予定の日 / 見出しの行 / タグ / 関係 / 添付 / 履歴 / ごみ箱の行 / 図 / タイマー / 目覚まし / タイル / しおり) | 🔴 **そのままでは呼べない** |
| **P2 現在地で代替** | 28 | 点を取ってはいるが、**state に「いまのそれ」が在る**(`selectedLid` / `dual.focus`)── 行を押す / 消す / 書き出す / 2 ペインの各操作 | 🟢 呼べる(いまの選択に効く) |
| **E 列挙** | 19 | 閉じた選択肢を 1 つ(面 / 主題 / 書式 / 種類 / 設定値) | 🟢 呼べる(**値ごとに 1 行**出す) |
| **V 値** | 8 | 欄の値そのもの(絞り込みの条件 / 添付の名前 / タイルの分類・アイコン / 3 つの入切) | 🟢 呼べる(その欄へ連れて行く) |
| **N 名詞** | **88** | 押した所から**何も要らない**(`target` は器の取得か点滅だけ) | 🟢 呼べる |

🔑 **名前だけで呼べる = 143 / 183(78%)。** ⚠ **P2 を数に入れている** ──
入れてよい理由は「**いまの選択に効く**」からで、これは既存の動線と同じ意味である
(行を選んでから右で押すのと、行を選んでから名前で呼ぶのは同じ物を指す)。
⚠ P2 を**除いた**保守的な数は **115 / 183(63%)**。どちらを書くかで印象が変わるので、
**両方書く**。点が要るのは **68**、うち**現在地で代替できるものを除くと 40**。

⚠ **40 は「パレットに出さない」ではない** ── 出し方が違うだけである:
Apple HIG の言い方(§3.1)では、**context menu の項目は必ず main interface にも用意する**。
🔑 P1 の 40 は **「いま指している物」を先に決める行**(例:「この表のセルを編集」は
**セルを選んでから**呼ぶ)として出せる ── つまり床は**パレット + 右クリックの対**であり、
**どちらか一方ではない**。

#### ⚠ 数え方(と、ここで踏んだ 2 つの罠)

判定は **`target`(押された要素)からデータを読んでいるか**で採り、コメントは先に剥いだ。

1. 🔴 **1 稿目の計器は、助っ人経由の読みを 1 件も拾えなかった。**
   `menuCarriedLine(target)` / `dualSide(target)` / `handleCopyMdBlock(target)` は
   `getAttribute` を**関数の向こう側**で呼ぶので、`target.` を探す正規表現に当たらない ──
   **点を取る操作が名詞に見える**(実測で **82 → 107** に増えた。25 件が隠れていた)。
   🔑 **`target` を渡している呼び出しそのもの**を拾う形にした。
2. 🔴 **`target` を読んでいても、点とは限らない。** `rename-attachment` /
   `toggle-app-tile` / `set-app-group` / `set-app-icon` の 4 件は、
   **対象は `selectedLid`(state)で、`target` からは入力欄の値しか読んでいない** ──
   実装を読むまで P1 に数えていた。⚠ **属性名の見た目だけで仕分けると、
   ここが 44 になる**(§4 の「計器の名前が範囲より広い」と同型)。

⚠ **仕分けは手である。** だから割り当て script は
**①同じ名前を 2 度割り当てたら投げる ②実在しない受け手を割り当てたら投げる**の
両方向で落としている ── 片方だけだと、綴り違いが**静かに N へ落ちる**。
