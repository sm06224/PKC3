# 保存した検索(#1038 C1)── 設計

> 出どころ:#1038 の残り 7 場面の調査(PKC2 の「保存した検索」の動線を借りた。実装は PKC3 の作りで新規)。
> flag ではない(正規の機能)。

## 1. 画面で何が起きるか

毎週「請求書」+ 種類「ノート・表」で絞っている人が、毎回語を打って札を押し直さずに済む。

1. 左の列で語を打つ / 種類の札を押す → 札の下に **この検索を保存** が出る。押すと保存される(**名前は自動**: `請求書(ノート・表)`)。
2. 保存すると **保存した検索(N)** が出る(畳んである。開くと一覧)。各行は **名前(押すと再適用)/ 名前を直す / 削除**。
3. 再適用すると、左の欄の語と種類の札が**保存したときの組に置き換わる**(足さない)。いまの絞りと同じ行は押された(濃い)状態で出る。
4. 探す面でも、欄の下に同じ帯が出る。そこでは**語だけ**を保存・再適用する(探す面に種類の札は無い)。

## 2. 決めたこと

| 論点 | 決め | 理由 |
|---|---|---|
| 何を憶えるか | `{ id, name, query, kinds[] }` だけ。**結果の lid は持たない** | 組から探し直せばいまの本文で引き直せる。結果を写すと古い物が残る(`search-log.ts` と同じ) |
| 保存先 | **端末ごと**の localStorage `pkc3.saved-searches`。container に入れない | 書き出し・バックアップに混ぜると、HTML を渡した相手に「何を探していたか」が並ぶ(最近探した語 `pkc3.search-history` と同じ判断) |
| 設定ファイル | `SKIPPED_KEYS` に why つきで登録(運ばない) | 行動の記録であって設定ではない |
| 双方向 | 保存・適用・名前を直す・削除の 4 つで 1 組 | 片道の操作を作らない(CLAUDE.md §2-9) |
| 重複 | 同じ組(語は前後の空白を無視、札は順序を無視)は 2 つ憶えない。押すと「もう保存されています」 | 同じ行が並ぶと選べない |
| 上限 | 12 件。超えるときは**古い物を黙って捨てず断る** | 消したくない検索が黙って消えるのを避ける |
| 保存できない物 | 語も札も無い絞り / `>` で始まる操作を探す字 | 検索ではない |
| 名前を直す | アプリ内の小窓(`promptInApp`)。空のまま決めたら変えない | native `prompt` は使わない。名前の無い行を作らない |
| 保存が使えない端末 | その session の中ではメモリの控えで効く | `?.` で `null` が `catch` を素通りしない(`storage === null` を先に見る) |
| 別のタブ | `storage` イベントで読み直し、変わったときだけ描き直す | 別のタブが保存・削除した物を、次の操作で食い違ったまま使わない |
| 種類の札が効かない面(連絡先・アプリ) | 帯は出す。再適用は語と札を state へ置く(札は一覧・フォルダ・予定で効く) | 種類の札と語は面をまたいで state に残る仕様に揃える |

## 3. 作り

- 規則(pure): `src/features/history/saved-search.ts`(保存・重複・改名・削除・名前の自動付け)
- 置き場: `src/adapter/platform/saved-search-store.ts`(`appSavedSearches`。アプリ全体で 1 個)
- 描き手: `src/adapter/ui/render/saved-searches.ts`(`scope` = `filter` | `page` で 2 か所に置く。種類の札と同じ ボタン列の作り `buildPressedButton`)
- 受け手: `binder.ts` の `save-search` / `apply-saved-search` / `rename-saved-search` / `delete-saved-search`
- 左の列の器: `shell.ts` の `saved-searches`(種類の札 `kind-bar` のすぐ下)。探す面の器: `search-page-saved`

## 4. 検算(テスト)

- 規則: `tests/features/saved-search.test.ts`(重複・上限・正規化・壊れた保存の読み)
- 置き場: `tests/adapter/saved-search-store.test.ts`(保存が無い端末の控え・書込の中身・別のタブの読み直し・通知)
- 配線: `tests/adapter/saved-search-wiring.test.ts`(押した所から state まで。保存 → 再適用 → 名前を直す → 削除、両方の置き場)
