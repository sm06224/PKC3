# PKC3 マニュアル

PKC3 はブラウザだけで動くノートアプリです。サーバーに何も送りません ──
データは**あなたのブラウザの中**(OPFS 上の SQLite と IndexedDB)にあります。

---

## 1. はじめる

| したいこと | やり方 |
|---|---|
| 開く | product URL を開く(初回はオンラインが必要) |
| インストールする | ブラウザのアドレスバーの「インストール」から。以後アプリとして開ける |
| オフラインで使う | 一度オンラインで開いていれば、以後は機内モードでも開く |
| `.md` をこのアプリで開く | インストール後、`.md` / `.markdown` をダブルクリック(OS が PKC3 に渡す) |

⚠ **`file://` で開いたときは PWA になりません**(Service Worker が成立しない)。
書き出した「閲覧用 HTML」は単体で開けますが、それは別物です(→ §5)。

### データはどこにある?

- **本文・メタ・履歴・relations** … OPFS 上の SQLite(専用 worker が持つ)
- **添付の実体(bytes)** … IndexedDB の Blob

どちらもブラウザのサイトデータです。**ブラウザのサイトデータを消すと全部消えます。**
消える前に「バックアップ」を書き出してください(→ §5)。

### 🔴 複数タブで開ける(保存の本体は 1 つ)

タブは何枚でも開けます。**2 枚目以降もふつうに使えます** ── 一覧・閲覧・編集・
新規作成、全部できます。仕組み上、保存を実際に書き込む「本体」は 1 タブだけで
(データベースが単一接続のため)、2 枚目以降の保存は**本体タブ経由**で届きます。
2 枚目以降のタブには、画面下の status に「複数タブ: このタブの保存は本体タブ経由です」
と常に出ています。⚠ ただし**アプリの窓**(→ §4-6)には出しません ── そちらは
user が自分で開いた窓で、そこでできることも無いためです(画面の下の 1 行は、
**その場で読ませたい文**のために空けてあります)。

- **同じノート**を 2 つのタブで同時に編集することはできません(片方の編集内容が
  黙って消えるのを防ぐため)。後から押した側に「このノートは別のタブで編集中です」と
  出ます。**別々のノート**なら並行して編集できます。
- あるタブで保存すると、他のタブの一覧・本文にも自動で反映されます
  (編集中のタブは、編集を終えたときに反映されます)。
- 本体のタブを閉じると、残ったタブの 1 つが**その場で本体を引き継ぎます**
  (「このタブが本体になりました」と出ます。読み直しは要りません)。
- 相手が古い版(この仕組みが入る前)のときだけ、従来どおり
  「別のタブで開いています。そのタブを閉じると、ここで続きが開きます…」と出て待ちます。

🔴 **同じノートに、別の窓から書き込みが重なったとき。**
本文を書いている最中に、**別のタブや別の窓**が同じノートに日付やチェックを
書くことがあります(→ §4-6)。そのまま保存すると、
**こちらで打った字が残り、別の窓の版は上書きされます**。

- **黙って上書きしません。** 重なったときだけ、画面の下に
  「別の窓の変更と重なりました…」と出ます
- **上書きされた版は履歴に残ります。** 右の情報から**履歴**を開くと、
  その版に戻せます(→ §6)
- ⚠ 保存せずに**取り消した**ときは、別の窓の版がそのまま残ります
  (打っていた字を捨てたので、新しいほうが勝ちます)

## 2. ノートを作る・編集する

左の列の上に、**探す**・作るボタン・**添付** が並んでいます(欄には「探す」と出ています。
マニュアルの他の場所で「絞り込み」と書いてあるのは同じものです)。

| ここ | 何をするか |
|---|---|
| **探す** | 題名**と本文**で一覧を絞ります(打つとすぐ効きます。消せば全部戻ります)。⚠ 本文の当たりは少し遅れて増えます ── 打った直後に出ないのは「まだ数えていない」であって「無い」ではありません |
| **+ ノート** | いま選んでいる種類で作ります(**Ctrl+N** でも同じ) |
| ▼ | 作る種類を選びます。選ぶとボタンの文言と図案が変わり、**Ctrl+N の対象も変わります** |
| **今日** | **今日の日付のノート**(`2026-08-23` のような題名)を開きます。無ければ作ります |
| **添付** | ファイルを取り込んで添付にします |
| **録音** | マイクで録って、いま開いているノートに入れます |
| **画面** | 画面を録って、いま開いているノートに入れます |
| **計る** | いま開いているノートの**作業時間**を計ります(止めると本文に入ります) |

⚠ ボタンは**いま何ができるか**を出します ── 表を作る状態なら「**+ 表**」になります。
⚠ **Ctrl+N は編集中には効きません**(打っている途中に別のノートへ飛ばないため)。

#### 録音・画面収録

会議やレビューを**その場で録って、いま書いているノートに残す**ための道です。

1. メモにするノートを開きます(**ノート**か**ログ**)
2. **録音**(または**画面**)を押します。マイク・画面の共有をブラウザが確認します
3. 収録している間は**画面の下に帯**が出ます ── 経った時間と、だいたいの大きさが出ます。
   帯は左の列を畳んでも消えません(止める道が消えないためです)
4. **止める**で終わりです。**捨てる**なら何も残しません

止めると、収録は**添付**になり、**そのとき開いていたノートの本文**に
その添付への参照(`[録音-2026-08-27-030102.webm](asset:ast-…)`)が入ります。
⚠ **開いていたノートはそのまま開いたまま**です(添付に切り替わりません)。

| こんなとき | どうなるか |
|---|---|
| ブラウザの側で「共有を停止」した | 収録は終わります。**そこまでの分は残ります** |
| 250MB まで録った | 自動で止まります。**そこまでの分は残ります** |
| マイク・画面を許可しなかった | 理由が出ます(黙って何も起きない、にはなりません) |
| ノートを開いていない / 追記できない種類を開いている | **添付にはなります**が、本文には入りません。そのことを画面の下でお知らせします |
| **編集している最中に「止める」を押した** | 断ります(**収録は続いています**)。編集を終えてから止めてください ── 編集中は添付を作れないので、押させて失わせないためです |
| **編集している最中に止まった**(共有の終了 / 上限) | **預かります**。編集を終えると、そのとき開いているノートに入れます |
| **止めた瞬間、たまたま本文を書いている最中だった** | **預かります**。書き終わるとすぐ入ります(ふつうは一瞬です) |
| すでに収録している | 2 本目は始まりません(先に止めてください) |

⚠ 本文に入るのは**参照**です ── **その隣に再生の器が出る**ので、そのまま聞けます
(2026-08-27 追加)。名前のリンクを押せば、これまでどおり保存できます。

⚠ 収録の中身は**添付と同じ置き場**(ブラウザの中)に入ります。持ち出すときは
「書き出す・取り込む」の章の手順で、添付ごと出してください。

#### 作業時間を計る

「この資料に何時間かけたか」を**そのノート自身に残す**ための道です。
⚠ ただの砂時計ではありません ── 止めると**本文に 1 行入る**のがこの道具の要です。

1. 計りたいノートを開きます(**ノート**か**ログ**)
2. **計る**を押します。画面の下に帯が出て、名前と経った時間が出ます
3. 別のノートを開いて押せば、**何本でも同時に**計れます
4. **止める**で終わりです。**捨てる**なら何も残しません

止めると、そのノートの本文の**末尾**に 1 行入ります:

```
- 作業 2026-08-27 06:40–07:03(23:11)
```

⚠ **丸めません**(「23 分」ではなく `23:11`)── 何度も計って**足し合わせる**ものなので、
潰すと合計が出せなくなるためです。

| こんなとき | どうなるか |
|---|---|
| ノートを開いていない / 追記できない種類を開いている | **押した時点で断ります**。⚠ 止めてから断ると、計った時間の行き場がありません |
| 同じノートをもう一度「計る」 | 断ります(先に止めてください)── 2 本走ると、止めた回数だけ行が増えて合計が倍になります |
| **編集している最中に「止める」を押した** | **時計はその瞬間に止まります**。本文へ入れるのは編集を終えてからです(待っている間に時間が伸びません) |
| 計っている相手のノートを消した | 本文には入りません。計った時間は**画面の下に字で出します**(黙って失わせません) |
| 別のタブを見ていた | 時間は正しく進みます ── **刻みを数えず、始めた時刻との差**で出しています |

⚠ **ページを読み直すと計測は消えます。** 開いている間だけ動く道具です。

#### 「今日」で書きとめる

思いついたことを、**どこに書くか決めずに**書きとめたいときに使います。

- 押すと **今日の日付を題名にしたノート**が開きます。その日に何度押しても**同じ 1 件**です
- まだ無い日は**その場で作ります**(ただの**ノート**です ── 特別な種類ではありません)
- ⚠ **編集中は効きません**(`Ctrl+N` と同じ理由 ── 打っている途中に飛ばないため)
- ⚠ 題名を変えると、次に押したときは**別に新しく作ります**(題名で見分けているため)
- ⚠ 予定の面には出ません ── 「今日書いたこと」は予定ではないので、
  日付は題名だけに持ちます。予定にしたいときは本文に `@2026-08-25` と書いてください(→ §3)

作れる種類は次のとおりです。

| 種類 | 何が違うか |
|---|---|
| **ノート** | 素の PKC-Markdown。いちばん普通のノート |
| **ログ** | 追記型。`## <日時>` の節を末尾に足していきます(秒まで) |
| **表** | csv fence と、レイアウト・グラフ・書式の指定 |
| **フォルダ** | 入れ物。フォルダ画面で階層になります |
| **スマート** | **条件に合うノートが自動で集まる**入れ物(→ §4「スマートフォルダ」) |
| **雛形** | よく打つ型を入れておき、**短縮語 + `Tab`** で呼び出します(→ §3「雛形を作って呼び出す」) |

⚠ **Todo は今はお休み中**です。作る導線を畳んでいるだけなので、
**取り込んだ Todo は普通のノートとして読めて、編集もできます**。
🔑 やることを書くのは**普通のノートのチェックリスト**です ──
**日付を書いた行**(`- [ ] やること @2026-08-25`)が、左の列の **予定** タブに
札として並びます(→ §4「予定」)。⚠ 日付を書かない行は、文章の体裁として使えます
(既定では予定に出ません)。

🔑 **本文はどれも PKC-Markdown 1 種類**です。archetype は「見せ方・編集の仕方」の
フレーバーであって、別のデータ形式ではありません ── だから、どのノートも
そのまま markdown として読めます。

編集は **編集** ボタン → 書く → **保存**。取り消しは **キャンセル**。
最初の設定では **1 面で編集(ライブ)**(下の「1 面で編集する」)で開きます。
設定の「表示」の「編集の仕方」で **2 ペイン(原文とプレビュー)** にもできます(→ §4-2)。
2 ペインでは**左に原文、右にプレビュー**が並びます。
プレビューは**打つ手が止まってから**追いつきます(打ち続けているときも 3 秒に 1 回は
反映されます)── 1 打鍵ごとに描き直すと画面がガタつくためです。
⚠ 変わった所だけを描き直すので、**スクロール位置は動かず、触っていない図も消えません**。
⚠ 2 ペインでは、画面が狭いときはプレビューを畳みます。
⚠ 本文の**文章の部分**をクリックしても編集には入りません(誤操作で本文が変わらない
ように)。⚠ **チェックの印と表の升は、これまでどおり押せばその場で直せます。**

🔑 **`Ctrl`(mac は `⌘`)を押しながら本文をクリックすると、その行から編集に入ります。**
読んでいて「この 1 行だけ直したい」というときの近道です ── 「編集」を押してから
もう一度その行を探す手間が要りません。

🔑 **`Alt` を押しながら本文をクリックすると、下の追記欄の「入り先」がその節になります。**
本文を開かずに、読んでいる場所へ 1 行足したいときの近道です(→ §4-4)。

⚠ **2026-08-28 に割り当てを変えました。** それまで `Alt` を押しながらのクリックが
「その行から編集」でした ── いまは **`Ctrl`(mac は `⌘`)**です。`Alt` は上の
「追記の入り先」になりました。

- ⚠ **素のクリックはこれまでどおり**です(何も起きません)
- ⚠ リンクやボタンの上では効きません(そちらの動きが優先です)──
  `Ctrl+クリック` の「新しいタブで開く」もそのまま残ります
- ⚠ 修飾キーを 2 つ以上押しているときは効きません(`Ctrl+Alt` や `Shift` との組)
- ⚠ `Alt+クリック` した所より上に見出しが無いときは、入り先を変えずに理由を出します
  (関係のない場所へ足さないためです)

### 見出しの見え方と、見出しで畳む

本文の見出しは、**左端に細い色の帯**が付きます。段が下がるほど帯は薄くなります。

- 🔑 **`####` より深い見出しも、本文より小さくはなりません。** 段は大きさではなく
  **帯の濃さ**で表しています(小さくして段を作ると、深い見出しが本文に埋もれます)
- `#` と `##` には、下に薄い区切り線も引きます(節の切れ目)

**この帯が、そのまま畳むボタンです。**

| したいこと | やり方 |
|---|---|
| 節を畳む | 左端の**帯を押します**。マウスを乗せると帯が**太く濃く**なります |
| 畳んだ節を開く | もう一度**帯を押します**(畳んでいる間は **▸** が出ています) |

- 🔑 **押し所は帯の幅だけ**です。見出しの**字のほう**を押しても畳みません ──
  読むつもりで押して中身が消える、が起きません
- 🔑 見出しの字から**その行の編集に入る**には、**`Ctrl`(mac は `⌘`)を押しながら**
  クリックします(→ §4「本文を押したときに何が起きるか」)
- ⚠ **ふだんは記号を出しません。** 見出しの行に記号が並ぶと、肝心の見出しの字が
  読みにくくなるためです。押せることは、乗せたときに**帯が太くなる**ことで分かります
- 🔑 **畳んでいる間だけは、乗せていなくても ▸ が出たまま**になります ──
  畳んだことも、開き直す口も、画面から消えません
- ⚠ 配下が何も無い見出しでは、帯は出ますが押せません(畳む物がないため)
- 畳み方は**その場の見え方**です。ノートには残らないので、開き直すと元に戻ります

### 本文をコピーする

読んでいるノートの上に、コピーのボタンが 3 つ並びます。

| ボタン | 何が入るか |
|---|---|
| **Markdown をコピー** | 本文の原文(書いたままの markdown) |
| **書式付きでコピー** | 見た目つき。Word やメールに貼ると**そのままの体裁**で入ります |
| **選択範囲をコピー** | 選んだところだけを**原文**で。選んでいないときは押せません |

⚠ **書式付きでコピー**は、貼り先で崩れないように**掃除してから**渡します ── 図やグラフの
原文、押せないボタン、PKC3 の内部の印は付いてきません。画像は貼り先でも読める形に
埋め込みます。⚠ 埋め込めなかった画像は**文字に置き換え、件数を画面に出します**
(壊れた画像を貼らせないためです)。

⚠ ふつうに範囲を選んで Ctrl+C したときは、これまでどおり**見えているテキスト**が入ります
(このボタンは別口です)。

### 1 面で編集する(ライブエディタ)

**最初の設定はこちらです。** 2 ペインに戻したいときは、設定の「表示」の
**編集の仕方**から選べます(→ §4-2)。

**押した行だけが原文になり**、周りは描画のまま残ります。行を離れると確定します。
🔑 **表の中や箇条書きの中でも同じです** ── 押した行(項目)だけが原文になり、
表や箇条書きの残りは**描かれたまま並んでいます**(どの行を直しているのかが見えます)。

🔑 **字を選んでいる間は、押しても行が開きません**(2026-08-28 に直しました)──
それまでは**ドラッグで字を選び終わった瞬間に選択が消えて編集に入って**いました。
コピーしたいだけのときに邪魔をしません。

- 🔑 **選んでいても開きたい**ときは、`Ctrl`(mac は `⌘`)を押しながらクリックします
- 🔑 **本文の下の余白**を押したときは、これまでどおり**末尾に行が開きます**
  (作ったばかりの空のノートは、ここが書き始める場所です)
- 🔑 まとめて直したいときは **全文を編集** ボタン(`Ctrl+A` と同じ)

| キー | 何が起きるか |
|---|---|
| **↓** / **↑** | 箱の中でカーソルが動きます。**いちばん下(上)に着いてから、同じ向きにもう 1 回**押すと、その行を確定して**次(前)の行を開きます** |
| **Tab** / **Ctrl+Enter** | その行を確定して閉じます |
| **Escape** | 打ったものを捨てて閉じます |
| **Ctrl+S** | その行を確定します(ブラウザの保存は開きません) |
| **Ctrl+A** | 全文が 1 つの入力欄になります(**全文を編集** ボタンでも同じ) |
| **Ctrl+Z** / **Ctrl+Shift+Z** | 行の中は打鍵ごと、行の外は確定ごとに戻します |

🔑 **隣の行へ移るのは「端で 2 回」です。** 長い段落は折り返して何行にも見えますが、
その途中では飛びません ── **本当にいちばん下(上)まで着いてから**、同じ向きにもう 1 回
押したときだけ移ります。⚠ 別のキーを打ったり字を入れたりすると、数え直しになります
(打った直後の 1 回で飛ばないためです)。**時間では切りません** ── ゆっくり押しても
かまいません。

書式パネルと **Ctrl+B / I / K** は、開いている行にも効きます。

#### 括弧は自動で閉じます

`[` `(` `{` `` ` `` `"` と、全角の `「` `『` `（` `【` を打つと、**閉じが自動で入り**、
カーソルはその中に置かれます。**文字を選んでから打つと、その文字を囲みます。**

🔑 **そのあと自分で閉じを打っても、二重にはなりません** ── すでにある閉じを
**通り抜けます**(2026-08-21 に直しました。それまでは `tags: [あ, い]` と打つと
`tags: [あ, い]]` になり、⚠ **そのタグが「い]」として黙って保存されていました**)。

⚠ 行頭で `` ` `` を 3 つ、または `:` を 3 つ打つと、**閉じは次の行**に入ります
(コード塊 / 囲みは行頭でないと効かないためです)。

⚠ この補完が効くのは **1 面編集の行**だけです。2 ペインの原文の欄や、
文書の情報の欄では入りません。

### 書式パネル

編集中は、原文のすぐ上に書式のボタンが並びます。**先に選んでから押す**と、
その範囲に効きます(何も選ばずに押すと印だけ入って、その間にカーソルが入ります)。
行頭の印(見出し / 箇条書き / 引用 / チェック)と **太字 / 斜体 / コード** は
**もう一度押すと外れます**。**表 / 図 / コード塊 / リンク** は雛形を差し込むので、
間違えたときは手で消してください。

| ボタン | 何になるか |
|---|---|
| **見出し1** / **見出し2** / **見出し3** | 行頭に `#` / `##` / `###` |
| **太字** / **斜体** / **コード** | 選んだ範囲を `**` / `*` / `` ` `` で囲みます |
| **箇条書き** / **番号** / **チェック** / **引用** | 行頭に `-` / `1.` / `- [ ]` / `>` |
| **リンク** | `[文字](url)` を入れて、`url` を選択した状態にします |
| **表** / **図** / **コード塊** | 雛形を差し込みます(表 = 2 列、図 = `mermaid`) |
| **日付** | 日付を選んで、カーソルの位置に入れます(`Ctrl` + `;`)。→ 下の「日付を入れる」 |
| **雛形** | 雛形を一覧から選んで入れます(`Ctrl` + `/`)。→ 下の「雛形を作って呼び出す」 |
| **ノート** | 別のノートを**題名で探して**、そこへのリンクをカーソルの位置に入れます(`Ctrl` + `Shift` + `K`)。→ 下の「別のノートへリンクを張る」 |
| **番号** | 番号付きリストの番号を、**上から順に振り直します**。途中に行を挿して番号がずれたときに 1 回押してください |
| **置換** | 本文の**探す語を全部置き換える**欄を開きます(`Ctrl` + `H`)。⚠ **大小を区別**したいときは、開いた欄の「大小を区別」を入れてください |

近道キー(本文の中だけ): `Ctrl`(Mac は `⌘`)+ `B` = 太字、`+ I` = 斜体、
`+ K` = リンク。⚠ 日本語の変換中は効きません(変換を確定してから押してください)。

#### ボタンが無い書式(鍵で入れます)

帯が横に長くなりすぎるので、次の 4 つは**ボタンを置いていません**。
**近道キーで入れます**(設定 → ショートカット で好きな鍵に変えられます)。

| 書式 | 何になるか | 既定の鍵 |
|---|---|---|
| **ハイライト** | 選んだ範囲を `==` で囲み、蛍光ペンのように光ります。色を付けたいときは `==[red]…==` と書けます | `Alt` + `Shift` + `H` |
| **ルビ** | 選んだ字にふりがなを付けます(`[[ruby:漢字|かんじ]]`)。押すと**読みの位置**にカーソルが入ります | `Alt` + `Shift` + `R` |
| **圏点** | 選んだ字の上に点を打ちます(`^^` で囲みます) | `Alt` + `Shift` + `E` |
| **打ち消し** | 選んだ字に取り消し線を引きます(`~~` で囲みます) | `Alt` + `Shift` + `X` |

⚠ どれも**もう一度押すと外れます**(太字と同じ)。
🔑 **名前を忘れても探せます** ── **操作を探す**(→ §10-1)で「ルビ」と打てば、
🔑 **そのまま入れられます**(鍵を覚えていなくても構いません)。
⚠ **先に入れたい所を選んでから**開いてください ── 開いた時点の選択範囲に入ります。

#### 別のノートへリンクを張る

書いている途中で「これは**先週の議事録**の続きだ」というとき、
書式の帯の **ノート** を押す(`Ctrl` + `Shift` + `K`)と、**題名で探す**小窓が出ます。
選ぶと、**いまカーソルが在る場所**にリンクが入ります。

```markdown
つづき:[先週の議事録](entry:mta73ihn-0001)
```

- 開いた直後にそのまま**題名を打って絞れます**。`Enter` でいちばん上が入ります
- **書いている自分自身は出ません**(貼っても同じ所に戻るだけなので)
- **ごみ箱に入れたノートも出ません**(押しても開けない先を候補にしないため)
- ノートが多いときは **50 件まで**出します。切ったときは小窓の下にその旨が出ます

⚠ **題名は貼ったときの字が残ります。** 後でそのノートの題名を変えても、
貼った字は変わりません(**リンク先は変わりません**ので、押せば開きます)。

🔑 相手のノートを**開いてから**貼りたいときは、右の情報ペインの
**参照をコピー**でも同じ 1 行が手に入ります。

#### 雛形を作って呼び出す

よく打つ文(住所・署名・議事録の型)は、**雛形**として置いておけます。

**作り方** ── 左上の作成ボタンから「**雛形**」を選び、本文に中身を書きます。
先頭の `abbr:` に**短縮語**を書いておくと、その語で呼び出せます。

```markdown
---
abbr: addr
---
〒100-0000 東京都千代田区…
```

**呼び出し方は 2 つ**あります。

1. **一覧から選ぶ** ── 書式の帯の **雛形** を押す(`Ctrl` + `/`)と、雛形の一覧が出ます。
   押した行がそのまま本文に入ります。⚠ 短縮語を覚えていなくても、**題名で選べます**
   (短縮語を書いてある雛形は「題名(短縮語)」と出るので、次からは `Tab` で呼べます)
2. **短縮語 + `Tab`** ── 本文を書いている途中で `addr` と打って **`Tab`** を押すだけです

⚠ 一覧には、PKC3 に**もとから入っている雛形**(表 / 図 / コード塊 / リンク)も並びます
── 自分の雛形をまだ作っていなくても、空の一覧にはなりません。

| 書き方 | 挿すとどうなるか |
|---|---|
| `${宛名}` | **そのまま残り、選ばれた状態**になります。打てば置き換わり、`Tab` で次の場所へ |
| `${date}` | 挿した日(`2026-08-25`)。⚠ 予定の `@` と同じ形なので `@${date}` と書けます |
| `${time}` / `${datetime}` | `14:30` / `2026-08-25 14:30` |
| `${cursor}` | 消えて、そこにカーソルが来ます |

- 🔑 **短縮語が当たらないときの `Tab` は、これまでどおり次の欄へ移ります** ──
  書きかけの邪魔はしません。`Shift` + `Tab` も触っていません
- ⚠ **語の途中では出ません** ── `myaddr` と打っても `addr` は展開されません
- ⚠ **同じ字で始まる短縮語が複数あるときは、長いほうが勝ちます**
- ⚠ **雛形の外(普通のノート)に `${date}` と書いても、そのまま表示されます** ──
  展開されるのは**雛形を挿すとき**だけです
- ⚠ 短縮語は**書かなくてもかまいません** ── 書いていない雛形は**一覧から**呼べます
  (`Tab` で呼べるのは短縮語を書いたものだけです)
- ⚠ 雛形が**とても多いとき**は、先頭から 200 件までを見ます。
  **とても長い雛形**(4000 字を超えるもの)は、切って挿すと本文が壊れるので出しません

#### 日付を入れる

**日付** を押すと、小さな窓が出ます。

```
[今日] [明日] [今週末] [来週]
日付 [2026-08-25]  時刻(任意) [__:__]     [やめる] [入れる]
```

- 上の 4 つを押すと、**日付の欄が埋まります**(押しただけでは入りません ── そのまま
  時刻も決められるようにしてあります)。**入れる** で本文に入ります
- **今週末** は「次に来る土曜」、**来週** は「次に来る月曜」です。⚠ どれも**今日より前**には
  なりません
- **時刻は空でかまいません**。入れると `@2026-08-25 14:00` の形になります
- 入るのは **カーソルのある場所**です。直前が字なら、区切りの空白が 1 つ入ります
- ⚠ 入れた分は **`Ctrl` + `Z` で戻せます**(書式パネルの他のボタンとは違います)

🔑 この日付を**チェックリストの行**に入れると、左の列の **予定** タブに出ます
(→ §4「予定」)。**ノート 1 件が丸ごと予定**のときは、frontmatter の `date:` に
書きます(同じ節)。

⚠ **番号**は行ごとに数え直します(`1.` `2.` `3.`)。
⚠ 書式パネルで書き換えた分は、ブラウザの「元に戻す」(`Ctrl+Z`)では戻りません
── 戻したいときは **キャンセル** で編集ごと捨ててください。

### 追記

**ノート** と **ログ** には、本文の下に **追記欄** が出ます。
打って **追記** を押すか `Ctrl`(Mac は `⌘`)+ `Enter` で、**編集画面を開かずに**
末尾へ足して保存します ── 長いログでも、毎回全文を開く必要はありません。

| 種類 | 押すと何が足されるか |
|---|---|
| **ログ** | `## <日時>`(秒まで)の節 + 打った内容 |
| **ノート** | 打った内容だけ(見出しは足しません ── 構造は書く人のもの) |

⚠ 押しても空行は増えません(末尾の余白は畳んでから足します)。
⚠ 空欄のまま押しても何も起きません。
⚠ **通ったときだけ欄が空になります**。失敗したときは打った内容が残ります。

#### 入り先を選ぶ(節の中へ足す)

追記欄の左に **入り先** の選択があります。既定は **末尾** で、これまでと同じです。
開くと、**そのノートの見出しが並びます** ── 選ぶと、その見出しの**節の終わり**に入ります。

長い議事録の「決定事項」に 1 行だけ足したい、というときに **本文を開かずに**
そこへ書けます。⚠ 選んだ入り先は、続けて追記しても**そのまま**です
(同じ節へ何度でも足せます)。

🔑 **本文の読みたい所を `Alt` を押しながらクリックすると、その節が入り先になります。**
一覧から見出しを探さなくても、**足したい場所を直接指せます**(2026-08-27 に足しました)。

- ⚠ 見出しが 1 つも無いノートでは、この選択は**出ません**(選ぶ物が無いため)
- ⚠ 押した所より**上に見出しが無い**ときは、入り先を**変えずに**理由を出します
  (関係のない場所へ足さないためです)
- ⚠ 押すまでの間に**その見出しが本文から消えていたら、足しません** ── 理由が出ます
  (黙って末尾へ入る、ということはありません)
- 同じ字の見出しが 2 つあっても、**選んだほう**に入ります

#### 足したものを外す

追記が通ると **元に戻す** が出ます。押すと、**直前に足した内容だけ**が本文から消えます
── 本文を開く必要はありません。

- ⚠ 戻せるのは**直前の 1 手**だけです(2 度押しても、それ以上は消えません)
- ⚠ その間に別の窓が同じ所を書き替えていたら、**何も消さずに理由が出ます**

#### 追記と編集がぶつかったとき

追記は編集画面を通らずに書くので、**同じノートを編集している間は追記できません**
(そのまま書けてしまうと、保存したときに追記が消えます)。追記欄の場所に理由と
出口が出ます。

| 出ているもの | 意味 | 押すもの |
|---|---|---|
| このノートは編集中です | あなたが編集中 | **保存して解放** か **編集を破棄** |
| 追記を書き込んでいます… | 書き込み中(普通は一瞬) | 返ってこないときだけ **強制解放** |

⚠ **強制解放** は最後の出口です。書き込みが実際には進んでいた場合、画面の表示が
実際の中身より古くなることがあります(開き直すと直ります)。

#### 編集中にできないこと

**編集中は別のノートに移れません**(打ちかけを捨てないためです)。一覧の行や
本文のリンクを押すと、**画面の下に理由が出ます** ── 保存するか取り消してから
もう一度押してください。

⚠ 一方、**設定 / フラグ / ヘルプ / 2 ペインで整理は編集中でも開けます**。
戻れば打ちかけも取り消し(Ctrl+Z)もそのままです(→ §4)。
🔑 **開いた面は、面の上に出る「× 閉じる」で本文に戻せます**(2026-08-22 に足しました)。

⚠ **打っている最中に鍵で開けるのは、文字を打たない鍵だけ**です ──
**Ctrl + ,**(設定)/ **F12**(フラグ)/ **F1**(ヘルプ)。
`Alt + 3` のような鍵は、打っている間は**本文に文字が入るのを防ぐために止めます**
(打つのをやめれば効きます)。

## 3. 本文に書けるもの(PKC-Markdown)

CommonMark に加えて、次が使えます。

### fence(``` で囲むブロック)

| 言語 | 何になるか |
|---|---|
| `html` | サンドボックス化した iframe の中で描画 |
| `svg` | 図(SVG)。`html` と**同じ箱・同じ決まり**で描きます |
| `mermaid` | 図(フローチャート・**クラス図 / シーケンス図 / 状態遷移図 / ER 図**ほか、下の一覧) |
| `chart` | グラフ(棒 / 折れ線 / 円 / ドーナツ / レーダー / 散布) |
| `csv` / `tsv` / `psv` | 表 |

末尾に `-render` / `-norender` / `-both` を付けると出し方を変えられます
(既定は `-both` = 描画とソースの両方)。csv 系は `noheader` などのオプションを
言語名の後ろに書けます。

    ```csv-render noheader
    りんご,120
    みかん,80
    ```

#### 🔴 表は、升を押して打てます

**描かれた表の升を押すと、その升が入力欄になります。** 周りは表のままです ──
`Enter` で確定、`Escape` で取り消し(押す前の字に戻ります)。
🔑 **CSV の原文を開いて、どのカンマが A1 かを数える必要はありません。**

| したいこと | どうするか |
|---|---|
| 升に打つ | 升を押して打ち、`Enter` |
| 升を空にする | 升を押して字を消し、`Enter` |
| やめる | `Escape`(押す前の字に戻ります) |
| 行を足す / 消す | 行の左端の升にマウスを乗せると **＋ ×** が出ます |
| 列を足す / 消す | 見出しの升(見出しが無い表なら 1 行目)に **＋ ×** が出ます |

⚠ **最後の 1 行 / 1 列は消せません** ── 消すと表そのものが消えて、CSV の原文に
戻ることになるためです。
⚠ **押せるのは読む面だけ**です。編集の面では、これまでどおり原文を直せます。
⚠ **書き出した HTML・印刷では押せません**(受け手が居ないので、押せる形にすると
「打ったのに消えた」になります)。
⚠ 升の中に**引用符つきの改行**(`"あ` で始まって次の行へ続く形)を書いた行だけは、
押せません ── そこへ書くと次の行まで巻き込むためです。原文を直してください。

🔑 **左上の「新規」→「表」**で作った空の表(5 列 × 3 行)も、そのまま升から打てます。

#### 🔴 升に式が書けます

**`=` で始めて打つと計算します。** 升には**結果**が出て、**押すと式**が出ます。

    ```csv
    しなもの,たんか,かず,小計
    りんご,120,3,=B2*C2
    みかん,80,5,=B3*C3
    合計,,,=SUM(D2:D3)
    ```

| | |
|---|---|
| 升の名前 | `A1` が左上です。⚠ **見出しの行も 1 行目**に数えます(`noheader` を切り替えても番号が動きません) |
| 使えるもの | `+ - * / ^` と `( )`、比べる `< > = <= >= <>` |
| 使える関数 | `SUM` / `AVERAGE` / `MIN` / `MAX` / `COUNT` / `IF` / `ABS` / `ROUND` / `CONCAT` / `LEN` |
| 範囲 | `A1:B10` のように書きます(関数の中でだけ使えます) |
| 🔴 `=` を**字として**書きたいとき | 先頭に `'` を付けます(`'=だいじ`)── 表示は `=だいじ` です |

🔑 **書いたものは本文に残ります。** 計算するのは**表示するときだけ**なので、
式が結果に置き換わって消えることはありません。

⚠ 範囲の中に**字**(見出しや注記)が混ざっていても、`SUM` などは**飛ばして**
計算します。⚠ ただし `=SUM(1,"あ")` のように**直接書いた字**は誤りになります
(打ち間違いを黙って 0 として足さないためです)。

読めなかったときは、その升に理由が出ます(表全体は消えません):

| 出る字 | 意味 |
|---|---|
| `#DIV/0!` | 0 で割りました |
| `#NAME?` | 使えない関数名です |
| `#REF!` | 範囲の書き方が違います |
| `#CYCLE!` | 升どうしがぐるぐる参照しています |
| `#ERR!` | 式として読めません(括弧の閉じ忘れなど) |

#### 中身を添付から取る

囲みの見出しに **`asset:<添付の鍵>`** と書くと、**中身をその添付から**取ります。
⚠ **言語は選びません** ── 上の表の 4 種でも、ふつうのコードの囲みでも同じに効きます。

    ```csv asset:ast-xxxxxxxx
    ```

| | |
|---|---|
| 何に使うか | 5,000 行の CSV を表で見る / 大きい図の原文を本文から出す / ソースコードのファイルをそのまま色付きで見せる |
| 鍵の取り方 | その添付を開いて **参照をコピー**(`![名前](asset:ast-…)` が手に入るので、`asset:` 以降を使います) |
| 語順 | `csv asset:… noheader` でも `csv noheader asset:…` でも同じです |
| 言語を書かないとき | ` ```asset:ast-… ` だけでも効きます(ふつうのコードの囲みになります) |

⚠ **囲みの中に字も書いてあると、それは控えになります** ── 添付が読めたときは
添付の中身が出て、読めなかったときに書いた字が出ます。

読めなかったときは、囲みの場所に**理由**が出ます(黙って空にはしません):

| 出る字 | 意味 |
|---|---|
| その添付が見つかりません | 鍵が違う / その添付を消しました |
| 添付を 2 つ書いています(1 つにしてください) | 見出しに `asset:` を 2 つ書きました |
| 添付の鍵が空です | `asset:` とだけ書きました |

🔑 **書き出しにも中身が入ります。** 閲覧用 HTML・Word・PowerPoint に書き出すときは、
囲みが指している添付を**その場で読んで焼き込む**ので、渡した相手の手元でも
本文に書いたのと同じに見えます(相手は添付を持っていなくてかまいません)。
⚠ 書き出すときに読めなかった添付だけは、囲みの場所に**理由**が残ります
(上の表と同じ字です)── **黙って空にはしません**。
⚠ Markdown の ZIP は例外です ── こちらは**原文をそのまま**書き出すので、
`asset:…` の行と添付のファイルが別々に入ります(読み直せる形です)。

🔑 **添付は消えません。** 見出しに書いた `asset:…` も「使っている添付」として
数えるので、片づけ(未参照の添付の掃除)で消えることはありません。

グラフは JSON で書きます。

    ```chart
    { "type": "bar",
      "labels": ["1月", "2月", "3月"],
      "datasets": [{ "label": "売上", "data": [10, 20, 15] }],
      "title": "月別の売上" }
    ```

`type` は `bar` / `line` / `pie` / `doughnut` / `radar` / `scatter` のどれかです。
`title` と `stacked`(積み上げ)、`legend`(凡例を出すか)も書けます。
⚠ 書けるのはここに挙げた項目だけです ── 知らない項目は**黙って無視します**。
⚠ 読めないときは、その場に理由が出ます(黙って空になりません)。

⚠ **図(`mermaid`)とグラフ(`chart`)は PNG にして表示します**。スクロールを軽く保つためで、
同じ図・同じ配色・同じ幅なら 2 回目からは焼き直しません(配色を変えると焼き直します)。

図の色は**選んでいる配色に従います** ── ダークな配色ならダークな図になり、
配色を切り替えると、開いている図はその場で描き直されます。

### どんな図が描けるか

`mermaid` の囲みは、**1 行目に書く記法の名前**で図の種類が決まります。
下はぜんぶ**そのまま書けます**(2026-08-28 に 22 種を実際に描いて確かめました)。

| 1 行目に書く | どんな図 |
|---|---|
| `graph TD` / `graph LR` | フローチャート(上から / 左から) |
| `classDiagram` | **クラス図**(UML) |
| `sequenceDiagram` | **シーケンス図**(UML) |
| `stateDiagram-v2` | **状態遷移図**(UML) |
| `erDiagram` | **ER 図**(実体関連図) |
| `requirementDiagram` | 要求図(UML) |
| `C4Context` | システム構成(C4) |
| `gantt` | 日程表(ガント) |
| `timeline` | 年表 |
| `journey` | 体験の流れ(カスタマージャーニー) |
| `kanban` | かんばん |
| `mindmap` | マインドマップ |
| `gitGraph` | 枝分かれの図(git) |
| `pie` | 円グラフ |
| `quadrantChart` | 4 象限 |
| `xychart-beta` | 折れ線 / 棒 |
| `radar-beta` | レーダー |
| `sankey-beta` | 流量図(サンキー) |
| `treemap-beta` | 面積で見る内訳 |
| `block-beta` | ブロック図 |
| `packet-beta` | ビット配置図 |
| `architecture-beta` | 構成図 |

🔑 **よく使う 4 つは、選ぶだけで入ります。** 書式の帯の **雛形** を押すと、
自分の雛形のあとに **クラス図 / シーケンス図 / 状態遷移図 / ER 図** が並びます。
押すとその場に書き出しが入るので、名前や矢印を書き替えるだけです
(「図」を押したときに入るのは、これまでどおりフローチャートです)。

たとえばクラス図はこう書きます。

    ```mermaid
    classDiagram
      class 帳簿 {
        +記帳()
      }
      帳簿 <|-- 出納帳
    ```

⚠ **記法そのものの書き方はここには書きません** ── 種類ごとに細かい決まりがあり、
本書に写すと必ず古くなるためです。1 行目の名前で検索してください
(mermaid の記法です。いま入っているのは **11.17.0**)。

⚠ 名前を間違えたときや書き方が通らないときは、**その場に理由が出ます**
(黙って空にはなりません)。

### 図・画像を大きく見る

図(や**本文に貼った画像**)にマウスを載せると**虫めがねのカーソル**になります。
押すと**別の窓**が開き、**実寸**で出ます(画面に出ている大きさではなく、
**縮める前の大きさ**です)。

- 窓の中の **＋** / **−** / **等倍** / **収める** で大きさを変えられます。
  Ctrl(mac は Command)を押しながらホイールでも変えられます
- 🔑 **大きくした絵は、掴んで動かすと送れます**(見たい所へ寄せられます)──
  端の細い棒を掴む必要はありません
- 🔑 **収める** はいつでも押せます ── 大きくしすぎても、窓に収まる大きさへ戻せます
  (開き直す必要はありません)
- 🔑 **段組みで読んでいるときにいちばん効きます** ── 段に収めるために
  小さくしてあるので、別の窓では小さくなる前の大きさで読めます
- ⚠ **押し所は増えていません**。絵そのものが押し所です
- ⚠ **編集しているときは開きません** ── そちらは絵を押すと
  **その行の原文**が開きます(直すためです)
- ⚠ 拡大すると粗くなります。焼いたときの大きさで固まっているためです。
  きれいなまま拡大したいときは **図を保存**(下)でベクタに落としてください

### 図を保存する

描かれた図の右上に **図を保存** があります。押すと **ベクタ**(`.svg`)で落ちてきます
── 画面に出ているのは PNG ですが、**書き出しは拡大しても粗くならない形**です。
資料に貼る・印刷する用途はこちらを使ってください。
書き出しには少し時間が掛かります(原文から描き直すため)。その間ボタンは
**書き出し中…** になって押せなくなります。落ちてくるファイルは、画面で見えている
のと**同じ配色**です。

ファイル名は `<ノートの題名>-図1.svg` のように、本文の中で**何枚目か**が付きます。

### そのほか

- **脚注** `[^1]`
- **目次** `:::toc` / `:::toc{depth=2}`

  🔑 **書かなくても、右の情報ペインに目次が出ます**(→ §4-0b)。この書き方は
  「**本文の好きな位置に**目次を置きたい」ときのものです。
- 🔴 **チェックリスト** `- [ ] やること` / `- [x] 済んだこと`

  **読む面では、印をそのまま押せます。** 押すと本文の `[ ]` が `[x]` に変わって
  保存されます(もう一度押すと戻ります)。⚠ 書き換わるのは**押した行の印 1 文字**
  だけで、まわりの本文も空白の入れ方も変わりません。
  ⚠ **編集中は押せません**(「編集を終了してから」と出ます)。
  ⚠ 保存に失敗しているときも押せません(そのときは「保存をやり直すか取り消してから」と出ます)。
  ⚠ **書き出した HTML・別の窓・印刷では押せません** ── 保存する先が無いので、
  押せる形で出しません(押せるのに残らない、を作らないためです)。
- **行の寄せ**(行頭に置きます)

  | 書き方 | どうなるか |
  |---|---|
  | `\|\| 本文` | **中央**に寄ります |
  | `\|> 本文` | **全体の寄せの反対側**に寄ります(何も宣言しない横書きなら右) |
  | `<\| 本文` / `\|< 本文` / `>\| 本文` | ⚠ **上と同じ**です(打ち間違い扱いで受理します) |

  ⚠ **矢印の向きに意味はありません** ── `<\|` と書いても `\|>` と同じ側に寄ります。
  寄せの記法は「**中央**」と「**全体の寄せの反対側**」の 2 つだけです。
  ⚠ **どちら側が「反対」か**は、その文書の frontmatter が決めます ──
  `direction: rtl` と書くと全体が右起点になり `\|>` は左へ、`align: right` と
  書いたときも `\|>` は**左**へ寄ります(全体の寄せが右なので、その反対)。
  `align: center` のときは**寄りません** ── 中央に「反対側」は無いからです。
  どうしても**物理的に左**へ寄せたいときは `:::paragraph{align=left}` と書いてください
  (`align=end` / `align=start` / `align=center` / `align=right` も書けます。
  `:::format{align=…}` も同じ値を受けます)
- **frontmatter**(先頭の `---` で囲んだ領域)── todo の `status` などはここに入る。
  文書全体の**書き方**もここで宣言します

  🔑 **1 面編集では「この文書の情報」という札**として、本文の上に出ます(中身も出ます)。
  書き替えるときは札の **情報を編集** を押してください ── Enter で改行、**確定**で
  反映、**やめる**で元に戻ります。

  🔑 **2 ペイン編集では札は出ません** ── 左の原文欄の**先頭にそのまま見えていて**、
  その場で書き替えられます(**保存**で残り、**キャンセル**で編集ごと元に戻ります)。
  ⚠ そのぶん**うっかり消せます** ── 閉じの `---` を消すと情報として読めなくなります
  (そのときは右の情報ペインの「タグ」の行が「読めていません」と出ます)。
  ⚠ 本文の編集や **全文を編集** では**巻き込まれません**(うっかり消せません)。
  ⚠ 先頭の `---` と閉じの `---` の両方が要ります。閉じを消すと情報として読めなくなり、
  そのときは **1 面編集なら札そのものが理由を出します**(要約の代わりに
  「文書の情報が読めていません」と出ます)。
  🔑 **読めなくても **情報を編集** は出します** ── 読めない原文こそ、そこで直したい
  場所だからです。⚠ ただし**本文の側に壊れた行がそのまま見えている**ときは出ません
  (切り出す行が無く、本文で直せるためです)。
  書いた内容は本文に残っているので、閉じの `---` を書き足せば元に戻ります。

  🔑 **編集していないときは、右の情報ペインの「タグ」の行**に「読めていません」と出ます
  (理由はその文字にマウスを乗せると出ます)。⚠ この行は**そのノートを開いている
  ときだけ**中身が出ます ── 一覧で選んだだけのときは `—`(まだ読んでいない)です。

  🔑 **読めていないノートに日付やチェックを付けても、書いた情報は消えません**
  (2026-08-22 に直しました)。⚠ それまでは情報がもう 1 組**前に足され**、
  user が書いたタグは本文の側へ落ちていました ── しかも画面は
  「読めている」顔をするので、**いちばん気づきにくい形**でした。
  既に 2 組になってしまったノートは、**1 組目のタグをこれまでどおり出します** ──
  そのうえで「タグ」の行にマウスを乗せると、**本文の先頭にもう 1 組ある**と理由が出ます
  (本文の上に残っている `---` の行を消せば戻ります)。
  ⚠ **行の字では「壊れています」とは言いません** ── 本文を水平線で始めて
  `TODO: …` のような行を続けただけの**普通のノート**と、見分けが付かないためです。

  | 書くもの | 値 | 何が変わるか |
  |---|---|---|
  | `writing` | `horizontal`(既定)/ `vertical` | 縦書きにします |
  | `direction` | `ltr`(既定)/ `rtl` | 右から左へ流します(アラビア語・ヘブライ語)。縦書きでは**段の進む向き**(右起こし / 左起こし)になります |
  | `align` | `left` / `right` / `center`(縦書きは `top` / `bottom` / `center`) | **寄せの既定**(何も書かない段落がどこへ寄るか)を決めます |

  ⚠ **流れの起点と逆の `align`**(左から右の文書での `align: right` など)を書くと、
  `\|>`(全体の寄せの反対側)の寄る先も**反対に**変わります ──
  `align: right` の文書では、何も書かない段落は右へ、`\|>` は**左**へ寄ります
  (横書き・左から右の文書の場合)。`align: left` を書いても、流れの起点と同じ側なので
  `\|>` は右のままです。`align: center` の文書では `\|>` は**寄りません**
  (中央に反対側は無いので、何も起きません)。
  ⚠ この入れ替えが効くのは**行頭の記号**(`\|>` `<\|` `\|<` `>\|`)だけです。
  `:::paragraph{align=end}` / `{align=start}` のように**言葉で書いた指定**は
  入れ替わりません ── 書いたとおり(流れの終わり側 / 起点側)に出ます。
  🔑 記号は**絵**なので、向きを描き間違えても意図が通ります(だから 4 形が同じ意味です)。
  言葉の指定は書いたことがそのまま意味なので、寛容さがありません ── 別のものです。
  ⚠ `direction: rtl` を書くと、何も書かない段落は**右**(= 行頭)から始まり、
  `\|>` は**左**に寄ります。
  ⚠ 縦書き(`writing: vertical`)では `direction` は**段が右から並ぶか左から並ぶか**を
  決めます。本文はどちらでも**上から下**へ流れます。
  ⚠ 縦書きの `align: top` / `bottom` も効きます(上下は縦書きでの「行頭 / 行末」です)。
  `align: bottom` の文書では `\|>` は**上**へ寄ります(全体の寄せの反対側)。
- **添付参照** `![名前](asset:<key>)` ── 添付は**独立したノート**になります。本文から
  参照したいときは、その添付の画面に出ている **参照をコピー** を押して貼ってください。
  画像なら本文の中にそのまま出ます。画像以外は**ダウンロードのリンク**(`[名前](asset:<key>)`)
  になります。
  🔑 **音・動画は、その場で聞けます / 見られます**(2026-08-27 追加)── リンクの
  **隣に再生の器**が出ます。⚠ **名前のリンクはそのまま残る**ので、押せばこれまでどおり
  保存できます。⚠ **録音・画面収録で入った参照にも、手で添付した音・動画にも**効きます。
  ⚠ 中身は**開くまで読みません**(長い収録があるノートでも、開くのは重くなりません)。
  ⚠ **書き出した閲覧用 HTML でも同じように聞けます**。⚠ 紙には器を出しません
  (名前のリンクは紙にも残ります)。
  🔑 **スクリーンショットは、編集中の本文にそのまま貼れます**(`Ctrl/Cmd+V`)──
  この行が**カーソルの位置に自動で入ります**(→ §7-1)
- **外のサイトへのリンク** `[題名](https://…)` ── 押すと**新しいタブで開きます**。
  🔑 **`https://` から書いたアドレスは、そのまま書くだけでもリンクになります**
  (`[題名](…)` で囲まなくてかまいません)。
  🔴 **アドレスの後ろは、空白か句読点で区切ってください。**
  `…のURLをどうぞ` のように**字を空けずに続けると、そこまでリンクに入ります**
  (`をどうぞ` が行き先の一部になり、押しても開けません)。
  句点・読点・かぎかっこの手前では**リンクが終わります**。
  ⚠ **中黒(`・`)だけは URL の一部**として扱います
  (`https://ja.wikipedia.org/wiki/クロード・モネ` が途中で切れないようにするため)。
  `・` を区切りに使って `URL・つづきの文` と書くとやはり文まで飲むので、
  そこは `[題名](URL)` で囲んでください。
  ⚠ **裸のアドレスはリンクになりません** ── `www.example.com` や `github.com/…`、
  `README.md` / `console.info` のようなファイル名・識別子は、
  **書いたままの字で出ます**。🔑 リンクにしたいときは**頭に `https://` を付けます**。
  (`README.md` のような字を昔はリンクにしていましたが、`.md` も `.info` も
  実在する国・分野の名前なので、押すと**まったく関係のない他人のサイト**が
  開くことがありました)
  🔑 **メールアドレス**(`a@example.com`)は、そのまま書くだけで**メールの
  リンクになります**(押すとメールの画面が開きます)。
  ⚠ **`https://` の中に `user@` を書いたものは、`@` の手前で切れます**
  (`https://token@example.com/x` → `https://token` まで)。全体をリンクに
  したいときは `[題名](https://token@example.com/x)` と囲んでください
  ── 見た目が `https://本物.example@偽.example/` のように**別の宛先へ誘う形**に
  なりうるので、自動では 1 本にしません。
- **ノートへのリンク** `[題名](entry:<lid>)` ── 押すと**そのノートが開きます**。
  🔑 **書き方を覚える必要はありません** ── リンクしたいノートを開いて、
  右の列の **参照をコピー** を押し、書いている本文に**貼るだけ**です
  (貼れる 1 行がそのまま入ります)。
  ⚠ **題名は貼った時のものが残ります** ── 後でそのノートの題名を変えても、
  貼った字は変わりません(リンク先は変わりません)。直したいときは貼り直してください。
  ⚠ 開かないときは理由が画面の下に出ます(見つからない / 編集中 / 書き方が読めない)。
  ⚠ **編集中は移れません**(保存するか取り消してください)。⚠ PKC2 から取り込んだ
  本文の `entry:…#…`(見出しまで指す形)も、**そのノートまでは開きます**。
- **カード参照** `@[card](entry:<lid>)` ── ノートへのリンクを**カードの形**で置きます。
  いまは `@card` という札が出るだけで、押すとそのノートが開きます。
  ⚠ **キーボードでも押せます**(Tab で移動して Enter か Space)。
- **携帯参照** `[題名](pkc://<コンテナ>/entry/<lid>)` ── どの PKC のものかまで書く形です
  (PKC2 から取り込んだ本文に出てきます)。**いま開いている PKC あて**なら、
  ノートへのリンクと同じように押すと開きます。
  ⚠ **別の PKC あては押せない印**(参照先を書いた札)として出ます ── いまは開く手段が
  ありません。**いま開いている PKC の添付あて**(`pkc://<コンテナ>/asset/<key>`)は、
  押すと**その添付を持つノート**が開きます(見つからないときは理由が出ます)。

### 付箋を自由に置ける「板」

ノートをホワイトボードのように使えます。`:::format` の塊に **`.pkc-place`** と
座標を書くと、その塊が**書いた位置に置かれます**:

```
:::format{.pkc-place x=40 y=40 w=320 h=200}
### 買い出し
- 牛乳
:::
```

- **x= / y=** が左上からの位置、**w= / h=** が大きさ、**z=** が重なりの順です(単位は px)
- 塊の**右上の持ち手(⠿)を掴んで動かす**と、離した位置が本文の `x=` / `y=` に
  **書き戻されます** ── 位置の正本はあくまで**本文**です(板は別のデータを持ちません)
- `:::format{.pkc-place entry=ノートのID x=… y=…}` と書くと、**そのノートの題名の札**に
  なります。押すと本体が開きます(⚠ 中身は写しません ── 写すと正本が 2 つになるためです)。
  ノートの ID は、そのノートの「参照をコピー」で得られる `entry:` の**後ろの英数字だけ**です
  ── ⚠ **閉じ括弧 `)` は含めません**。題名の札にこだわらないなら、コピーした 1 行を
  **そのまま塊の中に貼る**だけでも、押せるリンクとして働きます
- ⚠ **付箋が座標に置かれるのは、読む画面だけ**です。編集の画面と書き出した HTML では、
  付箋は座標に置かれず**上から順に並びます**(座標を数字で直したいときは、そのまま本文を
  編集してください)。動かせる持ち手(⠿)も読む画面にだけ出ます

### 区切りと改ページ

| 書き方 | 画面 | 紙・PDF |
|---|---|---|
| `---` | 横の罫線 | 罫線のまま(ページは変わりません) |
| `+++` | 区切りの線 | **ここでページが変わります** |
| `:::break{kind=page}` | `+++` と同じ | `+++` と同じ |
| `:::break{kind=rule}` | `---` と同じ | `---` と同じ |

⚠ **Word(.docx)でも `+++` は改ページ**になります(→ §5)。

### 出す形式で本文を出し分ける

`:::if{format=…}` で囲むと、**その形式のときだけ**中身が出ます。

```
:::if{format=docx}
Word にだけ入れたい文
:::

:::if{format=html}
画面と閲覧用 HTML にだけ出したい文
:::
```

| 形式 | どこで一致するか |
|---|---|
| `html` | 画面・印刷・閲覧用 HTML(既定) |
| `docx` | **Word の書き出し**(→ §5) |
| `pptx` | **PowerPoint の書き出し**(→ §5) |

⚠ 一致しない塊は**空になります**(その場に理由は出ません ── 意図して分けた印なので)。

### この画面をそのまま印刷する

ブラウザの印刷(Ctrl+P など)で、**いま開いているノートの全文**が紙に出ます。
**PDF に保存**を選べば PDF になります。紙・PDF では:

- 左の一覧と右の情報は出ません(本文だけになります)
- 「編集」などの操作ボタン、コードのコピーボタン、切替のボタンは出ません
- 見出しがページの最後で独りにならないようにし、コード・表・引用・画像は途中で切りません
- `+++` の位置でページが変わります
- **紙の大きさは設定の「紙面」に従います**(A4 / A3 の縦横。→ §4-2)。
  画面用の紙面(フル HD / 4:3)を選んでいるときは指定しないので、
  お使いのブラウザの既定の紙で出ます

⚠ **書き出した閲覧用 HTML の印刷とは別です**。あちらは目次が本文の先頭に付き、
「全体を印刷」で全件を続けて刷れます(§5 の「目次と印刷」)。

## 4. 画面のならび

🔑 **どの列も、自分が扱うものの操作を自分で持ちます。** 探す・出す・消すの導線が
2 か所に散ることはありません。
⚠ 例外は**編集中の出口**だけです ── 中央の **保存** / **キャンセル** と同じものが、
追記欄の場所にも(**保存して解放** / **編集を破棄** として)出ます。追記できない
理由をそこで説明しているので、**その場から抜けられる**ようにしてあります(→ §2)。
どちらを押しても結果は同じです。

| 場所 | 扱うもの | そこにある操作 |
|---|---|---|
| 左の列 | ノート全体 | 探す・作る・入れる・出す・片づける + **集計** / **設定** / **フラグ** / **ヘルプ** |
| 中央 | いま開いているノート | **編集** / **保存** / **キャンセル** |
| 右の列 | 選んでいるノート | **書き出す** / **閲覧用 HTML** / **Word** / **PowerPoint** / **PDF** / **履歴** / **削除** |

左の列のいちばん下に、ノート全体に対する操作が並びます。
⚠ ここだけは**図案を出しません** ── 7 つを狭い列に並べると、図案の分だけ段が増えて
一覧の高さを取るためです(**ボタンは 7 つとも在ります**)。

| 操作 | 何が起きるか |
|---|---|
| **取り込む** | PKC2 の書き出し・Markdown・連絡先(.vcf)を読み込みます |
| **バックアップ** | 元に戻せる形で保存します(→ §5) |
| **集計** | 本文の先頭に書いた項目でノートを束ねて数えます(→ §4-5) |
| **設定** | 見た目や、外へ何が伝わるかの判断(→ §4-2) |
| **フラグ** | 開発中の切り替え。いつか畳まれます(→ §4-3) |
| **ヘルプ** | 版・これまでのお知らせ・このマニュアル(→ §4-4) |

**閲覧用 HTML** / **持ち歩ける 1 枚** / **Markdown** / **構成をコピー** / **使っていない添付を消す** は、**設定**の中の
**書き出しと片づけ**に在ります(→ §4-2)。よく押すもの(取り込む・バックアップ)だけを
左の列に残し、**配るときと片づけるときにだけ使うもの**はそちらへ移しました。

⚠ **集計**だけは**編集中は開けません**(ノートを並べる面なので、開くと
書きかけの本文が画面から消えるためです)。保存するか取り消してから開いてください。
⚠ 下の 3 つ(**設定** / **フラグ** / **ヘルプ**)と、アプリの **2 ペインで整理** は
**編集中でも開けます**。寄り道して戻っても、打ちかけの本文も取り消し(Ctrl+Z)も
そのまま残ります ── 書きながらマニュアルを読んだり、置き場を眺めたりするためです。
⚠ ただし**別のノートに移ることはできません**(保存するか取り消してください)。
⚠ **2 ペイン**で**実際に移す**のは編集中はできません ── 押すと理由が出ます。

### 4-0. 列の大きさを変える・畳む

**列と列のあいだ、そして追記欄の上に、細い帯があります。** これが大きさの
つまみです。

| したいこと | どうするか |
|---|---|
| **幅を変える**(左の列 / 右の列) | 帯を**掴んで左右へ動かします** |
| **追記欄を大きくする** | 追記欄のすぐ上にある帯を**掴んで上へ動かします** |
| **畳む**(消す) | 帯を**押します**。もう一度押すと戻ります |
| **キーボードで** | 帯に `Tab` で移り、**矢印キー**で動かします(`Enter` で畳む・戻す) |

🔑 **小さくしすぎると畳まれます。** そのときも**帯は残る**ので、押せば
**元の大きさで**戻ります ── 戻せない状態にはなりません。
🔑 **決めた大きさは覚えます。** 次に開いたときも同じならびです。
設定の**設定を持ち出す**(→ §4-2)にも入るので、別の端末へ移せます。

⚠ **中央(本文)は畳めません。** 操作子の置き場であり、1 画面で完結させる本体だからです。
⚠ **画面が狭いときは自動のならびが優先されます** ── 手で決めた幅は、
画面がその幅より狭くなると自動で縮みます(はみ出して本文が消えることはありません)。
⚠ 幅を変えている間、本文の図は焼き直しません。**離したときに 1 回**だけ組み直します。

### 4-0b. 目次(見出しから自動で出ます)

**見出し(`#` / `##` / `###`)を書くと、右の情報ペインに「目次」の行が出ます。**
押すと、本文のその見出しまで移動します。

- 🔑 **書かなくても出ます** ── 本文に `:::toc` と書く必要はありません
  (書けば**本文の中にも**出せます → §3)
- ⚠ **見出しのないノートでは、この行ごと出ません**(押せる物がないため)
- ⚠ **1 面で編集している間は移動できません**(本文が表示されていないため)。
  押すと理由が出ます。2 ペイン(→ §4-2)なら編集中でも移動できます
- 🔑 **集計やフォルダの面からでも、1 回の押しで飛びます** ── 本文の面へ戻り、
  描き直しが終わるのを待ってから移動します(⚠ 待っても出てこないときだけ理由が出ます)
- 🔑 書き出した閲覧用 HTML にも、前から目次が出ています(→ §5)

### 4-1. 開いたときの画面を指定する(アドレスの `#pkc?view=`)

いつも集計から始めたい、といったときは、**アドレスの末尾に付け足して**
ブックマークしておけます。

```
https://…/PKC3/#pkc?view=query
```

| 付ける字 | 開く画面 |
|---|---|
| `detail` | 本文 |
| `query` | 集計 |
| `dual` | 2 ペインで整理 |
| `settings` | 設定 |
| `flags` | フラグ |
| `help` | ヘルプ |

🔑 **`calendar` / `kanban` と書いてあった古いブックマークも、そのまま使えます。**
左の列の **予定**(→ §2-6)を開いて、どこへ移ったかを画面の下に出します。

⚠ `detail` は**書かなくても同じ**です(何も足さないと本文の画面で始まります)。

🔑 **その画面を見ている間は、アドレスに字が残ります。** だから開いた状態のまま
**ブックマーク**(`Ctrl+D`)すれば、次からその画面で始まります。読み直し(`F5`)
しても同じ画面のままです。
🔑 **別の画面へ移ると、そのとき字が消えます。** ですので、本文を読み始めたあとに
更新が入って読み直しが起きても、勝手にその画面へ戻されることはありません。

⚠ **開いたままの PKC のアドレス欄に足したときも効きます。** 読み直しは要りません。
⚠ 面の名前を間違えると、本文の画面で開いて**画面の下に理由が出ます**
(そこに書ける名前が並びます)。

⚠ **アプリとして入れた窓では使えません。** インストールした PKC(→ §1)の窓には
アドレス欄が無いためです。ブラウザのタブで開いたときにお使いください。

⚠ **アドレスに書けるのは、上の `view` だけです。** 開発中の切り替えは
**フラグの画面**(→ §4-3)で入り切りします ── アドレスに書くものではありません。

### 4-2. 設定

左の列のいちばん下の **設定** から開きます。画面は 6 つに分かれています ──
**表示**(見た目の好み)/ **書き出しと片づけ**(配るとき・片づけるとき)/
**ショートカットキー**(キーの割り当て)/
**外部の画像**(外へ何が伝わるかの判断)/ **Office 表示**(この端末に置くかどうか)/
**処理**(読むだけの計器)です。

#### 表示

##### 配色

配色を選べます。**ライト** / **ダーク** / **GitHub** /
**GitHub ダーク** / **Solarized** / **Solarized ダーク** / **Dracula** /
**Nord** / **端末** の 9 つ。
⚠ 最初は **OS の設定に従います**。一度選ぶと、この端末ではそちらを覚えています。

##### 紙面

**本文の読み幅**と、**印刷したときの紙の大きさ**を選べます。

| 選ぶもの | 本文の読み幅 | 印刷の紙 |
|---|---|---|
| **A4 縦**(最初はこれ) | 42rem(全角 約 51 文字) | A4 縦 |
| **A4 横** | 62rem | A4 横 |
| **A3 縦** | 62rem | A3 縦 |
| **A3 横** | 91rem | A3 横 |
| **フル HD(16:9 横)** | **上限なし**(画面の幅いっぱい) | 指定しません(お使いのブラウザの既定) |
| **フル HD 縦(9:16)** | 64rem | 同上 |
| **4:3 横** | 60rem | 同上 |
| **4:3 縦** | 45rem | 同上 |

- 上限が掛かるのは**散文**(段落・見出し・箇条書き・引用・注意書きなど)だけです。
  **表・図・コード・添付は、どの紙面でも幅いっぱい**のままです。
- 読む面・添付の説明・編集のプレビュー・1 面のライブエディタは**同じ幅**で出ます。
- 書き出した閲覧用 HTML には、**書き出したときの紙面**が焼かれます(→ §5)。
- ⚠ ヘルプ(この画面)は紙面の対象外です。
- 一度選ぶと、この端末ではそちらを覚えています。**A4 縦**を選べば元に戻せます。

##### 文字の大きさ

本文と画面の**字の大きさ**を選べます。**小 / 標準 / 大 / 特大** の 4 つで、
最初は **標準**(これまでと同じ大きさ)です ── 選ばなければ見え方は変わりません。

- **押すとその場で効きます**(読み込み直さなくても変わります)
- 🔑 **読み幅(1 行の長さ)は動きません** ── 大きくすると、1 行に入る字が減ります
  (段が広がるのではなく、字が大きくなります)
- 一度選ぶと、この端末ではそちらを覚えています。**標準**を選べば元に戻せます
- ⚠ ブラウザ自体の拡大(`Ctrl` + `+`)とは別物です。あちらは画面ごと拡大しますが、
  こちらは**字だけ**が変わります

##### 本文の段組み(ウルトラワイド向け)

横に広い画面で、**本文を新聞のように段へ流して**読めます。
**1 段(最初はこれ)/ 2 段 / 3 段 / 4 段** から選べます。

1 段のままなら、これまでと 1 バイトも同じ見え方です。

- 🔑 **送りが横向きになります。** マウスホイールは**そのまま(縦に回して)**
  横へ送れます ── 持ち替える必要はありません
- 🔑 **画面の幅が足りないときは、自動でふつうの縦送りに戻ります。**
  段が読めない細さ(1 段あたり全角 34 文字ぶん)を下回ると、段組みを止めます。
  ⚠ 設定が消えるわけではありません ── 広い画面で開けばまた段になります
  - 🔑 **やめたときは、画面下の帯に理由が出ます** ──
    「**幅が足りないので段組みをやめました**」と、**何 px あれば戻るか**が出ます。
    広げて戻ったときは「**段組みに戻しました**」と出ます
  - ⚠ **自分で段数を選んだときは出ません**(そちらは選んだ結果だけが出ます)
- ⚠ **表と図は段の幅まで縮みます。** 段を増やすほど狭くなるので、
  表を広く見たいときは**段を減らして**ください
- 🔑 **段と段のあいだの線は、濃さを選べます。** 設定の **段の境界線** で
  「細い(既定・いまと同じ)/ はっきり / 線なし」から選べます。
  見分けにくいときは「はっきり」にしてください
- ⚠ **本文が短いと、右側に空きが出ることがあります。** 段は選んだ数だけ作られますが、
  中身が足りないと最後の段が空になり、**そこには線が引かれません**(CSS の決まりです)
- 🔑 **縦に長い図や写真は、段の高さに収まるまで小さくなります。**
  はみ出して下が切れることはありません(切れると、横送りになっているぶん
  **見えない所へ届く手段がありません**)。⚠ 小さくて読めないときは、
  **段を減らす**か、1 段に戻してください
- 🔑 **段組みのまま書き替えられます。** 読んでいる本文を
  **Ctrl(mac は Command)+ クリック**すると、その行だけが原文になります ──
  **段は解けません**。打っている箱は段の高さで止まり、超えた分は箱の中で送れます
  - ⚠ **箱が段の下のほうで開いたときだけ、次の段のいちばん上へ 1 度だけ移ります。**
    箱は途中で割れないので、段の残りに入らなくなるとまるごと移ります。
    そのあとは打っても動きません
  - ⚠ **2 ペインの編集(設定で選んだとき)は段になりません** ── あちらは
    本文まるごと 1 枚を書く画面なので、段へ流す形がありません
- 一度選ぶと、この端末ではそちらを覚えています。**1 段**を選べば元に戻せます
- 🔑 **読みながら切り替えられます。** `Alt+C` を押すたび **1 段 → 2 段 → 3 段 → 4 段**
  と回り、画面の下に**いま何段で出ているか**が出ます
- ⚠ **選んだ数どおりにならないことがあります。** 1 段の細さには下限(全角 約 34 文字)が
  あるので、画面が狭いと**入る数まで減ります** ── たとえば横 1200px ほどの器では、
  **2 段・3 段・4 段のどれを選んでも 2 段**になります。
  🔑 そのときは設定画面と `Alt+C` の両方が「**いまの画面では 2 段で出ています
  (3 段には 1376px 以上の幅が要ります)**」と言います。
  ⚠ **選んだ数は消えません** ── 広い画面で開けばそのとおりに出ます

##### 編集の仕方

編集画面の形を選べます。**1 面で編集(ライブ)**(最初はこれ)と
**2 ペイン(原文とプレビュー)** の 2 つです。
切り替えは、**次に編集を開いたときから**効きます(開いている編集はそのままです)。
一度選ぶと、この端末ではそちらを覚えています。

##### このアプリのデータ

ここは**選ぶところではなく、知らせるところ**です。ブラウザがこのアプリのデータを
**消さない扱いにしているか**が 1 行で出ます。

| 出る文 | 意味 | やること |
|---|---|---|
| **消さない扱いにしています** | 空き容量が減っても、このアプリのデータは残ります | ── |
| **消すことがあります** | 空き容量が足りなくなると消えることがあります | **ホーム画面(デスクトップ)に追加**すると、消さない扱いになることがあります |
| **対応していません** | このブラウザにその仕組みがありません | **バックアップを定期的に**(→ §5) |
| **まだ確かめていません** | 起動した直後です | 何か 1 つ保存すると確かめます |

🔑 **頼むのは、最初に何かを保存したときです。** 起動しただけでは頼みません ──
まだ何も書いていないうちに聞かれても、断る理由しかないからです。

⚠ どの状態でも、**バックアップ(`.pkc3.zip`)がいちばん確実**です(→ §5)。

##### お知らせ

**起動したときに新しいお知らせを出す**かを選べます(最初は出します)。
⚠ お知らせの帯の **今後は出さない** を押したときも、ここから戻せます。
⚠ 出さなくても、**過去のお知らせはヘルプから読めます**(→ §4-4)。

#### 外部の画像

本文に `![絵](https://…)` と書かれた画像や、`html` ブロックの中の画像を
**読み込むかどうか**を選びます。

| 選択肢 | どうなるか |
|---|---|
| **常にオン** | いつでも読み込みます |
| **常に確認**(既定) | 読み込まずに置き、ノートごとに聞きます |
| **常にオフ** | 読み込みません(聞きません) |

🔴 **読み込むと、相手のサーバーに「この端末がいまこれを開いた」ことが伝わります。**
画像の中身が見えなくても伝わります(1×1 の透明な画像でも同じです ── いわゆる
追跡用の画像)。本文は人からもらったものや AI が書いたものでもあるので、
書いた本人が意図していないこともあります。

**常に確認** のときは、外部の画像があるノートを開くと本文の上に帯が出ます。
**このノートで読み込む** / **読み込まない** のどちらかを押してください。
答えは**タブを閉じるまで**覚えます(ノートごとです)。

⚠ 読み込んでいない画像は、**破線の四角**として置かれます(消えたのではありません)。
⚠ 設定を変えると、ノートごとの答えは**消えます**。
⚠ **書き出した HTML に画像が入るのは「常にオン」のときだけ**です。書き出した
   ファイルは別の人が開くものなので、既定では入れません(URL は残っているので、
   後から取り出せます)。
⚠ 図(mermaid)は手元で描いているので、外へは何も出ません。

##### HTML の囲みで、画像以外が止まったとき

`html` の囲みの中身は**外の物を何も読み込めません**。画像だけは本文の上に出る帯で
「このノートで読み込む」を選べますが、**外にあるプログラム(JavaScript)・
見た目(CSS)・通信・入れ子のページ**は選べません ── どれも中身を
そのまま実行することになるためです。

止まったときは、本文の下に**何が止まったのか**が出ます。出ないまま真っ白に
なることはありません。

🔑 **どうしても動かしたいとき**は、その HTML を**ファイルとして添付**し、
添付の画面で **「アプリとして登録」** を押してください。アプリは別の窓で開くので、
外から取ってこられます(→ §7-3「アプリ」)。

#### Office 表示

Word / Excel / PowerPoint の添付を、**別の窓で開いて読める**ようにします(→ §7-4)。
そのために、**約 77MB のひとそろい**をこの端末に入れます。
一度入れれば、次からは**この端末の中から**起動します(毎回ダウンロードしません)。

| 押すもの | どうなるか |
|---|---|
| **取得して入れる** | 配布元(PKC3 と同じ場所)から取って入れます |
| **ファイルから入れる** | 手元の `lo-wasm-qt6.zip` を選んで入れます |
| **削除** | この端末から消します(ノートや添付は消えません) |

⚠ **勝手に取りに行きません。** 押した人にだけ入ります。
⚠ 入れている間は、進み具合が 1 行で出ます。終わるまで**入れる導線は押せません**。
⚠ **ファイルから入れる**は保険ではありません ── 配布元に届かない場所で PKC3 を
   開いているときは、これが唯一の道です。
⚠ 入っていても、**この環境で動くか**は別です。設定の 2 行目に
   「この環境では動きます / 動きません」と出ます。動かない場合は
   足りないもの(**JSPI** など)を名指しします。いまのところ Chrome / Edge など
   Chromium 系でだけ動きます(→ §7-4)。

#### 処理(ワーカー)── 開発者向け

重い処理(markdown の描画・添付の展開とハッシュ・グラフ・**Word の組み立て**)は
**別スレッド**で動きます。しばらく使われないと
自動で終了し、次に必要になったら作り直します。この画面で、いま動いているか・
待っている件数・1 件あたりの時間・直近のログが見られます。
⚠ ここに**変えられるものはありません**(読むだけです)。
⚠ ログに本文の中身は出しません(**文字数だけ**)。

### 4-3. フラグ

左の列のいちばん下の **フラグ** から開きます。ここは **開発中の切替**で、
設定とは分けてあります。

| | 設定 | フラグ |
|---|---|---|
| 誰のもの | あなた | 開発者・詳しい方 |
| 約束 | 正式な機能。消えません | **いつか畳まれます**(条件を各行に書いています) |

畳まれるとき、その切替は消えて、**中身は正式な機能か既定の挙動のどちらか**になります。
いま何も並んでいなければ、切り替えられるものがまだ無いということです。

うまく動かなくなったら **すべて既定へ戻す** を押してください。
一部の切替は**起動のときに決まる**ため、押すと**読み込み直します**
(そう書いてある行がそれです)。

`?pkc-flag=名前` を URL に付けると、**保存せずに**その場だけ試せます
(URL を外せば元に戻ります)。その間もその行は**押せます** ── 押すと保存して
読み込み直し、URL の指定は落ちます。

### 4-4. ヘルプ

左の列のいちばん下の **ヘルプ** から開きます。4 つが並びます。

| | 中身 |
|---|---|
| **この版** | いま動いている PKC3 の版(不具合の報告に添えてください) |
| **これまでのお知らせ** | 過去のお知らせを新しい順に、最大 10 件 |
| **ショートカットキー** | いま効いているキーの一覧(割り当て直すのは設定です) |
| **マニュアル** | このマニュアルの全文 |

⚠ マニュアルは**アプリの中に入っています** ── オフラインでも読めますし、
**いま動いている版のマニュアル**が必ず出ます(外のページを見に行きません)。
⚠ **編集中でも開けます**。戻れば打ちかけはそのままです。

### 4-5. 集計(項目ごとに束ねて数える)

左の列の **集計** から開きます。**本文の先頭に書いた項目**でノートを束ね、
値ごとに何件あるかを出す面です。

書き方は、本文のいちばん上を `---` で囲むだけです。

```
---
author: 佐藤
status: 未着手
tags: [設計, 実装]
---

ここから本文
```

こう書いたノートが何件かあると、**束ね方**に `author` / `status` / `tags` が
出てきます。選ぶと、その項目の値ごとにノートが束ねられます。

| | 何が起きるか |
|---|---|
| **束ね方** | 何で束ねるかを選びます。⚠ 一覧に出るのは**実際に書かれている項目**だけです |
| **数え直す** | 書き換えたあとの中身で数え直します(自動では数え直しません) |
| 組の見出し | 値と件数。押すと畳めます |
| 組の中の行 | ノートです。押すと**選ばれます**(面はここに留まります ── 本文は右の列と、面の切替 1 回で見られます) |

⚠ `tags: [設計, 実装]` のように**並べて書いた値**は、**どちらの組にも入ります**
(1 件のノートが 2 つの組に数えられます)。
⚠ その項目を書いていないノートは **(未設定)** の組にまとまり、**いちばん下**に出ます。
⚠ 数がとても多いときは上から順に切ります。切ったときは
「あと N 組」のように**画面に出します**(黙って減らしません)。
⚠ **編集中は開けません**(保存するか取り消してから開いてください)。

### 4-6. 🔴 組み込みアプリは**別の窓**で開きます

**2 ペインで整理**(→ §4-7)は、**左の列の「アプリ」タブ**から押すと **別の窓**で
開きます(Office と同じ形です)。

🔑 **読んでいた本文はそのまま残ります。** 本文を見ながら整理する、といった
使い方ができます。⚠ 以前は真ん中が入れ替わり、**本文が消えていました**。

🔑 **予定は「アプリ」ではありません。** 日付を見るのは**ノートの見方**なので、
別の窓ではなく**左の列の「予定」タブ**に出ます(→ §4「予定」)── 開いても
真ん中の本文は消えません。⚠ 以前は「カレンダー」「やることの板」というアプリでしたが、
2026-08-23 にこちらへ移しました。

- **窓はいくつでも開けます。** 同じアプリをもう一度押すと、もう 1 枚開きます
- ⚠ **ブラウザが新しい窓を塞いだとき**は、これまでどおり**この画面で開き**、
  画面の下に理由が出ます。別の窓で使いたいときは、ブラウザのポップアップの許可を
  出してください。⚠ **アプリとして入れた PKC**(→ §1)にはアドレス欄が無いので、
  許可はブラウザの**サイトの設定**から出します(アドレス欄の錠前ではありません)
- 🔑 **帰り道は、面の上の × 閉じる** です ── **別の窓なら窓ごと閉じます**
  (この画面で開いたときは、本文へ戻ります)
- 🔑 **窓の題名にその面の名前が入ります**(「2 ペインで整理 — PKC3」)── タスクバーに
  何枚並んでも見分けられます
- 🔑 **読んでいたノートは連れて行きます** ── その窓でも同じノートが選ばれています
- 🔑 アドレスに `#pkc?view=…` を付けて開いても、**この画面で**その面が出ます
  (→ §4-1)── ブックマークから始めたいときはこちらです

### 4-7. 2 ペインで整理する(アプリ)

**左の列の「アプリ」タブ**を開いて、**2 ペインで整理** を押します
(⚠ **別の窓**で開きます → §4-6。**Alt + 6** ならこの画面で開きます ──
⚠ ただし**打っている最中は止まります**。打鍵中にも鍵で開きたいときは、設定で
文字を打たない鍵に割り当ててください)。

**別の場所を左右に開いて、間でまとめて移す**ための面です。左の列の **フォルダ**
タブ(→ 下)は片手間の整理に使い、こちらは「腰を据えて片づける」ときに開いてください。

| | 何が起きるか |
|---|---|
| 行を 1 回押す | **選びます**(押した側が「移す元」になります) |
| **Ctrl**(mac は **Cmd**)を押しながら | 選ぶものを**足す・外す** |
| **Shift** を押しながら | 前に押した行からそこまでを**まとめて選ぶ** |
| フォルダを 2 回押す | **その側だけ**が中へ入ります(反対側は動きません) |
| **ルート** / フォルダ名(上のならび) | その場所へ戻ります |
| **タブ**(上のならび) | 押すとそのタブへ切り替わります(場所も、選んでいたものも、そのタブのものに戻ります) |
| **+**(タブの右) | いまの場所を、もう 1 枚のタブで開きます |
| **×**(タブの中) | そのタブを閉じます(最後の 1 枚は閉じられません) |
| 下の **F5 写す** / **F6 移す** | 選んだものを、**反対側がいま開いている場所**へ写す / 入れる |

**操作は画面のいちばん下に、いつも同じ順で並んでいます。**
**F5 写す / F6 移す / F2 名前 / F7 フォルダ / Shift + F4 ノート / F8 ゴミ箱 / F9 下見** ──
書いてある鍵がそのまま効きます(割り当てを変えると、**書いてある字も一緒に変わります**)。

🔑 **どちらが「元」かは、上のタブの帯の色と、下の件数の行で分かります。**
元になっているペインは帯がうっすら濃くなり、件数の行に **(ここが元)** と出ます。
行でもタブでもパンくずでも、**そのペインの中を押せば**元がそちらに移ります。

**列は押すと並べ替わります。** **名前 / 大きさ / 更新** の見出しを押すと
その列で並び、**もう一度押すと逆順**になります(▲▼ でどちら向きか分かります)。
⚠ 並び順は左の一覧と同じものです ── 片方で変えると、もう片方も同じ並びになります。
⚠ **大きさは本文の文字数**です。フォルダは **—** と出ます(中に何文字あるか、ではありません)。

**キーボードだけで動かせます。** 行を 1 回押せば、あとはマウスに戻らずに続けられます。

| 鍵 | すること |
|---|---|
| **↑ ↓** | **カーソル(枠)だけ**を送る(印は動きません) |
| **Space** / **Insert** | カーソルの行に**印を付ける・外して 1 行下へ**(飛び飛びに選べます) |
| **Shift + ↑ ↓** | そこまでまとめて選ぶ |
| **Ctrl + A** | そのペインの全部を選ぶ |
| **Enter** / **F3** | フォルダなら中へ入る / ノートなら開く |
| **Backspace** | 親のフォルダへ戻る |
| **Tab** | 反対のペインへ移る |
| **F2** | 名前をその場で打ち替える |
| **F5** | 反対のペインへ写す |
| **F6** | 反対のペインへ移す |
| **F7** | いまの場所にフォルダを作る |
| **Shift + F4** | いまの場所に**ノート**を作る |
| **F8** / **Delete** | ゴミ箱へ入れる |
| **F9** | 下見を出す / しまう |
| **Alt + ←** / **Alt + →** | そのタブが 1 つ前に見ていた場所へ戻る / 進む |

⚠ **フォルダもノートも、作っても本文の面へは移りません** ── 作ったものは
**その場に出ます**。整理を続けたいのに面から放り出される、を作らないためです。
名前は **F2** でその場で打ち替えられます。

🔑 **印が 1 つも無いときは、カーソルの行が相手になります。**
矢印で目当ての行まで下りて、そのまま **F6** で構いません ── わざわざ印を付けなくても動きます。

⚠ 入るのは**押したペインだけ**です(反対側と左の一覧は動きません)。
⚠ 空のフォルダに入っても、キーは効いたままです。
#### 🔑 場所の道具(現在地の並びにあります)

現在地(パンくず)の**左右**に、場所を扱う道具が並んでいます。

| 何 | すること |
|---|---|
| **◀ ▶** | そのタブが**1 つ前に見ていた場所**へ戻る / 進む(**Alt + ←** / **Alt + →**) |
| **名前で絞る**(欄) | **そのペインだけ**を名前で絞ります(左右で別の語を打てます) |
| **☆ / ★** | いまの場所を**留める** / 留めを外す |

⚠ **◀ ▶ はタブごと**です ── タブを切り替えたら、そのタブが辿った場所に戻ります
(別のタブで見ていた場所へ飛んだりしません)。
⚠ **絞る欄は左右で別**です。空にしておけば、これまでどおり左の一覧の絞り込みが効きます。
⚠ 絞る欄で **↓** か **Enter** を押すと、そのまま**行へ降りられます**。**Esc** で絞りが解けます。

**留めた場所は、現在地の下に帯で並びます。** 押すとその場所へ移り、**×** で外せます。
⚠ **ルートは留められません**(パンくずの左端からいつでも 1 押しで戻れるため)。
⚠ 留めた場所は**この端末に憶えます**(ノートの中には入りません)。
⚠ 留めたフォルダを消しても帯には残ります ── **×** で外してください
(消えたものが帯から見えなくなると、外しようがなくなるためです)。

#### 🔑 下見(開かずに中身を確かめる)

いちばん下の **F9 下見** を押すと、ペインの下に**カーソルの行の中身**が数行出ます。

⚠ **既定では出ません** ── 下見は本文を読みに行くので、要るときだけ出してください。
⚠ 一度出しておけば、**次に開いたときも出たまま**です(この端末に憶えます)。
⚠ フォルダを指しているときは何も出ません(フォルダに本文はありません)。
⚠ 長い本文は途中まで(末尾に **…** が付きます)── 全部読むなら本文の面で開いてください。

#### 🔑 情報行には合計も出ます

いちばん下の行に「**4 件中 1 件を選択 · 100 / 120**」のように出ます。
右側の数は**本文の文字数**で、「選んだぶん / 全体」です。

⚠ フォルダは数えません(本文を持たないため)── フォルダしか無い場所では合計は出ません。
⚠ **+** が付いていたら、まだ数えていない行が混ざっています(古いビルドで作ったノート)。
⚠ **—** は「1 つも数えられていない」という意味です(0 文字ではありません)。

**整理の操作も、この面から届きます。**

- **ゴミ箱へ** ── そのペインで選んだものを消します(**Delete** でも同じです)。
  戻せます。⚠ 左の一覧で選んでいたものは**巻き込みません**(画面に出ていないものは消しません)。
- **写す** ── そのペインで選んだものを、**反対側の場所へコピー**します(元は残ります)。
  ⚠ **フォルダを選ぶと中身も一緒に写ります**(中の入れ子もそのままの形で付いてきます)。
  ⚠ 同じ場所へ写したときだけ、名前のうしろに **のコピー** が付きます
  (別の場所なら名前は変わりません)。
- **名前を変える** ── 選んだ 1 件の名前を、**その場で打ち替え**ます(**F2** でも同じです)。
  Enter で確定、Esc でやめます。他所を押しても確定します。
  ⚠ まとめて名前を変えることはできません(同じ名前が並ぶだけなので、1 件ずつです)。
- **新しいフォルダ** ── そのペインが**開いている場所**に作ります。
  ⚠ 編集には入らないので、そのまま整理を続けられます。

**掴んで落とせます。** 行を掴んで、反対のペインへ落とすとそこへ移ります。

| 落とす先 | どこへ入るか |
|---|---|
| ペインの**地**(行の無いところ) | そのペインが**いま開いている場所** |
| **フォルダの行** | **その中** |
| **ノートの行** | そのペインが**いま開いている場所**(行の上で離しても捨てません) |

⚠ 掴んだ行に印が付いていれば、**その印ごと**運びます(付いていなければ掴んだ 1 件だけです)。
⚠ 運ぶのは**掴んだペインの印**です ── 反対側や左の一覧で選んでいたものは巻き込みません。
⚠ 落とせるところに来ると、そこが光ります。光っていないところで離しても何も起きません。

⚠ タブは 1 つのペインにつき **12 枚**までです。上限に達すると **+** は消え、
「タブは 12 枚までです」と出ます(押しても何も起きないボタンは置きません)。
⚠ 何も選ばずに押すと、**移すものを選んでください** と出ます(黙って何も起きない、
ということはありません)。
⚠ フォルダを**自分の中**へは入れられません ── 一部だけ断られたときは件数を、
ぜんぶ断られたときは「そこへは入れられません」と出します。
⚠ 左の列の **探す** と **並び順** は、この面にも効きます。語を打ったまま開くと
両側とも絞り込まれた結果が出るので、何も出ないときは探す欄を確かめてください
(そのときは「探している語に当たるものが、ここにはありません」と出ます)。
⚠ ここでの選択は、**左の列の選択とは別のもの**です(左右それぞれが自分の分を持ちます)。

### 種類で絞る(札を押す)

一覧に**種類の札**(`ノート 16` / `フォルダ 3` / `添付 12` のような形)が出ます。
押すとその種類だけになり、絞っている間は **解除** が出ます。

- ⚠ 札は**種類が 2 つ以上あるとき**だけ出ます(1 つしか無いなら押しても変わらないため)
- ⚠ 数は「**その種類だけにしたら何件になるか**」です ── 押す前に分かります
- **札が出るのは、種類の絞りが効く探し方だけ**です(**一覧 / フォルダ / 予定**)。
  ⚠ **連絡先・アプリでは出ません** ── そこでは絞れないので、
  押しても何も起きない札を置かないためです

### 行を右クリックする(できることが、その場に出る)

一覧やフォルダの**行を右クリック**すると、そのノートにできることが出ます。

| 出るもの | 何が起きるか |
|---|---|
| **参照をコピー** | 本文に貼れる 1 行(`[題名](entry:…)`)を写します |
| **素の Markdown** | 方言記法を落とした Markdown を写します |
| **書き出す** | このノートだけをバックアップ形式(`.pkc3.zip`)で保存します |
| **閲覧用 HTML** | このノートを、ブラウザで開くだけで読める 1 枚の `.html` にします。**PKC3 を持っていない相手にも渡せます**(片道) |
| **履歴** | このノートの履歴を開きます |
| **削除** | ごみ箱へ入れます(戻せます) |

- ⚠ **これまでのボタンや帯はそのまま残っています。** 右クリックは**近道**であって、
  唯一の口ではありません(同じ操作は情報ペインからも押せます)
- ⚠ **本文のリンクや図の上では、これまでどおりブラウザのメニューが出ます**
  ──「リンクをコピー」「画像を保存」が消えないようにするためです
- **閉じ方**: `Escape` / 外を押す / 画面を送る。閉じると、開く前に居た場所へ戻ります
- ⚠ **編集中は出ません。** 編集を終えてからにしてください、と画面の下に出ます
  (右クリックした行を先に選ぶ必要があり、編集中はその選択が断られるためです)

### 探し方を変える(左の列の上のタブ)

| タブ | 何が並ぶか |
|---|---|
| **一覧** | 全部のノートを並べます(絞り込みが効きます) |
| **フォルダ** | フォルダの階層をたどります(ゴミ箱もここ) |
| **アプリ** | 「アプリとして登録」した添付を並べます(→ §7-3) |
| **予定** | 日付を書いた項目を、日ごとに並べます(→ 下の「予定」) |
| **連絡先** | 電話やメールを書いたノートを並べます(→ 下の「連絡先」) |

⚠ **タブは畳みません。** 画面が狭くて 5 枚が 1 行に入らないときは、**折り返して 2 行**に
なります ── どの幅でも 5 枚とも押せます(字が隣に重なることはありません)。

### 連絡先(左の列のタブ)

ノートの**先頭**に `tel:` か `email:` を書くと、そのノートが**連絡先**として並びます。

```
---
tel: 090-1234-5678
email: taro@example.com
org: 例の会社
---

# 山田太郎

打ち合わせは水曜が空いているとのこと。
```

| 押すと | 何が起きるか |
|---|---|
| **名前** | そのノートを中央に開きます(左の列はそのまま) |
| **電話番号** | 端末の電話に渡します(かけられる端末なら発信の画面になります) |
| **メール** | メールの下書きが開きます |

- **名前は題名です。** `name:` は要りません ── 名前の出どころが 2 つになると、
  一覧と連絡先で違う名前が出ることになるためです
- **電話もメールも、いくつでも書けます**(`tel:` の下に `- 090-…` と並べます)
- **`org:` だけでは並びません** ── 連絡先とは「連絡できる」ものなので、
  電話かメールが 1 つ以上要ります(所属だけ書いた議事録が並ばないためです)
- ⚠ **数字が 1 つも無い電話・`@` の無いメールは、字のまま出ます**(押せません)
- ⚠ **電話とメールを、それぞれ 8 つまで並べます。** それより多いときは
  「ほか N 件」と出ます(電話とメールの合計です)── 全部はノートを開くと
  見られます(書き出す `.vcf` には**全部入ります**)
- ⚠ **タブを開いたときに集めます。** ノートが多いと少し待ちます ──
  開かない人には走らせません

#### vCard で出し入れする(.vcf)

- **取り込み**: スマホや他のアプリから書き出した `.vcf` ファイルを、左の列の下の
  **「取り込む」**から選びます。**1 枚が 1 ノート**になり、電話・メール・所属は
  ノート先頭の囲み(`tel:` / `email:` / `org:`)に、誕生日は `birthday:` に入ります
  - ⚠ 写せない項目(住所など)は**本文の行として残ります**(黙って捨てません)。
    ⚠ **読める字**で残ります(「住所(自宅): 渋谷1-2-3 渋谷区 東京都 150-0001 日本」)──
    `.vcf` の生の書き方のままにはしません。
    **写真・音・鍵など、中身が符号化されたものだけは取り込めません**
    (そのときは注意が出ます ── 数十 KB の 1 行が本文に入ると、そのノートが
    編集できなくなるためです)。⚠ **写真でも URL で書かれているものは残ります**
  - 複数の `.vcf` をまとめて選べます。名前の無いカードには「連絡先 N」と名前が付きます
  - ⚠ **中身が何も無いカードは飛ばします**(空のノートを作りません)。
    文字が壊れている `.vcf` では「文字が壊れている所がありました」と注意が出ます ──
    名前が黙って化けたまま入ることはありません
  - ⚠ **電話もメールも無いカード**(住所しか書いていないなど)は、ノートにはなりますが
    **連絡先タブには並びません**(並ぶ条件は「連絡できること」です)。
    そのときは取込の帯が「ノート N 件(うち連絡先に並ぶのは M 件)」と分けて言います
- **書き出し**: 連絡先タブの下の**「vCard で書き出す(N 件)」**を押すと、
  **いま見えている連絡先**が `.vcf` ファイル 1 つになって落ちてきます
  - 🔑 **絞り込み中は絞った分だけ**が出ます(ボタンの件数がそのまま出る数です)
  - ⚠ 連絡先が多くて**途中までしか集められていない**ときは、ボタンの字が
    「途中まで集めた N 件」になり、書き出した後の帯でもそう言います ──
    **全部だと思って元の `.vcf` を消さない**ためです
  - ⚠ **出るのは名前・所属・電話・メール・誕生日だけ**です ──
    住所やメモなど、本文に書いた残りは `.vcf` には入りません
    (⚠ 書き出したからといって**元の .vcf を消さないでください**)
  - ⚠ **極端に長い電話・メール**(1 つで 1,000 字を超えるもの)は、
    **その値だけ**が外れます ── 押した後の帯が「N 件で、長すぎる電話・メール
    (1,000 字超)を外しました」と言います。⚠ **同じ人の他の電話番号やメールは
    そのまま出ます**。途中で切った宛先を渡すと、相手の端末が
    **壊れた宛先を「在るもの」として保存する**ためです。
    ⚠ 本物の電話番号やメールアドレスがこの長さになることはありません
    (メールアドレスの上限は 254 字です)。外れた値は**ノートの本文には残っています**
  - ⚠ **電話やメールの種別**(携帯 / 自宅 / FAX / 勤務先)は、取り込みの時点で
    残せません ── 書き出すと全部同じ種別になります(取り込むときに注意が出ます)
  - 🔑 **所属は会社と部署に分かれたまま残ります**。`.vcf` の `ORG` は
    「会社」と「部署」を分けて持つので、取り込むと `org: [例の会社, 営業部]` の形で
    ノートに入り、書き出すと分かれたまま相手の端末へ渡ります
  - ⚠ **姓と名の区切りは付きません**。PKC では**ノートの題名がそのまま名前**なので、
    書き出した `.vcf` では名前が**1 つの字**として出ます(相手の端末では、
    姓の欄にフルネームが入ります)。⚠ 名前の出どころを 2 つにしないための決まりです ──
    姓と名を分けて持つと、一覧に出る名前とズレたときに直しようがなくなります
  - ⚠ 連絡先が書き出されるのは**このボタンを押したときだけ**です ──
    バックアップや他の書き出しに自動で混ざることはありません

### 予定(左の列のタブ)

🔴 **本文は 1 度も消えません。** 予定を見ている間も、真ん中には開いているノートが
出たままです。

```
┌ 予定 ─────────┐
│ ‹  2026年8月  ›  今月 │
│ 日 月 火 水 木 金 土  │  ← 小さな月。予定のある日には点が付きます
│           1  2       │
│  3  4  5  6  7  8  9 │
│ …  ㉕ …              │
│ ─────────────── │
│ 今日(2)              │
│  ☐ 14:00 打ち合わせ   │
│  ☐ 見積を送る         │
│ 明日(1)              │
│  ☐ …                 │
│ 8/27(木)(3)          │
└──────────────┘
```

| すること | どうするか |
|---|---|
| チェックを付ける・外す | 札の**印**を押します(元のノートの本文が書き替わります) |
| そのノートを開く | 札の**字**を押します(真ん中に出ます) |
| **予定を別の日へ動かす** | 札を**掴んで、日へ落とします**(小さな月の升目でも、下の日の見出しでも) |
| **何日かにまたがる予定を動かす** | 同じく掴んで落とすと、**期間ごと**ずれます(長さは変わりません) |
| **予定から外す** | 札にマウスを乗せると右端に **×** が出ます。押すと外れます(項目もノートも消えません)。札を**「日付なし」の見出しへ落とす**のも同じです |
| **繰り返しをやめる** | 繰り返しの札の **×** は「**この繰り返しをやめる**」です ── 本文の `@日付 毎週` が外れます(その回だけ消すことはできません) |
| 日付のない項目も見る | **日付のない項目も出す(N)** を押します |
| 済んだ予定も見る | **済んだ予定も出す(N)** を押します |
| 別の月を見る | **‹** **›** で送ります。**今月** で戻ります |

⚠ **編集中は、掴んで落としても動きません**(× も同じ)。そのときは画面の下に
「編集を終了してから行の予定を外してください」のように、**押した場所に合わせた理由**が
出ます ── これまでは**札が黙って元に戻るだけ**でした。
⚠ 保存に失敗しているときも同じで、そのときは「保存をやり直すか取り消してから」と出ます。

#### 予定には 2 つの単位があります

| 単位 | 何が予定になるか | 日付を書く場所 |
|---|---|---|
| **行** | チェックリストの 1 行 | 行の `@2026-08-25` |
| **ノート 1 件** | そのノートが丸ごと(会議のノート・その日の記録) | frontmatter の `date:` |

ノート 1 件を丸ごと予定にするときは、**右の列(情報)の「日付」**を押します。
日付が付いていれば「**外す**」も出ます。

⚠ **どのノートでも出せます**(特別な種類は要りません)。ログ・表・添付の
ノートでも同じです。

#### 日付の書き方

**行に書くとき**は、`@` のあとに **`2026-08-25`**(4 桁 - 2 桁 - 2 桁)と続けます。
時刻も書けます ── `@2026-08-25 14:00`(**2 桁 : 2 桁**)。

```
- [ ] 見積を送る @2026-08-25
- [x] 卵を買う @2026-08-25 14:00
- [ ] これは体裁のチェックリスト(日付が無いので既定では出ません)
```

| 書いたもの | 予定に出るか |
|---|---|
| `- [ ] 見積を送る @2026-08-25` | ✅ 出ます |
| `- [ ] 打ち合わせ @2026-08-25 14:00` | ✅ 出ます(時刻も札に出ます) |
| `- [ ] あとで読む` | ❌ 出ません(日付がありません) |
| `- [ ] ねじ @3 本` | ❌ 出ません(**日付の形ではない**ので、個数や単価はそのままです) |
| `- [ ] 大阪出張 @2026-08-25..2026-08-28` | ✅ 出ます(**4 日すべてに**出ます ── 下の「何日かにまたがる予定」) |
| `- [ ] ゴミ出し @2026-08-31 毎週` | ✅ 出ます(**毎週その曜日に**出ます ── 下の「繰り返す予定」) |

#### 時間になったら音で知らせる

行に**時刻まで**書いた予定(`- [ ] 打ち合わせ @2026-08-27 14:00`)は、
その時間になったときに**音で知らせられます**。

1. **設定 → 予定の知らせ**を入れます(最初は切です)
2. 入れた瞬間に **1 度だけ音が鳴ります** ── どんな音か分かりますし、
   その端末で音を出せるかもここで分かります
3. 時間になると、短い音が鳴って**画面の下に帯**が出ます
4. 帯の **開く**でそのノートへ移り、**閉じる**で片付きます

| こんなとき | どうなるか |
|---|---|
| 日付だけ書いた予定(`@2026-08-27`) | 鳴りません(その**日**であって、その**時刻**ではないためです) |
| frontmatter の `date:` に書いた予定 | 鳴りません(ノート 1 件が丸ごとその日、という意味で、時刻の置き場がありません) |
| 済んだ印(`- [x]`)を付けてある行 | 鳴りません |
| 同じ回に 3 件重なった | 3 件とも帯に出ますが、**音は 1 回**です |
| 過ぎた時刻の予定があるときに PKC を開いた | 鳴りません(**その時刻になった**ことを知らせるものなので、過ぎた分は鳴らしません) |
| 別のタブを見ていた | 鳴ります(時刻の差で見ているので、間が空いても取りこぼしません) |

🔴 **PKC を開いている間だけ鳴ります。** 閉じている間は鳴りません ──
ブラウザには「閉じたページを時刻で起こす」しくみが無いためです。
⚠ **鳴る前提で大事な予定を任せないでください。**

⚠ 音が出せない端末・設定でも、**画面の下の帯は必ず出ます**(入れたときに
「音を出せませんでした」と出ます)。

🔑 **`@1,500` や `@3` を日付と読み違えることはありません** ── 受けるのは
**4 桁 - 2 桁 - 2 桁の完全な形だけ**です。⚠ 逆に `@2026-8-5` のように桁を詰めない形は
**日付として読みません**(本文には残ります)。
⚠ **`@` の前に空白は要りません** ── `会議@2026-08-25` と続けて書いても読みます。
🔑 **札の字には `@2026-08-25` の部分は出ません**(見出しに日が出ているので、
同じ日付が 2 回出ないようにしています)。

#### 何日かにまたがる予定(出張・休暇・案件の期間)

日付を **2 つ**、`..` でつないで書きます ── `@2026-08-25..2026-08-28`。

```
- [ ] 大阪出張 @2026-08-25..2026-08-28
```

その予定は **8/25・8/26・8/27・8/28 の 4 日すべてに出ます**。
⚠ 1 日だけに置くと、途中の日を見に来たときに**載っていません**。

| すること | どうするか |
|---|---|
| いつまでか見る | 札の右に「**〜08/28**」と出ます(見出しはその日を出すので、終わりは札が出します) |
| **期間ごとずらす** | どの日の札でも、掴んで別の日へ落とすと**掴んだ日がその日に来ます**。長さは変わりません(3 日目を 3 日先へ落とせば、全体が 3 日ずれます) |
| 単日に戻す | 本文で `..2026-08-28` を消します |
| 予定から外す | 札の **×** を押すか、「日付なし」の見出しへ落とします ── **`@…` ごと消えます**(`..2026-08-28` だけ残ることはありません) |

- 🔑 **`〜` でも `～` でも書けます** ── `@2026-08-25〜2026-08-28`。
  ⚠ ただし PKC が**書き込むとき**は `..` に揃えます
- ⚠ **期間に時刻は付けられません**。期間の札は何日にも出るので、
  「その時刻」がどの日のものか決まらないためです。
  書いた時刻はそのまま**札の字に残ります**(黙って消えたりはしません)
- ⚠ **終わりが開始より前**(`@2026-08-28..2026-08-25`)や、**書きかけ**(`@2026-08-25..`)は
  **予定として読みません** ── 書いた字がそのまま本文に残るので、見て直せます
- ⚠ 期間が**とても長い**(1 年より先まで)ときは、束に出すのは **366 日ぶん**までです。
  札には終わりの日が出ます
- ⚠ **ノート 1 件を丸ごとの予定**(frontmatter の `date:`)には、まだ期間を書けません。
  期間が要るときは**チェックリストの行**に書いてください

#### 繰り返す予定(毎日・毎週・毎月・毎年)

日付のうしろに **`毎日` / `毎週` / `毎月` / `毎年`** と書きます。

```
- [ ] ゴミ出し @2026-08-31 毎週
- [ ] 家賃 @2026-09-01 毎月
- [ ] 朝会 @2026-08-31 09:30 毎週
```

**曜日は書きません** ── `@2026-08-31`(月曜)に `毎週` と書けば、毎週月曜です。
時刻も一緒に書けます。

| すること | どうするか |
|---|---|
| **いつまでか決める** | `..` で終わりを書きます ── `@2026-08-31..2026-12-31 毎週`(12/31 まで毎週) |
| **今日のぶんが済んだ** | その日の札の印を押します。⚠ **その日ぶんの行が本文に増えます**(下) |
| 済んだ回を取り消す | 「**済んだ予定も出す**」を押して、増えた行の印をもう一度押します |
| **繰り返しを終わりにする** | 本文で**規則の行そのもの**にチェックを付けます ── 予定タブから消えます(外せば戻ります) |
| **やめる / 変える** | 本文の `@… 毎週` を書き直します(消せば、その日 1 日だけの予定に戻ります) |

🔑 **印を押すと、規則の行はそのままで、その日ぶんの行が 1 本増えます。**

```
- [ ] ゴミ出し @2026-08-31 毎週      ← 規則の行(押しても変わりません)
- [x] ゴミ出し @2026-09-07           ← 9/7 の札を押すと、これが増えます
```

⚠ こうしているのは、**規則の行の印を押すと「この繰り返しは終わり」の意味になる**
からです。「今日のぶんが済んだ」とは別のことなので、行を分けています。
🔑 増えた行は**普通のチェック項目**なので、押せば外せますし、消せます。

- ⚠ **過ぎた回は出ません**(今日より前のぶん)。押していない回は本文にも残りません
- ⚠ 先のぶんは **2 か月ぶん**まで出ます。それより先は、その日が近づくと出ます
  (`@2027-06-01 毎年` のように**開始が先**のときは、その 1 回は必ず出ます)
- 🔴 **繰り返しの札は、掴んで日を動かせません。** 「規則ごとずらす」のか
  「この回だけずらす」のか決められないためです。落とすと**その理由が画面の下に出ます**
  ── 本文の `@… 毎週` を書き直してください
- ⚠ 空白は無くてもかまいません(`@2026-08-31毎週`)。⚠ 逆に、日付から離して書いた
  「毎週」(`@2026-08-25 の資料を毎週送る`)は**記法として読みません**(ただの字です)

**ノート 1 件に書くとき**は、本文の先頭の frontmatter に書きます ──

```
---
date: 2026-08-19
---
```

⚠ こちらも形は **`2026-08-19`** だけです。`2026-8-1` のような書き方は日付として
読まれません(**本文からは消えません**が、予定には出ません)。

#### 日付を書いていない項目も見たいとき

上の **日付のない項目も出す(N)** を押します ── **N** はいま隠れている件数です。
もう一度押すと、日付を書いた項目だけに戻ります。

⚠ 「文章の体裁としてチェックリストを使う」ことがあるので、**既定では出しません**。
🔑 ただし**捨ててはいません** ── 1 押しで全部戻ります。

⚠ ノートの予定には**印(チェック)が出ません** ── チェックする「行」が無いためです。
🔑 どちらの単位も**同じ束に並び、同じように掴んで落とせます**。落としたときに
書き替わる場所だけが違います(行の `@…` か、frontmatter の `date:` か)。

🔑 **掴んで落とすと、本文の `@2026-08-25` が書き替わります。** 動くのは日付の
部分だけで、前後の字は 1 文字も変わりません。時刻を書いてあれば、日を動かしても
時刻は付いたままです。

⚠ **今日より前の予定**は、いちばん上に出ます(印が付きます)。消したり別の場所へ
追い出したりはしません ── 見えなくなると、忘れたことにも気づけないからです。

⚠ **束は「日」です**(「今週」ではありません)。落とし先がそのまま日になるように
してあります ── 「今週」に落としても、どの日か決まらないからです。

⚠ 書き替わるのは**押した行の印 1 文字だけ**です。まわりの本文や空白の入れ方は
変わりません。⚠ 押した札の**そのノート**に書きます ── いま真ん中に開いている
ノートには書きません。
⚠ 編集中は押せません(「編集を終了してからチェックしてください」と出ます)。
⚠ 左の列の **探す** はこの面にも効きます(絞るのは**ノート単位**です)。
⚠ 数が多いときは**途中まで**を出し、そのことを上に書きます
(黙って切ることはありません)。

🔑 これまでに書いたチェックリストや `date:` は、**次に起動したときに数え直す**ので、
そのまま出ます(保存し直す必要はありません)。

⚠ どのタブでも**行の作りは同じ**です ── 行の頭に**種類の図案**、右端に**更新日**。
探し方が変わっても、行の読み方を覚え直さなくていいようにしています。

⚠ 最初に開くのは **フォルダ** です。**前回選んでいたタブをこの端末で覚えます**ので、
一覧で使いたい人は一度選べば次からも一覧で開きます。

### フォルダに入れる・出す・並べ替える(**フォルダ**タブ)

#### 選ぶ・まとめて選ぶ

| 操作 | 何が起きるか |
|---|---|
| **1 回押す** | その行を選びます(中央にそのノートが出ます) |
| **2 回押す**(フォルダ) | そのフォルダを**開きます**(中に入ります) |
| **Ctrl + 押す**(Mac は ⌘) | 印を**足す / 外す**(中央は変わりません) |
| **Shift + 押す** | 前に押した行から**そこまで**を印にします(いま見えている並び順で採ります) |

印を **2 件以上**付けると、一覧の上に **「n 件を選んでいます」** の帯が出て、
**まとめてゴミ箱へ** と **選択を解除** が押せます。

⚠ まとめて消せるのは**ゴミ箱まで**です(戻せます → §6)。
**完全に消す**操作はまとめて撃てません ── 戻せない操作を一括で撃てるようにするのが、
いちばん事故が大きいためです。

#### ドラッグ&ドロップで動かす

行を**掴んで**、**フォルダの行**に落とすとその中に入ります。
**パンくず**(上に出ている「ルート / …」)に落とすと、その階層へ**出せます**。
印が付いている行を掴むと、**印を付けた全部**が一緒に動きます。

⚠ フォルダを**自分の中や自分の子孫**へは落とせません(入れ子が輪になるため)。
落とせなかったときは、画面の下にその理由が出ます。


パンくず(いま何処に居るか)のすぐ下に、**選んでいるものの居場所**の帯が出ます。

| 操作 | やり方 |
|---|---|
| フォルダに入れる | 行を選び、帯の**選ぶ欄**で入れ先のフォルダを選ぶ(選んだ瞬間に動きます) |
| フォルダから出す | 同じ欄で **ルート(いちばん上)** を選ぶ |
| 並べ替える | 帯の **上へ** / **下へ** を押す(**同じフォルダの中**で隣と入れ替わります) |
| フォルダの中に作る | そのフォルダを選んでから **+ ノート**(帯の下に「どこに入るか」が出ます) |

⚠ 行ごとにボタンは付けません ── **いつも同じ場所**(帯)に出します。フォルダ自身も
選べば動かせます(行に付けると、フォルダは選んだ瞬間に一覧から消えるので動かせません)。
⚠ 先頭・末尾では **上へ / 下へ が押せなくなります**(押せるのに何も起きない、を作りません)。
⚠ 並べ替えは**同じフォルダの中だけ**です。別のフォルダへ動かすのは「居場所」の欄です
(1 つの操作に 2 つの意味を持たせないため)。

⚠ 探し方を変えても**中央はそのまま**です ── 中央は常に「いま開いているノート」を
出します(場所を覚え直さなくていいように)。
🔑 **日付を見るのは 予定 タブ**です(上の表)── ⚠ **別の窓は開きません**。
真ん中の本文は出たままなので、「予定を見ながら本文を書く」ができます。

### スマートフォルダ(条件に合うノートが自動で集まる)

**「請求」タグを付けたノートが、あちこちのフォルダに散っている** ── そういうときに
使う入れ物です。⚠ ノートを**動かしません**。散らばったまま、**1 か所から見えるように**します。

#### 作って、条件を選ぶ

1. 左の列の **▼**(作る種類)で **スマート** を選び、**+ スマート** を押します
2. **フォルダ** タブに出るので、**2 回押して中へ入ります**(⚠ 1 回目は選ぶだけです)
3. 一覧のすぐ上に出る**条件の帯**で、**タグ** の欄に語を入れて **条件に足す** を押します

条件を足すと、**そのタグが付いたノートが、どのフォルダに在っても集まります**。
🔑 タグは**本文の先頭(`tags:`)に書いたもの**でも、**本文の中に書いたもの**でも構いません
(→「本文の中にタグを打つ」)。
🔑 **後からそのタグを付けたノートは、開いたまま勝手に現れます**(開き直す必要はありません)。
タグを外せば、その場で消えます ── **入れ物の中身は、いつでもタグそのままです**。

⚠ **条件が 1 つも無いうちは、何も集めません**(「全部」ではありません)。
条件の帯に **条件を選んでください** と出ます。
⚠ 条件を **2 つ以上**足すと、**全部付いている**ノートだけが集まります。
🔑 タグは**何個でも付きます**し、**同じノートがいくつもの入れ物に出ます** ──
たとえば `2026年` `8月` `26日` の 3 つを付けておくと、
**3 つ全部**を条件にした入れ物(= その日のぶん)にも、`2026年` **だけ**を
条件にした入れ物(= その年のぶん)にも、同じノートが並びます。
⚠ 条件は **×** で 1 つずつ外せます。
⚠ 条件は **8 つまで**です。それ以上足そうとすると、**理由が出て足りません**
(古いほうを黙って落としたりはしません)。

#### タグ以外でも絞れます

条件の帯には、タグの欄のほかに **7 つの絞り口**があります。選んだ瞬間に効きます。

| 選び口 | 何で絞るか |
|---|---|
| **種類** | ノート / フォルダ / 添付 / 表 …(作ったときに決まる種類) |
| **更新** | **最近直したもの**(7 日以内 / 30 日以内 / 90 日以内 / 1 年以内) |
| **作成** | **最近作ったもの**(同上) |
| **日付** | ノートの**先頭に日付を書いてある / 書いていない** |
| **語** | **題名か本文にその語がある**(打って `Enter`) |
| **チェック** | **チェック項目がある / 無い** |
| **未処理** | **未処理の項目がある / 全部済んでいる** |

🔑 **タグと合わせて全部 AND** です ── 「種類が添付」+「更新が 30 日以内」なら、
**その両方に当てはまる**ものだけが集まります。「指定しない」を選ぶと外れます。

⚠ **「日付」が見るのは、ノートの先頭に書いた `date:` だけ**です ──
本文の行に書いた `- [ ] やること @2026-08-25` は**この条件では集まりません**
(予定のタブには出ます)。

🔑 **「チェック」と「未処理」は、ノートの中身を読んで数えます** ── だから
「**まだ終わっていない仕事がぜんぶ集まる場所**」が作れます(「未処理がある」を選ぶだけ)。
🔑 **開くたびに数え直します**ので、チェックを付け外しした分はそのまま出ます。
⚠ **古い版のタブで書き替えたノートだけ**、その回は出てこないことがあります ──
いまの版でもう一度保存すると出てきます。

🔑 **「語」は打ってから `Enter`**(または欄の外を押す)で効きます ──
1 文字ごとには効きません(打っている途中の語で集め直さないためです)。
外すときは**欄を空にして `Enter`** です。
🔑 **探す欄と同じ探し方**です ── 探して出てくるものは、ここでも集まります。

🔑 **日数は好きな数にできます** ── 選び口には 4 つしか出ていませんが、
ノートの先頭に `smart-updated: 45d` のように書けば、その日数で効きます。

⚠ 条件は **8 つまで**です。それ以上足そうとすると**足されず、理由が出ます**
(古いほうを黙って落としたりはしません)。

#### 入れる・外す(どちらもできます)

| やりたいこと | やり方 | 実際に何が起きるか |
|---|---|---|
| **入れる** | ノートを掴んで、**スマートフォルダの行**に落とす | そのノートの本文に**条件のタグが付きます** |
| **外す** | 中に入って行を選び、条件の帯の **ここから外す** を押す | そのノートの本文から**条件のタグが消えます** |

🔑 **「入れた / 出した」の実体は、タグの付け外し**です ── ノートは元の場所から
1 ミリも動きません。⚠ だから**同じノートが複数のスマートフォルダに出ます**
(タグは何個でも付きます)。

⚠ **落として入れられるのは、条件に「タグ」があるときだけ**です。
「種類」「更新」「作成」「日付」「語」しか条件に無い入れ物へ落とすと、
**理由が出て、何も起きません**(黙って捨てたりはしません)。
🔑 これらは**落とした側の本文を書き替えても満たせない**ためです ──
更新日はノートを保存したときに決まりますし、語は本文そのものです。
**条件にタグを 1 つ足せば、落として入れられるようになります。**
⚠ 同じ理由で、**ここから外す**もタグの条件があるときだけ効きます。

#### 見分け方と、できないこと

⚠ ふつうのフォルダとは**図案と色が違います**(星の付いたフォルダ)。
中身が条件で決まるので、次の 2 つは**できません**:

- **手で中へ入れる**(「居場所」の欄では選べません)── 入れるのは**落とす**か、
  そのノートにタグを付けるかです
- **中のものを並べ替える** ── 並びは一覧と同じ並べ替え(名前 / 大きさ / 更新)に従います

⚠ 集まる数には上限があります。超えたときは条件の帯に
**「N 件中 M 件を出しています」**と出ます(黙って切りません)。

#### 条件は本文に書いてあります

スマートフォルダの本文の先頭に、こう書かれています。

```
---
smart-tags: [請求]
smart-text: 請求書
---
```

🔑 **手で書き替えても効きます**(条件の帯の欄は、これを書くための道具です)。
🔑 **書き出し・取り込みに一緒に付いていきます** ── 端末を移しても条件は残ります。

#### 集まりそのものに期日と状態を持たせる(2026-08-27 追加)

同じ場所に **`date:`** と **`status:`** を書けます ── **予定の面に出ます**。

```
---
smart-tags: [請求]
date: 2026-09-30
status: doing
---
```

🔑 「請求のノートを月末までに片付ける」のように、**集まりそのものを 1 つの仕事**として
扱えます。⚠ 中のノートの状態は**合算しません**(集まりの状態は、ここに書いたものだけです)。
⚠ `archived:` は写しません ── 書いてもノートは一覧から消えません(片付けるのは todo だけです)。

### 右の列(情報)

選んでいるものの**題名・種類・居場所・作成日・更新日**と、それに対する操作
(**書き出す** / **閲覧用 HTML** / **Word** / **PowerPoint** / **PDF** / **履歴** / **削除**)が出ます。⚠ 画面が狭いときは**本文の下へ回ります**
(隠れません)。⚠ 編集中は押せません(確定するか取り消してください)。

⚠ **居場所**は入っているフォルダです(入れ子なら `親 / 子` の順)。どのタブから
選んでも出るので、**一覧タブのままでも所属フォルダが分かります**。どこにも入って
いなければ **ルート** と出ます。フォルダを移すとその場で変わります。

#### 集まり先(どのスマートフォルダに集まっているか)

**集まり先** に、そのノートを集めている**スマートフォルダ**が並びます。
押すとその入れ物へ移れます。

- ⚠ 上の **タグ** の札とは**別物**です ── あちらは「その語で探す」、
  こちらは「**実際に並んでいる入れ物へ行く**」です
- 🔑 入れ物は条件を**いくつも**持てる(たとえば「請求」と「未処理」の両方)ので、
  自分のタグを見ても**どこに集まっているかは分かりません**。だからここに出します
- ⚠ **一度も開いていない入れ物は出ません**(集めたときに分かることなので)。
  その入れ物を 1 度開くと、次から出ます
- ⚠ **1 つも分かっていないときは、行ごと出ません** ── 「無し」とは書きません
  (集めていないだけかもしれないので、無いと決めつけないためです)

### 確認の画面(消す前・上書きする前)

戻しにくい操作の前には、画面の中央に**確認**が出ます。⚠ これは PKC 自身の画面です
(ブラウザのものではありません)。

- **取り消す側が左、実行する側が右**です。位置はいつも同じなので、探さずに押せます
- 開いたときは**取り消す側**が選ばれています ── **Enter** を押しても実行はされません。
  **Esc** でも閉じられます(閉じたときは何も起きません)
- **不可逆な操作**は、実行する側のボタンに**色が付き**、そこに**何が起きるか**が
  書いてあります。全部で 7 種類です ── **削除**(ノート)/ **空にする**(ゴミ箱)/
  **上書きする**(書き出し先の同じ名前)/ **ノートを渡して開く**(素のまま起動)/
  **整理する**(使っていない添付)/ **打ち切る**(他のタブの保存権)/
  **切り替える**(編集中に新しい版へ ── 編集中の内容は保存されません)
- 閉じると、**押す前に居た場所へ戻ります** ── 表の行を選んだまま消したなら、
  そのままキーで次の行へ動けます

### 4-8. 参照元(このノートを参照しているのはどれか)

右の情報ペインの **参照元** に、**本文からこのノートへリンクしているノート**が並びます。
押すとそのノートへ移れます。

- 拾うのは、本文に書いた **ノート間のリンク**(`[題名](entry:…)` の形)です
- ⚠ 上の **関係** とは**別物**です ── あちらは user が手で張った辺、
  こちらは**本文のリンクから自動で拾ったもの**です。だから**消すボタンはありません**
  (消したいときは、参照している側の本文からリンクを外します)
- ⚠ **ゴミ箱の中からの参照は出ません**(押しても一覧に無いものへ飛ぶため)
- ⚠ 自分自身へのリンクは出ません
- 多いときは途中まで出し、**「ほかにもあります」**と件数を書きます(黙って切りません)
- ノートを選び直した直後は **「調べています…」** と出ます ── 「無し」ではありません

🔑 **中央の面は奪いません。** 本文は出たままで、右の列だけが変わります。

## 5. 書き出す・取り込む

### 書き出す(左の列のいちばん下と、設定の中)

| ボタン | ファイル | 可逆? | 用途 |
|---|---|---|---|
| **バックアップ**(左の列) | `<題名>-<日付>.pkc3.zip` | ✅ **可逆** | これさえあれば全部戻る。**定期的にこれを取る** |
### 何が容量を食っているか(保存領域が心細くなったら)

設定 → 書き出しと片づけ → 何が容量を食っているか の **調べる** を押すと、
**添付の重い順**にノートが並びます。

- **行を押すと、そのノートへ飛びます** ── 見えても辿り着けないと、結局 1 件ずつ
  探すことになるためです
- **(共有)** と付いた行は、**同じ添付を別のノートとも使っています** ──
  片方を消しても容量は減りません
- どこからも使われていない添付が残っていれば、その合計も出ます
  (**使っていない添付を消す** で片づけられます)

⚠ **ブラウザが言う使用量とは数え方が違います。** ここが数えるのは**添付の合計だけ**で、
ブラウザは索引や空き領域も数えます ── 一致しなくても壊れてはいません。

### 構成をコピー(ノートが増えてきたら)

ノートが 100 件を超えると、**2 ペインで 1 件ずつ運ぶ**のは現実的ではありません。
**設定 → 書き出しと片づけ → 構成をコピー** を押すと、いまのノートとフォルダの並びが、
**整理コマンドの書き方つき**でクリップボードに入ります。

1. **構成をコピー** を押す
2. AI(ChatGPT / Claude など)に貼って「**この構成を整理する案を考えて**」と頼む
3. 返ってきた案を読む

コピーされる紙には、こういう説明が最初から入っています:

```
#   mv <lid> <フォルダのlid|@名前|root>     フォルダの直下(または root)へ移す
#   mkdir "<題名>" [<親>] [as @名前]        フォルダを作る(親を省くと root)
#   rename <lid> "<新しい題名>"             題名を変える
```

⚠ ノートが非常に多いときは**上から 2000 件まで**にします。切ったときは
その旨がコピーした紙の中に書かれます。

#### 返ってきた案を当てる

同じ画面の **整理案を当てる** に、AI から返ってきた案をそのまま貼ってください。

- 貼ると**すぐ下に「何が起きるか」が並びます** ── 「『議事録』を『資料』の中へ
  移します」のように、**lid ではなく題名**で書きます
- 間違いがあれば **何行目が、なぜ駄目か**が出ます(「3 行目: xyz というノートは
  ありません」)
- 🔴 **間違いが 1 行でもあると「当てる」は押せません** ── 半分だけ当たると、
  どこまで進んだのか分からなくなるためです
- よければ **当てる** を押すと、まとめて反映されます

```
mkdir "2026 年の議事録" as @g
mv mta73ihn-0001 @g
mv mta73ihn-0002 @g
rename mta73ihn-0003 "総会(確定版)"
```

🔑 **`as @名前`** を付けると、**同じ案の後の行から**その新しいフォルダを指せます
── 「新しいフォルダを作って、そこへまとめて移す」が 1 回で書けます。

⚠ 1 つの案で扱えるのは **500 行**までです。
⚠ **取り消しはありません。** 当てる前の下見が、その代わりです ──
必ず目を通してから押してください。

#### 設定だけを別の端末へ持っていく

会社の PC で整えた**見た目や鍵の割当**を、家の PC でも同じにしたいとき。
⚠ **バックアップとは別物です** ── バックアップ(`.pkc3.zip`)を取り込むと
**ノートごと**移るので、移した先のノートが混ざります。ここで運ぶのは
**見た目と使い勝手だけ**で、**ノートは 1 件も入りません**。

設定 → 書き出しと片づけ の **設定を書き出す** を押すと
`PKC3-settings-<日付>.json` が落ちます。

**入るもの**:見た目 / 面の畳み方 / 編集の仕方 /「開く」で編集に入るか / 紙面 /
**文字の大きさ** / **本文の段組み** / 鍵の割当 / 探し方のタブ / 2 ペインの下見 /
貼り付けの判定 / 集計の束ね方 / 予定の時刻に知らせるか。

⚠ **入らないもの**(理由があります):

| 何 | なぜ運ばないか |
|---|---|
| **フラグ** | 実験中の切り替えで、設定とは別の仕組みです |
| **許可**(外部の画像 / 拡張 / 埋め込み) | 🔴 **その端末で、その中身を見て許した**ものです。運ぶと意味が変わります |
| **お知らせの既読** | 運ぶと、別の端末で**まだ読んでいないお知らせが消えます** |
| **2 ペインで留めた場所** | 別の端末では**別のノートを指してしまいます** |

#### 読み込むとき ── 当てる前に見せます

**設定を読み込む** でファイルを選ぶと、**その場では当てません**。
すぐ下に「**何が変わるか**」が並びます(「鍵の割当 を入れ替えます」のように)。

- よければ **設定を当てる** を押すと、まとめて入ります
- ⚠ **変わるものが 1 件も無ければ押せません**(理由が出ます)
- ⚠ 運ばない決まりのものや、**この版が知らない設定**が入っていたら、
  **件数を出して入れません** ── 黙って捨てません
- 🔑 **入れたあとは、いちど読み直してください** ── 鍵の割当も紙面も
  起動のときに読むので、当てただけでは画面が変わりません

| **閲覧用 HTML**(設定 → 書き出しと片づけ) | `<題名>-<日付>.html` | ❌ 片道 | 1 ファイルで渡す・見せる。単体で開いて**読める**(書けません) |
| **持ち歩ける 1 枚**(設定 → 書き出しと片づけ) | `<題名>-<日付>.pkc3.html` | ✅ **可逆** | **PKC3 ごと** 1 ファイル。ダブルクリックで開いて、**そのまま読み書きできる**(→ 下) |
| **Markdown**(設定 → 書き出しと片づけ) | `<題名>-<日付>.md.zip` | ❌ 片道 | PKC3 を捨てても読める形。1 ノート = 1 `.md`、添付は `assets/`。**Pandoc など他の道具への入口**(→ 下) |
| **書き出す**(右の情報ペイン) | `<ノート名>-<日付>.pkc3.zip` | ✅ 可逆 | 1 件だけ。消す前の退避に |
| **閲覧用 HTML**(右の情報ペイン) | `<ノート名>-<日付>.html` | ❌ 片道 | **このノート 1 件だけ**を、相手が開くだけで読める 1 枚に。⚠ 設定側の同名は**全部**をまとめます |
| **フォルダを書き出す**(右の情報ペイン。⚠ **フォルダを選んでいるときだけ出ます**) | `<フォルダ名>-<日付>.pkc3.zip` | ✅ 可逆 | そのフォルダと**中に入っているものごと**。**相手に一式を渡すとき** |
| **Word**(右の情報ペイン) | `<ノート名>-<日付>.docx` | ❌ 片道 | Word で開いて直したい・配りたいとき。**1 ノート = 1 文書** |
| **PowerPoint**(右の情報ペイン) | `<ノート名>-<日付>.pptx` | ❌ 片道 | 発表の資料にするとき。**見出しでスライドが切れます** |
| **PDF**(右の情報ペイン) | ⚠ **ファイルは落ちません** | ❌ 片道 | 紙に出す・PDF にする。押すと**ブラウザの印刷画面**が開き、そこで「PDF として保存」を選びます |

🔑 ファイルは**ドラッグ&ドロップでも入ります**(→ §7-1)。編集していないときに落とせば添付になり、**編集中の本文へ落とした画像は本文に入ります**。

#### 持ち歩ける 1 枚(PKC3 ごと持ち出す)

**設定 → 書き出しと片づけ → 持ち歩ける 1 枚** を押すと、
**PKC3 のアプリそのものと、いまの中身と、添付**が 1 つの `.html` になります。

- USB に入れて持ち歩き、別のパソコンで**ダブルクリックするだけ**で開きます
  ── サーバも、インターネットも要りません
- 🔴 **その 1 枚の中で、そのまま書けます**。「閲覧用 HTML」は読むだけですが、
  こちらは**続きを書ける PKC3 そのもの**です
- 書いた内容は、**開いたパソコンのブラウザの中**に残ります。もう一度同じ 1 枚を
  開けば続きが出ます

⚠ **知っておいてほしいこと**:

- **1 枚ごとに別の入れ物**です。2 枚書き出して両方に書くと、**中身は混ざりません**が、
  **片方に書いたことはもう片方には出ません**。戻すときは、その 1 枚の中で
  **バックアップ**を取って、元の PKC3 に取り込んでください
- **配られた 1 枚からは、さらに「持ち歩ける 1 枚」を書き出せません**
  (アプリの雛形を取りに行けないためです)。押すとその旨が出ます
- 保存は**少し待ってからまとめて**書かれます。⚠ **閉じるときに自動で書かれます**が、
  書けなかったときは画面の下に出ます
- ファイルは **6 MB ほど**あります(アプリが丸ごと入っているためです)

#### フォルダを書き出す(一式を渡す)

フォルダを選ぶと、右の情報ペインに **フォルダを書き出す** が出ます。押すと、
**そのフォルダと、中に入っているものぜんぶ**(入れ子のフォルダの中まで)が
1 つの `.pkc3.zip` になります。

- **フォルダの器も入ります** ── 取り込み直すと、**フォルダごと**戻ります
- 添付は、**中のノートが使っている物だけ**入ります(過去の版が使っていた物も)
- ⚠ **外へ繋がる関係は入りません**(相手のノートが入らないため)。何件落ちたかは
  書き出した後の帯に出ます
- ⚠ フォルダ以外を選んでいるときは**出ません**(押せるのに必ず失敗する、を作らないため)

🔑 **バックアップと同じ形式**なので、そのまま取り込み直せます。

#### PDF にする(紙に出す)

右の情報ペインの **PDF** を押すと、そのノートを**紙の形に組み直して**
ブラウザの**印刷画面**が開きます。そこで送り先に「**PDF として保存**」を選べば PDF になり、
プリンタを選べばそのまま印刷できます。

⚠ **ファイルはこちらからは落ちません** ── 保存するかどうかは印刷画面で決めます。

- **紙の大きさ**は設定(§8)の紙の設定で変わります(既定は A4 縦)
- **`+++` は改ページ**になります(→ §5)
- 一覧・情報ペイン・お知らせは**紙には出ません**(押せるものが紙には無いため)
- 別の面(集計など)を見ているときに押すと、**そのノートを開いてから**刷ります
- ⚠ **編集中は押せません** ── 確定するか取り消してください
  (編集の面は入力欄なので、刷ると見えている 1 画面ぶんしか出ません)

🔑 `Ctrl+P`(mac は `⌘P`)でも同じ紙が出ます ── **PKC3 はこのキーを奪っていません**。

#### Word(.docx)で出す

右の情報ペインの **Word** で、**いま選んでいるノート 1 件**が Word 文書になります。
見出し・段落・箇条書き(入れ子も)・表・引用・コード・水平線・強調・外部リンクが、
**画面で見ているのと同じ形**で入ります。

**本文に貼った添付の画像も、図(mermaid)もグラフも入ります。**
画像の大きさは**縦横比そのまま**で、紙の本文幅(A4 縦で 17cm)より広いものだけ、
その幅に合わせて縮みます。

🔑 **図(mermaid)はベクタで入ります。** 拡大しても粗くならず、Word の中で
**図形として触れます**(線や箱を選んで直せます)。⚠ **グラフ(chart)は絵のまま**です ──
グラフの描き手はベクタを出さないので、そこは画像になります。
図もグラフも**画面と同じ配色**で入ります。

⚠ **画面で見えている面だけが入ります。** 表(csv)や図の塊は画面で
「中身 / 原文」を切り替えられますが、文書に入るのは**既定で見えているほう**です
(原文で見せる指定 `csv-norender` を書いた塊は、原文のほうが入ります)。

**紙は設定の紙面と同じ**になります(→ §4-2 の「紙面」)。A4 / A3 の縦横はそのまま、
画面向けの形式(フル HD / 4:3)は**印刷と同じく A4 縦**になります。
**改頁(`+++`)は Word でも改頁**、**ページ番号**は下の中央に入ります。
文書の先頭に書いた設定(`---` で囲んだ所)は本文に出ず、`{{vars.…}}` は値に置き換わり、
`heading-number: true` の見出し番号もそのまま入ります(画面と同じ材料で描いています)。

⚠ **入らないものもあります** ── html の箱、外から読む画像、
Word が読めない形式(SVG 等)、大きさを読めなかった画像、描けなかった図。
落とすときは黙って消さず、**その場所に「［… は写せませんでした］」と書き**、
書き出したあとの行に件数を出します ── どこが欠けたかが本文を読めば分かります。

⚠ Word 文書は**取り込み直せません**(片道)。戻せる形が要るときは「バックアップ」です。

🔴 **バックアップだけが可逆**です。「閲覧用 HTML」と「Markdown」は
frontmatter に居場所の無いもの(relations / 履歴)が落ちます。
「Markdown」は**落ちたものを書出し後に件数つきで画面に出します**。
「閲覧用 HTML」は件数を出さず、「取り込み直せません」とだけ言います。

#### PowerPoint(.pptx)で出す

右の情報ペインの **PowerPoint** で、**いま選んでいるノート 1 件**がスライドになります。
⚠ Word と大きく違うのは、**本文が勝手に切れる**ところです。

| 本文に書いたもの | どうなるか |
|---|---|
| `# 大見出し` | **扉のスライド**が始まります(題名が大きく中央に) |
| `## 中見出し` | 直前が扉なら**その副題**。そうでなければ**新しいスライド** |
| `### 小見出し` | **新しいスライド**(見出しがそのスライドの題になります) |
| `---` / `+++` | そこで**スライドが切れます**(題の無いスライドが始まります) |
| それ以外(段落・箇条書き・表・図・画像) | **いま作りかけのスライドの中身**になります |

🔑 **切れ方は PKC2 と同じ**です ── PKC2 で書いた資料を持ってきても、同じ所で切れます。

⚠ **中身が 1 つも無いスライドは作りません。** `---` のすぐ後に見出しを書いても、
白いだけのスライドは挟まりません(PKC3 でそう決めました)。

**入るもの**は Word とほぼ同じです ── 見出し・段落・箇条書き(番号付きも、入れ子も)・
**表(格子のまま)**・引用・コード・強調・外部リンク・添付の画像・図(mermaid)・グラフ。

- 🔑 **画像と図は縦横比そのまま**です。枠より小さいものは**引き伸ばしません**
  (粗くしないため)
- 🔑 **表は格子**として入ります(文字に潰れません)。列の幅は**中身の量**で決まります
- 🔑 **入りきらない文字は PowerPoint 側が縮めます**(切り捨てません)
- ⚠ 大きさを読めなかった画像は入れません ── その場に理由を書きます

⚠ **スライドの版面は 16:9 固定**です(設定の紙面は Word と PDF 向けで、
スライドには効きません)。

⚠ PowerPoint の file も**取り込み直せません**(片道)。戻せる形が要るときは
「バックアップ」です。

#### ⚠ 添付の「控え」も一緒に入ります

Office で上書き保存すると、**入れ替える前の中身が控えとして残ります**(→ §7-4)。
書き出しには、**いまの中身だけでなくその控えも入ります** ── 戻せるようにするためです。

🔑 したがって、**同じ文書を何度も上書きしたノートがあると、書き出しは大きくなります**
(控えは 1 件につき最大 5 世代)。⚠ 書き出したあとの行に、その内訳が出ます ──
**「添付 12(うち控え 7)」**のように。書き出したファイルが思ったより大きいときは、
まずこの数字を見てください。

#### Markdown で出す(Pandoc など他の道具へ渡す)

設定(§8)の**書き出しと片づけ**にある **Markdown** で、全ノートが
`.md.zip` になります。展開すると **1 ノート = 1 つの `.md`**、添付は `assets/` です。

🔑 **本文は書いたとおりの原文がそのまま入ります。** 組み直していないので、
`.md` を開けば書いたものがそのまま読めます
(⚠ 組み直すと、こちらが知らない書き方を**黙って落とす**ためです)。
🔑 **添付の参照は相対パスに書き換わります**(`asset:…` → `assets/…`)──
展開したフォルダをそのまま別の markdown ビューアで開いても**画像が出ます**。

**これが他の形式への入口です。** 展開したフォルダで、たとえば:

```
pandoc -f gfm ノート.md -o ノート.epub
pandoc -f gfm ノート.md -o ノート.tex
```

Word / PowerPoint / PDF は**アプリの中に口があります**(上の表)ので、
Pandoc が要るのは**それ以外の形式**(EPUB / LaTeX / reST など)のときです。

⚠ **PKC3 だけの書き方は、他の道具には伝わりません**:

| 書き方 | 他の道具でどう見えるか |
|---|---|
| `+++`(改頁) | ⚠ **ただの `+++` という行**として出ます(改頁になりません) |
| `{{vars.…}}` | ⚠ **書いたままの文字**として出ます(値に置き換わりません) |
| ```` ```mermaid ```` / ```` ```chart ```` | ⚠ **原文のコードのまま**です(絵にはなりません) |
| `:::toc` / `:::if{…}` などの囲み | ⚠ **囲みとして読まれるとは限りません** ── 書き方が PKC3 独自(`:::名前{鍵=値}`)なので、道具ごとに扱いが違います |

🔑 **読む側が知らない書き方も、消えません** ── そのままの文字として残ります。

⚠ ただし `.md` は**本文をそのまま写しただけの file ではありません**。次の 3 つは変わります:

- **添付の参照**が相対パスに書き換わります(上のとおり ── 書き換えないと外で画像が出ません)
- **文書の情報**(`---` の中)に、題名と種類が**書き足されます**
  ── ⚠ 同じ鍵を自分で書いていた場合は**上書きし、書き出したあとの行でそう言います**
- **添付そのもののノート**には、その file への**参照行が 1 本足されます**
  ── 足さないと中身が空の `.md` になり、外から辿り着けません

⚠ 値を置き換えた形が要るときは、**Word か PDF で出してください** ──
そちらは画面と同じ材料で組むので、`{{vars.…}}` は値に、`+++` は改頁になります。

⚠ **履歴・relations・アプリの登録は入りません**(→ 上の表)。戻せる形が要るときは
「バックアップ」です。

#### 閲覧用 HTML の見え方

本文は**書いたとおりの形**(見出し・箇条書き・表・コード・リンク・添付)で出ます。
書き出すときに PKC3 の中で描いて焼き込むので、開く側には何も要りません。

**本文の幅もアプリの画面と同じ**です。散文(段落・見出し・箇条書き)には読みやすい幅の
上限が掛かり、**表・図・コードは横幅いっぱい**を使います(横に広いほど読めるため)。
紙に印刷したときも同じ組み方です。

- **図(mermaid)とグラフ(chart)は原文のまま**出ます(絵にはなりません)。絵で渡したいときは、
  図の右上の **図を保存** で SVG を出してください
- **履歴・relations・アプリの登録**は入りません(→ 上の表)

#### 目次と印刷

左の列は 2 つの**折りたたみ**に分かれています。見出し(▸)を押すと畳めます。

| 器 | 中身 |
|---|---|
| **ノート** | 入っているノートの一覧 |
| **この文書の目次** | 開いているノートの見出し(`#`〜`###`)。行を押すとその場所へ移ります |

見出しが 1 つも無いノートでは「**見出しがありません**」と出ます(空の器は残しません)。

印刷は 2 通りです。

| ボタン | 出るもの |
|---|---|
| **この文書を印刷** | 開いているノート 1 件。先頭にそのノートの目次が付きます |
| **全体を印刷(N 件)** | 全体の目次 → ノート 1 件ずつ(ノートごとにページが変わります) |

ブラウザの印刷から **PDF に保存**を選べば PDF になります。紙・PDF では:

- 左の列は出ません(**目次は本文の先頭に付きます**)
- 折りたたんでいた器は**開いた状態で**出ます。印刷が終わると畳んだ状態に戻ります
- 見出しがページの最後で独りにならないようにし、コード・表・引用・画像は途中で切りません

⚠ **全体を印刷**は全件をいったん組み立てます。印刷が終わる(またはノートを選び直す)
と組み立てたものは捨てます ── ノートが数千件あると、組み立ての間だけ重くなります。

### 取り込む

左の列のいちばん下の **取り込む** から選びます。
⚠ **編集中は押しても開きません**(「編集を終了してから取り込んでください」と出ます)──
ファイルを選び終わってから断られる、を避けるためです。

- **PKC2 の書出し全 9 形式**(単一 HTML + ZIP 8 種)→ §移行ガイド
- **素の `.md` / `.markdown`** ── 複数選択できます(1 件ずつノートになります)
- **PKC3 のバックアップ**(`.pkc3.zip`)
- **連絡先**(`.vcf` / `.vcard`)── 1 枚が 1 ノートになります(→ §連絡先)

判別は**拡張子ではなく中身**(先頭バイトと manifest)で行います。
⚠ ただし**連絡先だけは拡張子で見分けます**(`.vcf` / `.vcard`)。
判別できないものは**推測せずに断ります**。

⚠ 取込で落ちたもの・書き換えたものは、**画面に全件出ます**(1 行の status に
埋もれません)。閉じるまで残ります。

### 見ている頁をブックマークで取り込む

読んでいる記事を、**ブックマークバーのボタン 1 つ**で PKC に取り込めます。

⚠ **はじめに設定が要ります**(既定では取り込みません)。左の列の **フラグ** で
**「ブックマークで見ている頁を取り込めるようにする」を入**にして、再起動してください。

#### ブックマークの作り方

1. ブックマークを 1 つ新しく作ります(名前は「PKC に取り込む」など、お好きな字で)
2. **URL のところ**に、下の 1 行を貼ります
3. ⚠ `PKC_URL` を、**ご自分の PKC のアドレス**に置き換えてください
   (アドレス欄に出ている、`#` より前の部分です)

```
javascript:(function(){var U='PKC_URL';var w=window.open(U+'#pkc?capture=1');function h(e){if(e.source!==w||!e.data||e.data.pkc3!=='capture-ready')return;window.removeEventListener('message',h);var s=String(window.getSelection()||'');w.postMessage({jsonrpc:'2.0',id:1,method:'pkc.createEntry',params:{grant:e.data.grant,title:document.title,body:(s?s+'\n\n':'')+'出典: '+location.href}},new URL(U).origin);}window.addEventListener('message',h);})()
```

#### 使い方

1. 取り込みたい頁を開きます(取りたい部分を**選択**しておくと、それが本文に入ります)
2. ブックマークを押します
3. **新しいタブで PKC が開き、取り込んだノートが編集の形で出ます**
4. そのまま **保存** すると残ります。要らなければ捨ててください
5. ⚠ **元の記事のタブはそのまま**です(退きません)

入るのは **題名(頁の題)/ 選んだところ / 出典の URL** の 3 つです。

#### ⚠ 知っておいてほしいこと

- 取り込みを受けるのは、**そのブックマークで開いたタブの、最初の 1 通だけ**です
  (60 秒で切れます)。ふだん開いている PKC のタブは**何も受けません**
- ⚠ **相手が誰かは確かめていません** ── だから届いたものは**黙ってしまい込まず、
  編集の形で目の前に出します**。見て、要らなければ捨ててください
- 記事の本文を**アドレスに載せません**(ブラウザの履歴に残らない / 長さの制限も無い)
- ⚠ 画像は取り込みません(本文の字だけです)

### 添付の画像・PDF を別の窓で見る

添付が**画像**または **PDF** のとき、詳細に **別の窓で見る** が出ます。押すとその添付だけの
窓が開くので、**本文を書きながら見られます**。窓の題名には**添付の名前**が出ます。

- **画像** … 小さな窓で開きます。対応しているブラウザでは、常に手前に留まる小窓
  (ピクチャーインピクチャー)になります
  - 🔑 窓の中の **＋** / **−** / **等倍** / **収める** で大きさを変えられます。
    **開いた直後は今までどおり窓に収まる大きさ**で、**等倍**を押すと実寸になります
  - 🔑 大きくした絵は**掴んで動かすと送れます**
- **PDF** … 頁を繰って読めるように**大きな窓**で開きます(常に手前の小窓にはしません)

⚠ 窓を閉じると、その添付のために使っていたメモリはすぐに返します。
⚠ ポップアップを止めている設定だと開けません(そのときは画面に理由が出ます)。

### ノート同士をつなぐ(関係)

右の情報ペインの **関係** に、そのノートが持つつながりが出ます。

- 足すには、下の欄に**相手の題名**を打ち(候補が出ます)、種類を選んで **関係を足す**
- 種類は **関連 / 分類 / 時系列 / 出典** の 4 つです
- 相手の題名を押すと、そのノートへ移ります
- 消すには、その関係の **消す** を押します(⚠ ノート自体は消えません)

⚠ **居場所(フォルダの親子)はここでは作れません** ── あちらは **フォルダ** タブで
移動すると付きます。同じことを 2 通りで作れると、どちらが本当か分からなくなるためです。
⚠ 同じ題名のノートが複数あるときは、**どれか分からないので足せません**(題名を分けてください)。

#### つながりの図

関係の下に **つながり** の欄が出ます。**いま選んでいるノートを真ん中**に、
つながっている相手が円く並びます。

- **相手を押すと、そのノートへ移ります**(図を見て、そのまま辿れます)
- 出るのは **2 手先まで**(相手の相手まで)です
- 下に **関連 3 / 出典 1** のように、線の種類と本数が出ます
- つながりが多いときは**途中で切り、切ったことを書きます**
- **本文に書いたリンクは破線**で出ます(`[題名](entry:…)` で張ったもの、
  および `pkc://` の**この容れ物あて**)。相手から自分への参照(参照元)も
  同じ破線で出ます

⚠ **破線は、真ん中のノートの分だけ**です。2 手先のノートが本文に書いているリンクは
出ません(出すには全部の本文を読み直すことになり、選ぶたびに重くなるためです)。
実線の関係のほうは 2 手先まで出ます。

⚠ **つながりが 1 つも無いノートでは、この欄ごと出ません**(点 1 つを図にしません)。
⚠ **居場所(フォルダの親子)は図に出ません** ── 出すとフォルダの木になってしまい、
見たいもの(意味のつながり)が埋もれるためです。

### タグを、その場で打つ

右の情報ペインの **タグ** の行に、**打つ欄**があります。打って `Enter` で付きます。

| したいこと | どうするか |
|---|---|
| **付ける** | 欄に打って `Enter`(隣の **+** でも同じです) |
| **外す** | 付いている札の **×** を押します |
| **そのタグで探す** | 札の**名前のほう**を押します |

- 🔑 **欄に触ると、すでに使っているタグが候補に出ます** ── 同じタグを打ち間違えて
  増やさずに済みます。⚠ 候補に無い**新しいタグ**も、そのまま打てば付きます
- ⚠ 付いたタグは**本文の先頭**(`tags:` の行)に入ります ── 書き出しにも
  別の端末にも、そのまま乗ります
- ⚠ **編集中は欄が出ません**(本文は編集の側が持っているためです)。保存してから触ってください
- ⚠ 本文の先頭が**読めていない**とき(閉じの `---` が無い等)も出ません ──
  そのときは行に「読めていません」と出るので、先に本文を直してください

### 本文の中にタグを打つ(編集しながら打てます)

本文の**行そのもの**をタグの行にできます。

```
# 買い物メモ

#買い物 #家事

牛乳と洗剤
```

- 🔑 **井桁のすぐ後ろに空白を置かない**のが、見出しとの分かれ目です ──
  `# 買い物` は見出し、`#買い物` はタグです
- 🔑 **タグ同士は空白で区切ります**(半角・全角・タブのどれでも構いません)
- ⚠ **その行だけ**がタグの行です。前後に別の字があるとタグになりません
- 🔑 **そのタグは、その行が入っている見出しに付きます** ── どの章で付けたのかが残ります
- ⚠ **番号だけの名前はタグになりません**(`#117 #121` のような行を守るためです)。
  番号をタグにしたいときは `#no117` のように字を混ぜてください
- ⚠ ``` で囲んだ中は見ません(コードの中の `#` はそのままです)

🔑 **こちらは編集しながら打てます** ── 上の「その場で打つ」欄は保存してからでないと
触れませんが、本文の中なら**書いている途中でそのまま**打てます。

### 本文のタグの見え方

読んでいるとき、本文のタグ行は**札の形**で出ます(文章と見分けやすくするためです)。

- 🔑 **札を押すと、そのタグで一覧が絞られます** ── 読みながらそのまま辿れます。
  ⚠ 編集しているあいだは押せません(本文の字を触っている最中に面が動かないように)
- 🔑 **見せ方は選べます** ── 設定の **本文のタグの見せ方** で
  「**札**(既定)/ **枠の札** / **文字のまま**」から選べます。押すとその場で効きます
- ⚠ **本文そのものは変わりません** ── 書いた字はそのままで、見え方だけが変わります
- ⚠ **書き出した HTML でも札で出ます**(そちらは押せません ── 受け手が居ないためです)

🔑 **保存のときに重複はまとめられます** ── 同じタグを何度書いても 1 つに数えます。
⚠ **本文の先頭(`tags:` の行)は書き換えません** ── そちらは user が直接書く場所のまま、
本文の中に書いたぶんはアプリの側が集めて憶えます。

🔑 **スマートフォルダは、どちらのタグでも集めます**(先頭に書いたタグと同じ扱いです)。
⚠ 既にノートを持っている場合、本文の中のタグは**次に起動したとき**にまとめて集められます。

### まとめてタグを付ける・外す

フォルダタブで **2 件以上**選ぶと出る帯に、タグの欄と **タグを付ける** / **タグを外す**
があります。選んだぶんの本文に、まとめて書き込みます。

- ⚠ 相手は**いま表に出ている印**だけです(絞り込みで消えた行は触りません)
- ⚠ 既に付いているものは**書き直しません**(更新日時が動きません)
- 結果は「**3 件に付けました / 1 件は既に付いていました**」と 1 通で出ます
- 🔑 **外すのも同じ帯から**できます(付けるだけの片道にはしていません)

### 予定タブから、その場でやることを足す

予定タブの上に **やること** の欄と日付、**足す** があります。押すと、
**今日のノートの末尾**に `- [ ] やること @日付` の形で書かれます。

- 🔑 **日付の欄は、最初から今日で埋まっています** ── そのまま押せば**今日のところ**に出ます
- 日付の束の見出しの **+** を押すと、**その日**が上の日付欄に入ります(書きません)
- ⚠ 日付を**空にしてから**押すと、日付なしのやることになります
- 🔑 足したものは**その場で面に出ます**(開き直す必要はありません)
- ⚠ **画面は切り替わりません** ── 予定を眺めたまま足せます
- 今日のノートがまだ無ければ、**作ってから**書きます

### 掴んだまま、別のタブへ持っていく

左の列で行や札を**掴んだまま**、上のタブ(一覧 / フォルダ / アプリ / 予定)の上で
**少し止める**と、その面に切り替わります。手を離さずに、フォルダの行を予定の日へ
持っていけます。

- ⚠ **通り過ぎただけでは変わりません**(止めたときだけです)
- ⚠ **タブの上で離しても何も起きません** ── タブは通り道であって、入れ物ではありません
- ⚠ パソコンの中のファイルを運んでいるときは効きません(落とす先が消えるためです)

## 6. 履歴とゴミ箱

- **履歴** … 右の情報ペインの **履歴** ボタン。過去の版に**復元**できます。
  ⚠ 戻す前の状態も履歴に積まれるので、**戻したことも取り消せます**
- 履歴は 1 ノートあたり**最新 100 件**まで保たれます

### 戻す前に中身を見る

履歴の行には、**その版と 1 つ新しい版のちがい**が `+12 −3` の形で出ます。
題名が同じ版が並んでいても、どれが大きく変わった版かがひと目で分かります。

⚠ 数が出ない版もあります ── その版を**まるごと**持っているときは、
くらべる相手が居ないので**何も出しません**(`+0 −0` とは書きません。
「変わっていない」という嘘になるためです)。

**行そのものを押すと**、その版と**いまの本文**のちがいが下に開きます。

- `+` が足された行、`−` が消された行です(色が見えなくても印で分かります)
- 変わっていない所は **⋯ 変わっていない N 行** と畳まれます
- ⚠ **読むだけです。1 バイトも書きません**(戻すのは隣の **復元** です)
- もう一度押すか **閉じる** で畳みます。履歴を閉じても一緒に畳まれます
- **ゴミ箱** … 左の列の **フォルダ** タブの中。消したノートはここに入り、**戻せます**
- **ゴミ箱を空にする** … ⚠ **不可逆**。確認を出します

## 7. 添付

左の列の上にある **添付** からファイルを入れます(複数選択できます)。
実体は IndexedDB に入り、**1 ファイル = 1 ノート**(種別「添付」)になります。

添付の画面には、画面に出せるものはその場で出ます(画像・音声・動画・PDF・
文字のファイル)。**PDF は器いっぱいの高さで出ます**(ブラウザの PDF ビューアが
そのまま動くので、拡大・頁送り・検索が使えます)。**出せない種類**(zip など)は、
そう書いてあります ──
「この種類は画面に出せません。上の**ダウンロード**で保存して開いてください」。
⚠ **PDF を出せないブラウザ**では、その場に「上のダウンロードから開いてください」と出ます。
⚠ 何も出ないまま黙っていることはありません(中身が空なのか出せないのかが
分からない、という状態を作らないため)。

### 7-0. 大きな写真は「縮めますか」と聞きます

携帯の写真は 1 枚 5〜12MB あるので、**そのまま入れると数枚で器を圧迫します**。
**長辺が 2048px を超える大きな画像**(1.5MB 以上)を添付すると、こう聞きます:

```
大きな画像です(4000×3000 / 11.4 MB)。
2048×1536 / 1.4 MB に縮めて取り込みますか?
⚠ 縮めると元の細かさは戻りません。そのままでよければ「いいえ」を選んでください。
```

- **縮める** … 縮めたほうが入ります(**元の画素は戻りません**)
- **そのまま** … 原寸のまま入ります

⚠ **数字は見積もりではありません** ── 先に縮めてから、**実際にできた大きさ**を
お見せしています。断ったときは、縮めたほうはその場で捨てます。

🔑 **勝手には縮めません。** 写真はあなたのもので、縮めるのは取り消せないからです。

⚠ 次のものは**触りません**:
**1.5MB 未満**の画像 / **長辺 2048px 以下**の画像 / **SVG**(画素ではない)/
**GIF**(動きが失われる)/ 画像でないファイル。
⚠ **形式は変わりません**(PNG は PNG のまま ── 透過が落ちないように)。
⚠ 縮めてもあまり小さくならなかったときは、**聞かずに原寸のまま**入れます。

### 7-1. スクリーンショットを貼る・ファイルを落とす

🔑 **編集中の本文に、スクリーンショットをそのまま貼れます。** 画像をコピーした状態で
本文の欄を選び、`Ctrl+V`(Mac は `Cmd+V`)を押してください。**カーソルの位置**に
`![スクリーンショット-2026-08-18-143005.png](asset:…)` の 1 行が入り、
確定すると**本文の中に画像として出ます**。

- **何枚でも入ります** ── クリップボードに画像が複数あれば、**全部**入ります
- **取り消せます**(`Ctrl+Z`)── 入った行は普通の文字と同じ扱いです
- **名前は貼った日時**から付きます(クリップボードの画像に名前は無いため)。
  添付の一覧でもその名前で並びます
- **継ぎ足しの欄**(「追記する内容」)にも同じように貼れます
- ⚠ **編集していないときに貼る**と、本文には入らず**添付のノート**になります
  (左の列の **添付** ボタンと同じ結果です)
- ⚠ 画像が無いとき(文字のコピーなど)は**普通の貼り付け**です。邪魔をしません

**ファイルを画面へ落として(ドラッグ&ドロップ)入れることもできます。**

| 落とす先 | どうなるか |
|---|---|
| **編集中の本文**(文字を打つ欄) | 画像は**本文に入ります** |
| **それ以外のどこか**(編集していないとき) | 全部**添付のノート**になります(複数まとめて落とせます) |

⚠ **編集中は、画像以外のファイルを受け取れません**(「編集を終了してから添付して
ください」と出ます)。⚠ **画像が 1 枚も無い**貼り付けは、次の「文字を貼る」の
扱いになります ── 変換するものが無ければ**普通の貼り付け**です(邪魔をしません)。

⚠ 貼っている最中に**別の欄を触る**と、書いていた行が閉じて差し込み先が無くなります。
そのときは画面の下に理由が出ます ── 編集を抜けていれば**添付として残り**、
まだ編集中なら「もう一度貼ってください」と出ます(クリップボードは残っています)。

⚠ 落とした瞬間に**画面がそのファイルへ切り替わってしまう**ことはありません
(ブラウザの既定の動きは止めています ── 書きかけの本文を失わないためです)。
⚠ 整理(**使っていない添付を消す**)の最中に貼ると、**断ります** ── 消す走査と
同時に置くと、置いたばかりのものを「使っていない」と数えてしまうためです。
画面には「添付の取込 / 整理が実行中です。完了してから、もう一度選び直してください」と
出ます。終わってからもう一度貼ってください(クリップボードは残っています)。

左の列のいちばん下の **使っていない添付を消す** で、**どのノートからも参照されていない**添付を消せます。
⚠ 自動では消しません(明示操作のみ)。⚠ 不可逆なので確認を出します。
🔑 **他のタブが編集中のときは、整理は断ります。** 編集中の本文に貼った画像は、保存するまで
「どのノートからも参照されていない」と数えられるためです ── 「他のタブで編集中です。
そちらを保存してからもう一度お試しください」と出ます。
⚠ 本体タブと話せないときは「**確かめられません**」と出て、やはり整理しません
(「編集中です」とは言いません ── 探しても見つからないタブを探させないためです)。

⚠ 整理・取込・書出しの最中は、削除などの壊す操作は止まります
(走査中に消えると「書き出したつもりでファイルが 1 個も落ちていない」状態になるため)。

### 7-2. 文字を貼る(ウェブページ・AI の回答)

🔑 **ウェブページや AI の回答をコピーして本文に貼ると、形のまま入ります。**
見出し・箇条書き・番号付き・表・コード・引用・リンク・強調が、PKC-Markdown の
記法に**戻って**入ります(貼ったあとに書き直す必要がありません)。

| コピー元にあるもの | 入る形 |
|---|---|
| 見出し | `## 題` |
| 箇条書き / 番号付き(入れ子も) | `- 項目` / `1. 項目`(字下げも保ちます) |
| チェックの付いた一覧 | `- [x] 済み` / `- [ ] まだ` |
| 表 | GFM の表(`\|` を含むセルも壊れません) |
| コード(言語つき) | ``` ```ts ``` のコードフェンス |
| 引用 | `> 引用` |
| リンク・画像 | `[題名](URL)` / `![説明](URL)` |
| 太字・斜体・打ち消し・行内コード | `**太字**` / `*斜体*` / `~~打ち消し~~` / `` `コード` `` |

🔑 **ページの図(SVG)も、図のまま保存します。** ウェブページに描かれている図形は
そのままの形(ベクタ)で添付になるので、**拡大しても粗くなりません**。
⚠ 図の中に仕込まれた script は取り込みのときに落とします(書き出した図を別のアプリで
開くことがあるためです)。

🔑 **本文に埋め込まれた画像は、添付として保存します。** コピー元のページが画像を
`data:`(文字として埋め込んだ画像)や `blob:`(そのページの中だけで生きる画像)で
持っている場合、そのまま貼ると**あとで開いたときに消えます**。PKC3 は貼った時点で
**添付として取り込み**、本文の参照を `asset:` に書き換えます ──
本文に出る説明は、コピー元が付けていた説明(`alt`)をそのまま使います。
⚠ 読み込めなかったものは**元の参照のまま残し**、画面の下に理由を出します
(黙って消しません)。

⚠ **ふつうのリンクの画像**(`https://…`)は、貼った時点では取り込みません ──
元の場所を指したままです。既定では**外部の画像を読み込む前に確認**するので、
貼った直後は枠だけが出ます(読む面で「このノートで読み込む」を押すと出ます)。
⚠ 相手のサイトから消えれば、その画像も見えなくなります。
🔑 **手元に残したいときは、右の列の「外部の画像を取り込む」を押してください**
(すぐ下)。

#### 外部の画像を、あとから手元へ取り込む

貼り付けたウェブページの画像は `https://…` を指したままなので、**相手のサイトから
消えれば見えなくなります**。手元に残したいときは、そのノートを開いて右の列の

> **外部の画像を取り込む(3 枚)**

を押してください。⚠ **枚数はそのノートに書かれている外部画像の数**です
(同じ URL が 2 回出てきても 1 枚と数えます)。

| 何が起きるか | |
|---|---|
| 押すと | その画像の**置き場所へ通信します**(枚数のぶんだけ) |
| 読めたもの | このノートの**添付**になり、本文が `asset:` を指すように変わります |
| 読めなかったもの | **元の URL のまま残ります**。画面の下に**理由**が出ます |

🔴 **押すことが「外へ通信してよい」という返事です。** だから自動ではやりません ──
相手のサーバーに「この端末がいまこれを開いた」ことが伝わるためです(→ §4-2「外部の画像」)。
⚠ **本文に 1 枚も無いときはボタンごと出ません**(押しても何も起きない物は置きません)。
⚠ **ノートを開いていない**(本文がまだ読めていない)ときも出ません。
⚠ **編集中は押せません**(保存するか取り消してください)。

読めなかったときの理由は、たとえばこうです:

| 出る字 | 意味 |
|---|---|
| 置き場所が 404 を返しました | その URL にはもう画像がありません |
| 読み込めませんでした(置き場所が許可していないか、届きませんでした) | 相手のサイトが**他所からの読み取りを許していない**か、繋がりませんでした。⚠ **画面には出るのに取り込めない**ことがあります(見るのと読み取るのは別の許可です) |
| 画像ではありませんでした(text/html) | その URL から返ってきたものが画像ではありませんでした |
| 添付を保存する空き容量が不足しています | この端末の空きが足りません(→ §4-3「使っている量」) |

🔑 **同じ URL をリンク(`[記事](https://…)`)としても書いている場合、そちらは
変わりません** ── 押したのは画像の取り込みであって、リンクを添付へ差し替える
ことではないからです。

#### リッチテキスト(生成 AI チャット / Word / ワードパッド / テキストエディット)

🔑 **書式付きの文字も、形のまま入ります。**

Word・Excel・Google ドキュメント・LibreOffice からコピーしたものは、上の表と
**同じように**入ります(こうしたアプリはウェブページと同じ形もクリップボードに
載せるので、そちらを読んでいます)。

🔑 **そのうえで、「リッチテキスト」しか渡してこないアプリにも対応しました** ──
Windows の**ワードパッド**、Mac の**テキストエディット**(リッチテキスト書類)、
一部のアプリがそれです。⚠ **これまではこうしたアプリから貼ると、書式が丸ごと
落ちてただの文字になっていました。**

| コピー元にあるもの | 入る形 |
|---|---|
| 見出し(スタイルで「見出し 1」を当てたもの) | `# 題` |
| 箇条書き / 番号付き(入れ子も) | `- 項目` / `1. 項目` |
| 表 | GFM の表 |
| リンク | `[題名](URL)` |
| 太字・斜体・打ち消し | `**太字**` / `*斜体*` / `~~打ち消し~~` |
| 下線 | `:文字:underline:` |
| **コード** | コードの囲み(``` ``` ```)。文の途中は `` `行内コード` ``。コピー元が「ここはコード」と印を付けているか、等幅で書かれている行が対象です |
| 貼り込まれた画像(PNG / JPEG) | 添付として取り込み、`asset:` を指します |

🔑 **生成 AI チャットの回答も、コードごと入ります。** 回答を選んでコピーすると、
説明とコードが**そのまま**の形で入ります ── コードは囲みになり、続いた行は
**1 つの囲み**にまとまります。

⚠ **入らないものもあります**(黙って化けさせないために書きます):

- **コードの言語**(``` の後ろに付く `ts` など)── リッチテキストは言語を
  持ちません。⚠ コピー元がウェブページの形も渡してくるとき(生成 AI の多くと
  Word / Google ドキュメント)は**そちらを読む**ので、言語も入ります
- **図形の画像(WMF / EMF)** ── ブラウザで描けない形式なので落とします
  (PNG / JPEG の画像は入ります)
- **見出しに見えるだけの大きい文字** ── 「見出し 1」のスタイルや見出しの印が
  付いていないものは、ふつうの段落として入ります

⚠ **文書を丸ごと等幅フォントで書いてある場合は、コードにしません** ──
「ここがコード」という対比が無いためです(全部が囲みになってしまいます)。

#### 🔑 うまく入らないときは、読み取る形を切り替えられます

**設定 → 貼り付け → 読み取る形**。

コピーすると、**同じ内容が複数の形**(ウェブページの形 / リッチテキスト /
ただの文字)で持ち回られます。⚠ **どれが正確かは相手のアプリによって違う**ので、
PKC3 のおまかせが当たらないことがあります ── そのときはここで切り替えてください。

| 選ぶもの | どうなるか |
|---|---|
| **自動**(既定) | ウェブページの形を先に読み、無ければリッチテキストを読みます |
| **ウェブページの形だけ** | リッチテキストを読みません。リッチテキストの変換が合わないときに |
| **リッチテキストを優先** | リッチテキストを先に読みます。生成 AI の貼付が崩れるときに |
| **ウェブページの形をそのまま(html の囲み)** | **変換しません。** ` ```html ` の囲みに入れて、**見た目のまま**残します |
| **変換しない** | コピーした文字をそのまま貼ります(書き換えを一切しません) |

- 🔑 **大きさで断りません。** 以前はウェブページの形が 1MB、リッチテキストが 4MB を
  超えると読まずに平文へ落としていましたが、**画像が埋め込まれたページは 1MB を
  軽く超える**ので、いちばん貼りたいものが貼れませんでした。上限は撤廃しています。
  ⚠ とても大きいページでは、貼った直後に**一瞬待つ**ことがあります
  (実測: 1MB で約 0.07 秒、4MB で約 0.2 秒)。
- ⚠ 読んだけれど戻せなかったときは、**フラグを点けると理由が出ます**
  (「変換しても得るものがありませんでした」)

##### 「ウェブページの形をそのまま(html の囲み)」について

PKC3 はふだん、ウェブページの形を **PKC-Markdown へ戻します** ── 見出し・箇条書き・
表・コードの囲み・太字は、これで正しく戻ります。
⚠ ですが **markdown に無い形**(色 / 段組 / SVG / 凝ったレイアウト)は**落ちます**。

これを選ぶと、**変換せずに ` ```html ` の囲みへ入れます**。囲みの中身は
**箱(sandbox)の中**で描かれるので、見た目がそのまま残ります。

- ⚠ **あとで直すときは HTML を触ります**(誤字 1 つでもタグの中を直すことになります)
- ⚠ **囲みにできるのはウェブページの形だけ**です。リッチテキストしか届いていないときは、
  そのままの文字で貼られます(理由はフラグを点けると出ます)
- 🔑 中身に ``` が入っていても大丈夫です ── **囲みのほうを長くします**

🔑 **どれに切り替えればよいか分からないときは、フラグを点けてください。**
**フラグ → 「貼り付けたとき、何が届いてどれを使ったかを画面に出す」**を入にすると、
貼るたびに **何が何字届いて、どれを使ったか**が画面の下に出ます
(⚠ **中身は出しません** ── 大きさと判断だけです)。

⚠ **リッチテキストを読めるのは Chrome 系のブラウザだけ**です。Firefox は
リッチテキストの受け渡しに既知の不具合があるため、そこでは自動的に
ウェブページの形かただの文字になります。

⚠ 生成 AI の「コピー」ボタンは、**Alt(Mac は Option)を押しながら**押すと
markdown の原文をくれることがあります ── その場合 PKC3 は**原文をそのまま**入れます
(見た目から作り直すより、原文のほうが必ず正確だからです)。

🔑 **このアプリの中のノートへのリンクを貼ると、押せるリンクになります。**
ノートの場所を指す文字(`pkc://…/entry/…`)をコピーして本文に貼ると、
**そのノートの題名が付いた内部リンク**として入ります ── 押すとそのノートが開きます。

⚠ **別の入れ物のノート宛は、そのままです**(持ち運べる参照として残します)。
⚠ **こちらに無いノート宛も、そのままです** ── 在りもしない題名を書かないためです。

⚠ **横取りしない場面があります**(そのほうが正確だからです):

- **コピー元が markdown 原文を渡してきたとき** ── AI チャットの「コピー」ボタンは
  たいてい原文(` ``` ` や `#` の付いた文字)を渡します。この場合は**原文をそのまま**
  入れます。見た目から作り直すより、原文のほうが必ず正確です
- **形のない文字**(ただの平文)── 普通の貼り付けです
- **前後に文が付いたノートへのリンク** ── 文の途中に混ざった `pkc://…` は書き換えません
  (書いた文をこちらの都合で組み替えないためです)
- **題名の欄・絞り込みの欄** ── 変換しません(本文の欄だけです)

⚠ 平文として貼った文字が**記法に化けることはありません** ── 行頭の `- ` や `#` は
そのままの見た目で入ります(`\-` のように逃がして入れます)。

### 7-3. ランチャー

左の列の **アプリ** タブに、アプリとして登録した添付が並びます。

| タイル | 押すと |
|---|---|
| アプリ(HTML の添付) | **新しいタブ**で、隔離した器の中に開きます |
| URL(行き先のホスト名が右に付きます) | **新しいタブ**でそのサイトを開きます |

**アプリとして登録する** ── HTML のファイルを添付し、その添付の画面にある
**アプリとして登録** にチェックを入れます。チェックを入れると、同じ場所に
**グループ** と **目印** の欄が出ます。

- グループ名を付けると見出しでまとまります(**名前順**に並びます)。付けないものは先頭
- 目印は絵文字 1〜2 字。付けると行の左に出ます
- PKC2 から取り込んだ順番(`app_order`)はそのまま引き継ぎます
- サイドバーの **絞り込み** がここでも効きます

🔑 URL タイルを押しても、**相手のサイトにはあなたがどこから来たか伝わりません**
(リンク元も、開いた元のページへの参照も渡していません)。

🔒 **取り込んだ HTML は、あなたのノートに手が届きません**。アプリのタイルは
隔離した器(サンドボックス)の中で動くので、中の HTML から保存済みのノート・
添付・設定を読むことはできません。

**アプリは状態を保存できます**。器の中では、そのアプリ専用の保存領域が
`localStorage` として見えます ── 同じタイルを開き直すと続きから使えます。
⚠ 保存できるのは **1 アプリ 2MB** までです(超えるとアプリ側に
`QuotaExceededError` が返り、画面の下にも 1 行お知らせが出ます)。
⚠ この保存領域は**ノートの書き出しに含まれません**(バックアップから戻しても
アプリのデータは戻りません)。⚠ ノートを消すと、そのアプリのデータも消えます。
#### 素のまま起動する(そのアプリにノートを渡す)

⚠ 囲いの中では **IndexedDB / cookie / Cache / Service Worker が使えません**。器の中は
「どこにも属さない場所」なので、これらは**触ることすら**できません。

これらに触ったアプリは、**画面の上に 1 行**出します ──
「このアプリは IndexedDB を使おうとしましたが、囲いの中では使えません」。
⚠ 触っても**そこで止まりません**(2026-08-06 に直しました)── 「無い」ものとして
見えるので、代わりの保存(囲いの中の 2MB)へ切り替えられるアプリはそのまま動きます。
それでも動かないアプリは、**画面の下に 1 行**理由が出ます。

そういうアプリは、その添付の画面の **素のまま起動** で開きます。

🔑 **「同じ場所」はウィンドウのことではありません。** 窓はどちらでも**別窓**で開きます ──
変わるのは**データの入れ物**のほうです:

| | そのアプリは誰として動くか | PKC3 のノート・添付・設定 |
|---|---|---|
| ふつうの **起動** | **よその人**(どこにも属さない場所) | 🔒 触れません |
| **素のまま起動** | **PKC3 と同じサイトの人** | 🔓 **全部読めますし、書き換えもできます** |

だから押すと確認が出ます ── ボタンは **ノートを渡して開く** です。
⚠ 保存先も変わります ── 囲いの中で貯めた内容は、素のままでは**見えません**。

##### 一度許したら、次からは聞きません(アプリとして登録したものだけ)

**アプリとして登録**した添付は、一度 **ノートを渡して開く** を押すと**その中身については
次から聞きません**(期限はありません)。ランチャーのタイルを押すだけで素のまま開きます。

⚠ **憶えているのは「中身」であって「そのノート」ではありません。** 中身を別のものに
差し替えると**また聞きます**(同じ名前でも、1 バイトでも違えば別物として扱います)。
⚠ **登録していない添付は憶えません** ── その画面を開いている間だけ有効で、
読み込み直すとまた聞きます。
⚠ 憶えた許可は **設定 → 素のまま起動を許したアプリ** から**いつでも取り消せます**。

🔴 **承知しておいてほしいこと。** 素のままのアプリは PKC3 と同じ場所で動くので、
**この許可の一覧そのものも書き換えられます**。つまり、**悪意のある HTML を 1 度でも
許してしまうと、そのアプリが他のアプリを「許可済み」に足すことができます**。
⚠ これは保存先を変えても防げません(同じ場所で動く以上、どこに置いても届きます)。
知らない相手からもらった HTML には **ノートを渡して開く** を押さないでください。

#### 目次を見せて起動する(アプリにノートの一覧を読ませる)

囲いの中のアプリは、これまで PKC3 の中を**一切**見られませんでした。
「今日の予定を出す」「ノートを数える」といったことをさせたいときは、
その添付の画面の **目次を見せて起動** で開きます。

| | アプリに見えるもの |
|---|---|
| ふつうの **起動** | 🔒 何も見えません |
| **目次を見せて起動** | 📋 ノートの**題名・種類・日付・印**の一覧だけ |
| **素のまま起動** | 🔓 本文も添付も設定も全部(上の節) |

🔑 **目次だけでは本文も添付も渡りません。** アプリが「この本文を見せて」と
**頼む口はありません** ── 取りに行く仕組みそのものが無いので、頼まれても渡りません。

##### 1 件だけ渡す(このアプリへ送る)

本文を渡したいときは、**あなたが 1 件ずつ渡します**。ノートを選んで、右の情報ペインの
**このアプリへ送る** を押してください。開いているアプリの名前が並びます。

- 渡るのは **押した 1 件だけ**です(本文つき)
- ⚠ **添付の中身は渡りません**。本文に添付の参照が何個あるかだけが伝わります
- ⚠ アプリ側から「次はこれをください」と**取りに来ることはできません**

##### 渡した 1 件は、アプリから書き戻せます

渡したノートは、そのアプリが**直して返す**ことができます(例:フォームや表のアプリ)。

- 🔴 **書き戻せるのは、あなたが渡した物だけ**です。渡していないノートは、
  アプリが名前を知っていても書けません
- 🔴 **1 件でもおかしな依頼が混ざっていたら、全部断ります**(半分だけ書かれることはありません)
- 🔴 **書き戻しは履歴に残ります** ── アプリが書いた本文も、いつでも戻せます
- ⚠ **PKC3 で編集中は書き戻せません**(打ちかけを裏から潰さないためです)
- ⚠ その間に PKC3 側で本文を書き替えていたら、**書き戻しは断られます**
  (アプリが持っているのは古い本文なので)
- ⚠ アプリができるのは**本文を直して返す**ことだけです。新しく作る・消す・
  名前を変える口はありません

##### 一度許したら、次からは普通の「起動」でも見えます

許すと、そのアプリの**中身について**憶えます(期限はありません)。
次からは普通の **起動** を押すだけで目次が見えるので、**目次を見せて起動** のボタンは
出なくなります ── 代わりに **起動** の説明に「このアプリにはノートの目次を見せます」と出ます。

⚠ **憶えているのは「中身」であって「そのノート」ではありません** ── 中身を差し替えると
また聞きます(素のまま起動と同じ決まりです)。
⚠ 許可は **設定 → 目次を見せているアプリ** から**いつでも取り消せます**。
⚠ **素のまま起動の許可とは別**です ── 片方を取り消しても、もう片方は残ります。

⚠ HTML の添付は、**その添付の画面から** **起動** / **目次を見せて起動** / **素のまま起動**
で開けます ── 「アプリとして登録」しなくても開けます
(登録はランチャーに並べるための設定です)。

⚠ アプリのタイルを開いたタブは、**PKC3 の画面を閉じると一緒に使えなくなります**
(中身は PKC3 が渡しているためです)。

⚠ ランチャーに出るのは **HTML の添付** と **URL タイル**、それに下の
**Office のタイル**だけです(PDF や画像は一覧から開いてください)。

**Office のひとそろい(→ §4-2)を入れてある端末**では、ランチャーの先頭に
**Office** のタイルが並びます。押すと Office の窓(スタート画面)が開き、
新しい文書・表計算・プレゼンテーションを作れます。ノートの添付ではないので、
一覧には出ません。入れていない端末にはタイル自体が出ません。

### 7-4. Office の添付を読む・書く(Word / Excel / PowerPoint)

`.docx` / `.xlsx` / `.pptx`(および古い `.doc` / `.xls` / `.ppt`、`.odt` などの
OpenDocument)を添付すると、その添付の画面に **Office で開く** が出ます。
押すと**別の窓**が開いて、そこに文書が組み上がります。

🔑 **別の窓なので、PKC3 の編集を続けたまま資料を読めます。**
⚠ 窓は **1 つだけ**です。開いている状態でもう一度押すと、その窓に表示し直します。
⚠ 窓を閉じると、使っていたメモリはまるごと返ります。

**縦書き・禁則・ルビ・圏点**を含む日本語の組版がそのまま出ます(日本語フォントを
同梱しています)。

#### 手元のファイルを、そのまま開いて直す

PKC3 を**アプリとして入れている**と、`報告書.docx` を**ダブルクリック**したときに
PKC3 で開けます(`.docx` / `.xlsx` / `.pptx` / `.doc` / `.xls` / `.ppt` /
`.odt` / `.ods` / `.odp` / `.rtf`)。

1. ファイルをダブルクリックすると PKC3 が起動し、画面の下に
   **「報告書.docx を開けます ── アプリの「Office」を押してください」** と出ます
2. 左の **アプリ** タブから **Office** を押すと、その文書が開きます
3. **保存すると、元のファイルへ書き戻します**(PKC3 のノートにはなりません)

🔑 **取り込む → 開く → 直す → ノートになる → 書き出す → 置き直す**、という
6 手の往復が要りません。

⚠ **なぜ 1 度押す必要があるのか** ── ブラウザは「user が押していない窓」を
自動では開けない決まりになっています(勝手に窓が増えるのを防ぐため)。
だから**受け取ったことをお知らせして、押されたときに開く**形にしてあります。

⚠ **元のファイルへ書き戻せないとき**は、開く前に
「元のファイルへは書き戻せません(この環境が対応していません)」と出ます。
⚠ **ファイルとのつながりは、その起動の間だけ**覚えます ── PKC3 を読み直すと
切れるので、もう一度ファイルを開いてください(**知らないうちに書き込む権利を
持ち続けない**ようにするためです)。

#### 使うには、先に「ひとそろい」を入れます

初めは **設定 → Office 表示** から入れてください(約 77MB / → §4-2)。
入れる前の添付の画面には、ボタンではなく理由が出ます ──
「Office 表示にはひとそろい(約 77MB)が要ります。まだ入っていません。」

⚠ **押しても何も起きないボタンは出しません。** 開けないときは必ず理由が出ます。

#### 動くブラウザ

いまのところ **Chromium 系(Chrome / Edge など)** でだけ動きます。
Firefox / Safari では「この環境では動きません」と、足りないもの
(**JSPI** ── WebAssembly の Promise 統合)を名指しで出します。
⚠ Office 以外の機能は、どのブラウザでもこれまでどおり使えます。

#### ひとそろいの版

設定の **Office 表示** に、いま入っている版が出ます。
**配布元に別の版があるとき**は、そこに 1 行増え、起動したときにも 1 度お知らせします ──
**「取得して入れる」から入れ直せます**。

⚠ **勝手に取りに行くことはありません。** 起動時に読むのは版の目録(数百バイト)だけで、
77MB のひとそろいは**あなたが押したときだけ**取りに行きます。
⚠ 「新しい / 古い」ではなく「**別の版**」と出ます ── 版に前後の順序が無いためです
(手元のほうが新しいこともあります)。

#### 保存すると、PKC3 に残ります

Office の窓で **保存**(Ctrl+S)すると、その中身が **PKC3 に取り込まれます**。
Office の窓の中だけで完結して、窓を閉じたら消える ── ということはもうありません。

| Office でやったこと | PKC3 で起きること |
|---|---|
| PKC3 から開いた添付を**上書き保存** | **そのノートの中身が入れ替わります**(名前や説明はそのまま) |
| **新しく作った文書**を保存 / 別名で保存 | **添付のノートが 1 件できます**(名前は Office で付けた名前) |
| その文書を**もう一度**保存 | **同じノートの中身が入れ替わります**(ノートは増えません) |

取り込むと、画面の下の行に「**Office の保存を取り込みました: ⟨名前⟩**」と出ます。

🔑 **入れ替える前の中身は控えが残ります。** 控えはノートの中に積まれ、
**5 世代 / 合計 200MB** まで保ちます。それを超えると古いほうから外れます。

⚠ **PKC3 側で本文を編集している最中に保存が届いたときは、編集を終えてから取り込みます**
── 編集中の下書きを壊さないためです。取り込みは編集を終えた時点で自動で走ります。
⚠ タブを閉じてしまっても消えません ── **次に PKC3 を開いたときに取り込まれます**。

⚠ この機能は **Chromium 系のブラウザ**で動きます(内部で OPFS という置き場を使います)。
使えない環境では、窓の側で「保存を PKC へ渡せませんでした」と理由が出ます。

#### どの形式で保存できるか

**ODF**(`.odt` / `.ods` / `.odp` / `.odg`)は、開いてそのまま保存できます。

**Word / Excel / PowerPoint の形式**(`.docx` / `.xlsx` / `.pptx`、古い `.doc` /
`.xls` / `.ppt`、それに `.rtf`)も保存できます ── 保存を押すと、
**その形式のままにするか ODF にするか**を Office が訊いてくるので、選ぶと書き込まれます。

⚠ **ひとそろいの版によります。** 2026-08-24 より前の版では、これらの形式で保存を押すと
「一般的な I/O エラー」で失敗し、**編集した内容がそこで失われていました**。
古い版が入っている間は、**開いた時点で**画面の下に断りが出て、
**Office の窓の上の行**にも「保存できません」と印が付きます ── **押してから気づくことはありません**。

🔑 直すには **設定 → Office 表示** の「**取得して入れる**」で入れ直してください(→ §4-2)。

#### 窓が固まったとき

Office の中身が固まると、**その窓のタブは何も受け付けなくなります**
(クリックもキーも通らず、窓の中には何も出せません)。

🔑 PKC3 の画面に戻ってくると、**下の行に「Office の窓が応答していません」**と
出ます。窓のタブを閉じて、もう一度 **Office で開く** を押してください。

⚠ 出るのは**戻ってきたとき**です ── 固まっている間はその窓を見ているので、
PKC3 側に出しても目に入らないためです。

---

⚠ **いま入っているのがどのビルドか**は、設定の Office の欄に出ます(版の文字列の下に、
LibreOffice の識別子の先頭・焼いた日時・ビルド番号)。不具合を報告するときは、この行を
そのまま添えてください ── **版の名前だけでは中身を見分けられないことがあります**。
前に入れた一式は素性を持っていないので「不明」と出ます(入れ直すと出ます)。

## 8. お知らせと更新

### お知らせ

新しいお知らせがあると、起動したときに**本文の下の帯**に出ます。
**出るのは 1 件ずつ**で、新しいものから順に出ます。

- **次へ** … いま出ている 1 件を読んだことにして、**次のお知らせを出します**。
  残りが 1 件になると出なくなります
- **閉じる** … **残っている分もまとめて**読んだことにして、帯を畳みます。
  **見出しの右端**にあります
- **今後は出さない** … 以後は出しません。⚠ **設定の「表示」から戻せます**(→ §4-2)

⚠ 見出しに **お知らせ(残り N 件)** と出ます。**次へ**を押すたびに減ります。
⚠ 低い画面などで 1 件が入りきらないときは、帯の**中だけ**が送れます。
**閉じる**は見出しに在るので、どれだけ送っても画面から出ません。

⚠ かぶせる窓では**ありません** ── 帯が出るだけで、そのまま作業を続けられます。
⚠ 閉じても消えません。**過去のお知らせはヘルプから読めます**(→ §4-4)。

### 更新

新しい版が配られると、画面に **「新しい版があります(再読込 / あとで)」** が出ます。

- **再読込** … その場で新しい版に入れ替わります
- **あとで** … 案内だけ消えます。**次に開いたときにまた出ます**

🔴 **勝手には入れ替わりません。** 押したときだけ、**押したタブだけ**が再読込します
── 別のタブで編集中の下書きを巻き込まないためです。

---

## 9. 困ったとき

| 症状 | 見るところ |
|---|---|
| 「別のタブで開いています」から進まない | 相手のタブが古い版のままの可能性。**そのタブを一度読み直す**と、以後は 2 枚同時に使えます(§1「複数タブで開ける」) |
| 「このノートは別のタブで編集中です」と出る | 他のタブで同じノートの編集を開いたままです。そちらで保存(または取消)してください |
| status に `⚠` だけの警告(「エラー:」が付かないもの)が出る | 保存先を確保できていない(= **再読込で消える**)。他タブを閉じて開き直す |
| status に `⚠ エラー: …` が出る | **操作が断られただけ**です(保存先とは無関係)。書いてある理由に従ってください。⚠ **開き直さないで** ── 編集中の下書きが消えます |
| オフラインで白紙 | その版をまだ保存していません。一度オンラインで開き直してください |
| 取り込めない | 判別できない形式です。PKC2 の書出し / PKC3 のバックアップ(`.pkc3.zip`)/ 素の `.md` かを確認してください |

画面下の status は、**知らせることがあるときだけ**出ます(何も無いときは
高さ 0 で、地の文を占めません)。

**バージョン**は **ヘルプ**(左の列のいちばん下)のいちばん上に出ています。
不具合を報告するときは、その行の内容を添えてください。

## 10. ショートカットキー

キーボードは**近道**です。マウスだけでも全部できますが、よく使う操作には鍵が当たっています。

⚠ **Ctrl** は Mac では **⌘** でも同じように効きます(どちらでも通ります)。
⚠ **日本語を変換している最中のキーは、変換のものです** ── PKC3 は横取りしません。

### 画面のどこでも効くもの

| キー | 何をするか |
|---|---|
| **Ctrl + N** | ノートを作る(いま選んでいる種類で。編集中は効きません) |
| **Ctrl + E** | 選んでいるノートを編集する |
| **Ctrl + F** | 絞り込みの欄へ移る |
| **Ctrl + H** | 置換の帯を開く / 閉じる |
| **Ctrl + ;** | 日付を入れる(編集中だけ効きます) |
| **Ctrl + /** | 雛形を入れる(編集中だけ効きます) |
| **Ctrl + Shift + K** | ノートへのリンクを入れる(編集中だけ効きます。→ §3「別のノートへリンクを張る」) |
| **Ctrl + Shift + P** | 操作を名前で探す(→ §10-1) |
| **Alt + 1** | 本文の面へ |
| **Alt + 2** | 集計の面へ |
| **Alt + 3** / **Ctrl + ,** | 設定の面へ |
| **Alt + 4** / **F12** | フラグの面へ |
| **F1** / **Alt + 5** / **Ctrl + Shift + /** | ヘルプの面へ |
| **Alt + 6** | 2 ペインで整理(アプリ)を開く(→ §4-7) |
| **Alt + C** | 本文の段組みを切り替える(押すたび 1 → 2 → 3 → 4 段。→ §7「本文の段組み」) |

⚠ **打っている最中**は、文字を打たない鍵だけが効きます ── **Ctrl + ,** / **F12** /
**F1** / **Ctrl + Shift + /** / **Ctrl + Shift + P**。`Alt +` の数字は打鍵中は止まります(本文に記号が
入るのを防ぐため)。割当は設定で変えられるので、打鍵中にも使いたい面は
**文字を打たない鍵**に割り当ててください。
| **Alt + [** / **Ctrl + \** | 左のペインを畳む / 戻す |
| **Alt + ]** / **Ctrl + Shift + \** | 右のペインを畳む / 戻す |
| **Ctrl + Alt + \** | 両側のペインを畳む / 戻す(集中) |
| **Alt + ←** / **Alt + →** | 戻る / 進む(2 ペインの面では、そのタブが見ていた場所を辿ります) |

⚠ 面を開く鍵は、**もう一度押すと本文に戻ります**。
⚠ **アプリの一覧のタイルは違います** ── そちらは押すたびに**新しい窓**が開きます
(→ §4-6)。

### 10-1. 操作を名前で探す

**やりたいことの名前**を打って、その場で実行できます。綴りや置き場所を覚えていなくても
たどり着けるので、**たまにしか使わない操作**にはこちらが速いことがあります。

- 開き方は 2 つ ── 左下の **「操作を探す」** を押す / **Ctrl + Shift + P**
- 名前を打つと絞り込まれます。**説明の中の言葉**でも当たります
  (「caret」で「日付を入れる」が出ます)
- **Enter** で、いちばん上の**押せる**行が走ります
- 各行には**割り当たっている鍵**も出ます ── 次からはその鍵で直接呼べます

⚠ **いま押せない操作も、隠さずに出します。** 代わりに**なぜ押せないか**が並びます
(「ノートを選んでいるときだけ効きます」など)── 探しても見つからないと、
user は「その機能が無い」と思ってしまうからです。押せない行は**灰色で押せません**。

⚠ **編集の途中でも開けます。** `Ctrl + Shift + P` は文字を打たない鍵なので、
本文に記号が入る心配はありません。

⚠ 説明が長いときは**折り返して**出ます。一覧が長いときは**一覧だけ**が縦に送れ、
**探す欄と「やめる」はその場に残ります**。

🔑 **編集中は、書式もここから入れられます**(ハイライト / ルビ / 圏点 / 打ち消し /
太字 / 斜体 / リンク)── **選んでから開く**と、閉じたあと**その範囲**に入ります。
⚠ 帯に出ていない 4 つ(ハイライト / ルビ / 圏点 / 打ち消し)は、**ここが押して入れる
唯一の口**です(帯は 14 個で既に横に長いので増やしていません)。
⚠ 待っている間に画面が組み直されて欄が変わった場合は、**入れずに理由を出します**
── 選んでいない所に書き込まないためです。


### 編集しているとき

| キー | 何をするか |
|---|---|
| **Alt + Shift + H** | ハイライト(`==` で囲む) |
| **Alt + Shift + R** | ルビ(`[[ruby:漢字|かんじ]]`) |
| **Alt + Shift + E** | 圏点(`^^` で囲む) |
| **Alt + Shift + X** | 打ち消し(`~~` で囲む) |

| キー | 何をするか | どこで |
|---|---|---|
| **Ctrl + S** / **Ctrl + Enter** | 編集を確定する | 2 列の編集(原文・題名の欄) |
| **Escape** | 編集をやめる | 同上 |
| **Ctrl + B** / **Ctrl + I** / **Ctrl + K** | 太字 / 斜体 / リンク | 2 列の編集と、1 面の開いている行 |
| **Ctrl + Enter** | 継ぎ足しを送る | 継ぎ足しの欄 |
| **Tab** / **Shift + Tab** / **Ctrl + Enter** / **Ctrl + S** | その行を確定して閉じる | 1 面の編集(開いている行の欄) |
| **Escape** | その行の編集をやめる | 同上 |
| **Alt + ↓** / **Alt + ↑** | その行を確定して次(前)の行を開く | 同上 |
| **Ctrl + A** | 全文を 1 つの欄で編集する | 1 面の編集(面そのもの) |
| **Ctrl + Z** / **Ctrl + Shift + Z** / **Ctrl + Y** | 取り消す / やり直す | 同上 |

### フォルダの表で(OS のファイラと同じ)

⚠ **フォルダの表の行に焦点があるとき**だけ効きます(行をクリックすると焦点が入ります)。

| キー | 何をするか |
|---|---|
| **↓** / **↑** | 次の行へ / 前の行へ(2 ペインではカーソルだけが動きます) |
| **Shift + ↓** / **Shift + ↑** | 次の行まで / 前の行まで選び足す |
| **Enter** / **F3** | 開く(フォルダなら中へ) |
| **Backspace** / **Alt + ↑** | 親フォルダへ |
| **Delete** / **F8** | 選んでいるものをゴミ箱へ(いつでも戻せます) |
| **Ctrl + A** | いま出ている行をぜんぶ選ぶ |

### 2 ペインの面で

⚠ **2 ペインの面(そのペインに焦点があるとき)**だけ効きます。

| キー | 何をするか |
|---|---|
| **Space** / **Insert** | 印を付ける / 外して次の行へ |
| **F5** | 反対のペインへ写す(元は残ります) |
| **F6** | 反対のペインへ移す |
| **F2** | 名前を打ち替える |
| **F7** | いまの場所にフォルダを作る |
| **Shift + F4** | いまの場所にノートを作る(作っても本文の面へは移りません) |
| **F9** | 下見を出す / しまう(指している行の中身を、その場で数行だけ) |
| **Alt + ←** / **Alt + →** | そのタブが 1 つ前に見ていた場所へ戻る / 進む |
| **Tab** | 反対のペインへ移る |

🔑 **印が無ければ、カーソルの行が相手**になります。

**Enter は「読む」ところから始まります。** 開いたらすぐ編集に入りたいときは、
**設定** の **開いたときの状態** で「開いたら、そのまま編集に入る」を入れてください。

⚠ 行を 1 回押して選んだだけでは編集に入りません ── それは「選ぶ」であって「開く」ではありません。

### 割り当てを変える

**設定** の **ショートカットキー** で、キーを割り当て直せます。

1. 変えたい操作の **割り当て** を押します(「キー待ち…」に変わります)
2. 使いたいキーを押します ── その場で効くようになります
3. やめるときは **Esc** を押します

- 1 つの操作に**複数の割当**を持てます(上の表で `/` で並んでいるものがそれです)
- いらない割当は、その鍵の隣の **×** で外せます。**全部外す**こともできます
- **既定に戻す** で、その操作だけ最初の割当へ戻ります。**すべて既定に戻す** は全部です
- 割当は**この端末に覚えます**(ノートの中には入りません)。別のタブで変えると、
  開いているタブにもすぐ効きます

⚠ 次のものは割り当てられません ── **修飾キーの付かないキー**(そのままだと文字が
打てなくなるため。`Escape` / `Tab` / `F1`〜`F12` は例外です。**フォルダの表だけで効く
操作**は、字を打つ相手が居ないので `Enter` や `Delete` も割り当てられます)と、
**Ctrl + C / V / X / Q / W / T**(コピー・貼り付けなど、他の意味が強すぎるものです)。
⚠ 同じ割当を 2 つの操作に付けることはできません ── ぶつかる相手の名前が出ます。
