# PKC3 マニュアル

> ⚠ **この doc は「いま動くもの」だけを書く。** 予定・設計中のものは書かない
> ── 書いた瞬間に嘘のマニュアルになる(P7 段⑥ の前提)。
> 最終更新: 2026-08-03(P7 段⑥ 時点)

PKC3 はブラウザだけで動くノートアプリです。サーバーに何も送りません ──
データは**あなたのブラウザの中**(OPFS 上の SQLite と IndexedDB)にあります。

---

## 1. はじめる

| したいこと | やり方 |
|---|---|
| 開く | product URL を開く(初回はオンラインが必要) |
| インストールする | ブラウザのアドレスバーの「インストール」から。以後アプリとして開ける |
| オフラインで使う | 一度オンラインで開いていれば、以後は機内モードでも開く |
| `.md` をこのアプリで開く | インストール後、`.md` / `.markdown` をダブルクリック(OS が PKC3 に渡す) |

⚠ **`file://` で開いたときは PWA になりません**(Service Worker が成立しない)。
書き出した「閲覧用 HTML」は単体で開けますが、それは別物です(→ §5)。

### データはどこにある?

- **本文・メタ・履歴・relations** … OPFS 上の SQLite(専用 worker が持つ)
- **添付の実体(bytes)** … IndexedDB の Blob

どちらもブラウザのサイトデータです。**ブラウザのサイトデータを消すと全部消えます。**
消える前に「バックアップ」を書き出してください(→ §5)。

### 🔴 タブは 1 つだけ

書き込みは 1 タブだけが持ちます(writer lease)。2 枚目のタブは
「別のタブで開いています。そのタブを閉じると、ここで続きが開きます…」と出て待ちます
── 閉じれば自動で引き継ぎます。

## 2. ノートを作る・編集する

サイドバー上部は左が**絞り込み**、右が **新規** メニューです。

| ここ | 何をするか |
|---|---|
| **絞り込み** | 題名で一覧を絞ります(打つとすぐ効きます。消せば全部戻ります) |
| **新規** | ノートを作る / 添付を入れる |

作るものはこの **新規** メニューから選びます。

| ボタン | archetype | 何が違うか |
|---|---|---|
| **+ノート** | `text` | 素の PKC-Markdown。いちばん普通のノート |
| **+Todo** | `todo` | frontmatter に `status` / `date` / `archived` を持つ。かんばん・カレンダーに出る |
| **+ログ** | `textlog` | 追記型。`## <日時>` の節を末尾に足していく(秒まで) |
| **+シート** | `spreadsheet` | csv fence + frontmatter(レイアウト・グラフ・書式) |
| **+フォルダ** | `folder` | 入れ物。ファイラで階層になる |

🔑 **本文はどれも PKC-Markdown 1 種類**です。archetype は「見せ方・編集の仕方」の
フレーバーであって、別のデータ形式ではありません ── だから、どのノートも
そのまま markdown として読めます。

編集は詳細画面の **編集** ボタン → 書く → **保存**。取り消しは **キャンセル**。
⚠ 本文をクリックしても編集には入りません(誤操作で本文が変わらないように)。

## 3. 本文に書けるもの(PKC-Markdown)

CommonMark に加えて、次が使えます。

### fence(``` で囲むブロック)

| 言語 | 何になるか |
|---|---|
| `html` | サンドボックス化した iframe の中で描画 |
| `mermaid` | 図 |
| `csv` / `tsv` / `psv` | 表 |

末尾に `-render` / `-norender` / `-both` を付けると出し方を変えられます
(既定は `-both` = 描画とソースの両方)。csv 系は `noheader` などのオプションを
言語名の後ろに書けます。

    ```csv-render noheader
    りんご,120
    みかん,80
    ```

### そのほか

- **脚注** `[^1]`
- **目次** `:::toc` / `:::toc{depth=2}`
- **frontmatter**(先頭の `---` で囲んだ領域)── todo の `status` などはここに入る
- **添付参照** `asset:<key>` ── 「添付」から入れると自動で入ります

## 4. 上部のならび

左が**ビューの切替**(常に出ています)、右が**役割ごとのメニュー**です。
メニューは押すと開き、外側を押すか `Esc` で閉じます(項目を選んでも閉じます)。

| メニュー | 中身 |
|---|---|
| **取り込む** | **取込** |
| **書き出す** | **バックアップ** / **閲覧用 HTML** / **Markdown** |
| **整理** | **添付の整理** |
| **表示** | **ライト** / **ダーク**(配色。選ぶと次から覚えています) |

⚠ 最初の配色は **OS の設定に従います**。一度選ぶと、そちらが優先されます。

### 見方を変える(左のボタン)

| ビュー | 何が見えるか |
|---|---|
| **詳細** | 選んだノート 1 件 |
| **かんばん** | todo を `status` の列に並べる。⚠ アーカイブ済みは**常に**出ない |
| **カレンダー** | todo を `date` で並べる。アーカイブ済みは切替で出せる |
| **ファイラ** | フォルダの階層をたどる |
| **ランチャー** | 「アプリとして登録」した添付をタイルで並べる(→ §7-2) |

⚠ ビューを切り替えても**選択は変わりません**。

## 5. 書き出す・取り込む

### 書き出す(上部の **書き出す** メニュー)

| ボタン | ファイル | 可逆? | 用途 |
|---|---|---|---|
| **バックアップ** | `<題名>.pkc3.zip` | ✅ **可逆** | これさえあれば全部戻る。**定期的にこれを取る** |
| **閲覧用 HTML** | `<題名>.html` | ❌ 片道 | 1 ファイルで渡す・見せる。単体で開いて読める |
| **Markdown** | `<題名>.md.zip` | ❌ 片道 | PKC3 を捨てても読める形。1 ノート = 1 `.md`、添付は `assets/` |
| **書き出す**(詳細画面) | `<題名>.pkc3.zip` | ✅ 可逆 | 1 件だけ。消す前の退避に |

⚠ いまはファイルの**ドラッグ&ドロップは受けません**(取込・添付ともボタンから選びます)。

🔴 **バックアップだけが可逆**です。「閲覧用 HTML」と「Markdown」は
frontmatter に居場所の無いもの(relations / 履歴)が落ちます。
「Markdown」は**落ちたものを書出し後に件数つきで画面に出します**。
「閲覧用 HTML」は件数を出さず、「取り込み直せません」とだけ言います。

### 取り込む

上部の **取り込む** メニュー → **取込** から選びます(複数選択できます)。

- **PKC2 の書出し全 9 形式**(単一 HTML + ZIP 8 種)→ §移行ガイド
- **素の `.md` / `.markdown`** ── 複数選択できます(1 件ずつノートになります)
- **PKC3 のバックアップ**(`.pkc3.zip`)

判別は**拡張子ではなく中身**(先頭バイトと manifest)で行います。
判別できないものは**推測せずに断ります**。

⚠ 取込で落ちたもの・書き換えたものは、**画面に全件出ます**(1 行の status に
埋もれません)。閉じるまで残ります。

## 6. 履歴とゴミ箱

- **履歴** … 詳細画面の **履歴** ボタン。過去の版に**復元**できます。
  ⚠ 戻す前の状態も履歴に積まれるので、**戻したことも取り消せます**
- 履歴は 1 ノートあたり**最新 100 件**まで保たれます
- **ゴミ箱** … 消したノートはここに入ります。**戻せます**
- **ゴミ箱を空にする** … ⚠ **不可逆**。確認を出します

---

## 7. 添付

サイドバーの **新規** メニュー → **+添付** からファイルを入れます(複数選択できます)。
実体は IndexedDB に、本文には `asset:<key>` の参照が入ります。

上部の **整理** メニュー → **添付の整理** で、**どのノートからも参照されていない**添付を消せます。
⚠ 自動では消しません(明示操作のみ)。⚠ 不可逆なので確認を出します。

⚠ 整理・取込・書出しの最中は、削除などの壊す操作は止まります
(走査中に消えると「書き出したつもりでファイルが 1 個も落ちていない」状態になるため)。

### 7-2. ランチャー

**ランチャー** ビューに、PKC2 で「アプリとして登録」した添付がタイルで並びます。

| タイル | 押すと |
|---|---|
| アプリ(HTML の添付) | **新しいタブ**で開きます |
| URL(`↗` と行き先のホスト名が付きます) | **新しいタブ**でそのサイトを開きます |

- 並び順は PKC2 のグループ(`app_group`)と順番(`app_order`)をそのまま引き継ぎます
- グループ名の無いものは **よく使う** にまとまります
- サイドバーの **絞り込み** がここでも効きます

⚠ PKC3 でタイルを**作る**導線はまだありません(PKC2 から取り込んだものが出ます)。

🔑 URL タイルを押しても、**相手のサイトにはあなたがどこから来たか伝わりません**
(リンク元も、開いた元のページへの参照も渡していません)。

---

## 8. 更新

新しい版が配られると、画面に **「新しい版があります(再読込 / あとで)」** が出ます。

- **再読込** … その場で新しい版に入れ替わります
- **あとで** … 案内だけ消えます。**次に開いたときにまた出ます**

🔴 **勝手には入れ替わりません。** 押したときだけ、**押したタブだけ**が再読込します
── 別のタブで編集中の下書きを巻き込まないためです。

---

## 9. 困ったとき

| 症状 | 見るところ |
|---|---|
| 「別のタブで開いています」から進まない | 他のタブ・他のウィンドウで PKC3 を開いていないか |
| 画面下の status に `memory` と出る | OPFS を確保できていない(= **再読込で消える**)。他タブを閉じて開き直す |
| オフラインで白紙 | その版をまだ保存していません。一度オンラインで開き直してください |
| 取り込めない | 判別できない形式です。PKC2 の書出しか素の `.md` かを確認してください |

画面下の status には常に **バージョン・ビルド種別・ストレージの実体**が出ています
── 不具合を報告するときはこの行を添えてください。
