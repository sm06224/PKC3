# PKC3 マニュアル

PKC3 はブラウザだけで動くノートアプリです。サーバーに何も送りません ──
データは**あなたのブラウザの中**(OPFS 上の SQLite と IndexedDB)にあります。

---

## 1. はじめる

| したいこと | やり方 |
|---|---|
| 開く | product URL を開く(初回はオンラインが必要) |
| インストールする | ブラウザのアドレスバーの「インストール」から。以後アプリとして開ける |
| オフラインで使う | 一度オンラインで開いていれば、以後は機内モードでも開く |
| `.md` をこのアプリで開く | インストール後、`.md` / `.markdown` をダブルクリック(OS が PKC3 に渡す) |

⚠ **`file://` で開いたときは PWA になりません**(Service Worker が成立しない)。
書き出した「閲覧用 HTML」は単体で開けますが、それは別物です(→ §5)。

### データはどこにある?

- **本文・メタ・履歴・relations** … OPFS 上の SQLite(専用 worker が持つ)
- **添付の実体(bytes)** … IndexedDB の Blob

どちらもブラウザのサイトデータです。**ブラウザのサイトデータを消すと全部消えます。**
消える前に「バックアップ」を書き出してください(→ §5)。

### 🔴 複数タブで開ける(保存の本体は 1 つ)

タブは何枚でも開けます。**2 枚目以降もふつうに使えます** ── 一覧・閲覧・編集・
新規作成、全部できます。仕組み上、保存を実際に書き込む「本体」は 1 タブだけで
(データベースが単一接続のため)、2 枚目以降の保存は**本体タブ経由**で届きます。
2 枚目以降のタブには、画面下の status に「複数タブ: このタブの保存は本体タブ経由です」
と常に出ています。

- **同じノート**を 2 つのタブで同時に編集することはできません(片方の編集内容が
  黙って消えるのを防ぐため)。後から押した側に「このノートは別のタブで編集中です」と
  出ます。**別々のノート**なら並行して編集できます。
- あるタブで保存すると、他のタブの一覧・本文にも自動で反映されます
  (編集中のタブは、編集を終えたときに反映されます)。
- 本体のタブを閉じると、残ったタブの 1 つが**その場で本体を引き継ぎます**
  (「このタブが本体になりました」と出ます。読み直しは要りません)。
- 相手が古い版(この仕組みが入る前)のときだけ、従来どおり
  「別のタブで開いています。そのタブを閉じると、ここで続きが開きます…」と出て待ちます。

## 2. ノートを作る・編集する

左の列の上に、**絞り込み**・作るボタン・**添付** が並んでいます。

| ここ | 何をするか |
|---|---|
| **絞り込み** | 題名で一覧を絞ります(打つとすぐ効きます。消せば全部戻ります) |
| **+ ノート** | いま選んでいる種類で作ります(**Ctrl+N** でも同じ) |
| ▼ | 作る種類を選びます。選ぶとボタンの文言と図案が変わり、**Ctrl+N の対象も変わります** |
| **添付** | ファイルを取り込んで添付にします |

⚠ ボタンは**いま何ができるか**を出します ── 表を作る状態なら「**+ 表**」になります。
⚠ **Ctrl+N は編集中には効きません**(打っている途中に別のノートへ飛ばないため)。

作れる種類は次のとおりです。

| 種類 | 何が違うか |
|---|---|
| **ノート** | 素の PKC-Markdown。いちばん普通のノート |
| **ログ** | 追記型。`## <日時>` の節を末尾に足していきます(秒まで) |
| **表** | csv fence と、レイアウト・グラフ・書式の指定 |
| **フォルダ** | 入れ物。フォルダ画面で階層になります |

⚠ **Todo は今はお休み中**です(かんばん・カレンダーも一緒)。作る導線を畳んで
いるだけなので、**取り込んだ Todo は普通のノートとして読めて、編集もできます**。

🔑 **本文はどれも PKC-Markdown 1 種類**です。archetype は「見せ方・編集の仕方」の
フレーバーであって、別のデータ形式ではありません ── だから、どのノートも
そのまま markdown として読めます。

編集は **編集** ボタン → 書く → **保存**。取り消しは **キャンセル**。
最初の設定では **1 面で編集(ライブ)**(下の「1 面で編集する」)で開きます。
設定の「表示」の「編集の仕方」で **2 ペイン(原文とプレビュー)** にもできます(→ §4-2)。
2 ペインでは**左に原文、右にプレビュー**が並びます。
プレビューは**打つ手が止まってから**追いつきます(打ち続けているときも 3 秒に 1 回は
反映されます)── 1 打鍵ごとに描き直すと画面がガタつくためです。
⚠ 変わった所だけを描き直すので、**スクロール位置は動かず、触っていない図も消えません**。
⚠ 2 ペインでは、画面が狭いときはプレビューを畳みます。
⚠ 本文をクリックしても編集には入りません(誤操作で本文が変わらないように)。

### 本文をコピーする

読んでいるノートの上に、コピーのボタンが 3 つ並びます。

| ボタン | 何が入るか |
|---|---|
| **Markdown をコピー** | 本文の原文(書いたままの markdown) |
| **書式付きでコピー** | 見た目つき。Word やメールに貼ると**そのままの体裁**で入ります |
| **選択範囲をコピー** | 選んだところだけを**原文**で。選んでいないときは押せません |

⚠ **書式付きでコピー**は、貼り先で崩れないように**掃除してから**渡します ── 図やグラフの
原文、押せないボタン、PKC3 の内部の印は付いてきません。画像は貼り先でも読める形に
埋め込みます。⚠ 埋め込めなかった画像は**文字に置き換え、件数を画面に出します**
(壊れた画像を貼らせないためです)。

⚠ ふつうに範囲を選んで Ctrl+C したときは、これまでどおり**見えているテキスト**が入ります
(このボタンは別口です)。

### 1 面で編集する(ライブエディタ)

**最初の設定はこちらです。** 2 ペインに戻したいときは、設定の「表示」の
**編集の仕方**から選べます(→ §4-2)。

押した行だけが原文になり、周りは描画のまま残ります。行を離れると確定します。

| キー | 何が起きるか |
|---|---|
| **↓** / **↑** | 箱の中でカーソルが動くだけです(**隣の行へは飛びません**) |
| **Alt+↓** / **Alt+↑** | その行を確定して、**次(前)の行を開きます**。箱のどこに居ても効きます |
| **Tab** / **Ctrl+Enter** | その行を確定して閉じます |
| **Escape** | 打ったものを捨てて閉じます |
| **Ctrl+S** | その行を確定します(ブラウザの保存は開きません) |
| **Ctrl+A** | 全文が 1 つの入力欄になります(**全文を編集** ボタンでも同じ) |
| **Ctrl+Z** / **Ctrl+Shift+Z** | 行の中は打鍵ごと、行の外は確定ごとに戻します |

書式パネルと **Ctrl+B / I / K** は、開いている行にも効きます。

### 書式パネル

編集中は、原文のすぐ上に書式のボタンが並びます。**先に選んでから押す**と、
その範囲に効きます(何も選ばずに押すと印だけ入って、その間にカーソルが入ります)。
行頭の印(見出し / 箇条書き / 引用 / チェック)と **太字 / 斜体 / コード** は
**もう一度押すと外れます**。**表 / 図 / コード塊 / リンク** は雛形を差し込むので、
間違えたときは手で消してください。

| ボタン | 何になるか |
|---|---|
| **見出し1** / **見出し2** / **見出し3** | 行頭に `#` / `##` / `###` |
| **太字** / **斜体** / **コード** | 選んだ範囲を `**` / `*` / `` ` `` で囲みます |
| **箇条書き** / **番号** / **チェック** / **引用** | 行頭に `-` / `1.` / `- [ ]` / `>` |
| **リンク** | `[文字](url)` を入れて、`url` を選択した状態にします |
| **表** / **図** / **コード塊** | 雛形を差し込みます(表 = 2 列、図 = `mermaid`) |
| **置換** | 本文の**探す語を全部置き換える**欄を開きます(`Ctrl` + `H`) |

近道キー(本文の中だけ): `Ctrl`(Mac は `⌘`)+ `B` = 太字、`+ I` = 斜体、
`+ K` = リンク。⚠ 日本語の変換中は効きません(変換を確定してから押してください)。

⚠ **番号**は行ごとに数え直します(`1.` `2.` `3.`)。
⚠ 書式パネルで書き換えた分は、ブラウザの「元に戻す」(`Ctrl+Z`)では戻りません
── 戻したいときは **キャンセル** で編集ごと捨ててください。

### 追記

**ノート** と **ログ** には、本文の下に **追記欄** が出ます。
打って **追記** を押すか `Ctrl`(Mac は `⌘`)+ `Enter` で、**編集画面を開かずに**
末尾へ足して保存します ── 長いログでも、毎回全文を開く必要はありません。

| 種類 | 押すと何が足されるか |
|---|---|
| **ログ** | `## <日時>`(秒まで)の節 + 打った内容 |
| **ノート** | 打った内容だけ(見出しは足しません ── 構造は書く人のもの) |

⚠ 押しても空行は増えません(末尾の余白は畳んでから足します)。
⚠ 空欄のまま押しても何も起きません。
⚠ **通ったときだけ欄が空になります**。失敗したときは打った内容が残ります。

#### 追記と編集がぶつかったとき

追記は編集画面を通らずに書くので、**同じノートを編集している間は追記できません**
(そのまま書けてしまうと、保存したときに追記が消えます)。追記欄の場所に理由と
出口が出ます。

| 出ているもの | 意味 | 押すもの |
|---|---|---|
| このノートは編集中です | あなたが編集中 | **保存して解放** か **編集を破棄** |
| 追記を書き込んでいます… | 書き込み中(普通は一瞬) | 返ってこないときだけ **強制解放** |

⚠ **強制解放** は最後の出口です。書き込みが実際には進んでいた場合、画面の表示が
実際の中身より古くなることがあります(開き直すと直ります)。

#### 編集中にできないこと

**編集中は別のノートに移れません**(打ちかけを捨てないためです)。一覧の行や
本文のリンクを押すと、**画面の下に理由が出ます** ── 保存するか取り消してから
もう一度押してください。

⚠ 一方、**設定 / フラグ / ヘルプは編集中でも開けます**。戻れば打ちかけも
取り消し(Ctrl+Z)もそのままです(→ §4)。

## 3. 本文に書けるもの(PKC-Markdown)

CommonMark に加えて、次が使えます。

### fence(``` で囲むブロック)

| 言語 | 何になるか |
|---|---|
| `html` | サンドボックス化した iframe の中で描画 |
| `mermaid` | 図 |
| `chart` | グラフ(棒 / 折れ線 / 円 / ドーナツ / レーダー / 散布) |
| `csv` / `tsv` / `psv` | 表 |

末尾に `-render` / `-norender` / `-both` を付けると出し方を変えられます
(既定は `-both` = 描画とソースの両方)。csv 系は `noheader` などのオプションを
言語名の後ろに書けます。

    ```csv-render noheader
    りんご,120
    みかん,80
    ```

グラフは JSON で書きます。

    ```chart
    { "type": "bar",
      "labels": ["1月", "2月", "3月"],
      "datasets": [{ "label": "売上", "data": [10, 20, 15] }],
      "title": "月別の売上" }
    ```

`type` は `bar` / `line` / `pie` / `doughnut` / `radar` / `scatter` のどれかです。
`title` と `stacked`(積み上げ)、`legend`(凡例を出すか)も書けます。
⚠ 書けるのはここに挙げた項目だけです ── 知らない項目は**黙って無視します**。
⚠ 読めないときは、その場に理由が出ます(黙って空になりません)。

⚠ **図(`mermaid`)とグラフ(`chart`)は PNG にして表示します**。スクロールを軽く保つためで、
同じ図・同じ配色・同じ幅なら 2 回目からは焼き直しません(配色を変えると焼き直します)。

図の色は**選んでいる配色に従います** ── ダークな配色ならダークな図になり、
配色を切り替えると、開いている図はその場で描き直されます。

### 図を保存する

描かれた図の右上に **図を保存** があります。押すと **ベクタ**(`.svg`)で落ちてきます
── 画面に出ているのは PNG ですが、**書き出しは拡大しても粗くならない形**です。
資料に貼る・印刷する用途はこちらを使ってください。
書き出しには少し時間が掛かります(原文から描き直すため)。その間ボタンは
**書き出し中…** になって押せなくなります。落ちてくるファイルは、画面で見えている
のと**同じ配色**です。

ファイル名は `<ノートの題名>-図1.svg` のように、本文の中で**何枚目か**が付きます。

### そのほか

- **脚注** `[^1]`
- **目次** `:::toc` / `:::toc{depth=2}`
- **行の寄せ**(行頭に置きます)

  | 書き方 | どうなるか |
  |---|---|
  | `\|\| 本文` | **中央**に寄ります |
  | `\|> 本文` | **全体の寄せの反対側**に寄ります(何も宣言しない横書きなら右) |
  | `<\| 本文` / `\|< 本文` / `>\| 本文` | ⚠ **上と同じ**です(打ち間違い扱いで受理します) |

  ⚠ **矢印の向きに意味はありません** ── `<\|` と書いても `\|>` と同じ側に寄ります。
  寄せの記法は「**中央**」と「**全体の寄せの反対側**」の 2 つだけです。
  ⚠ **どちら側が「反対」か**は、その文書の frontmatter が決めます ──
  `direction: rtl` と書くと全体が右起点になり `\|>` は左へ、`align: right` と
  書いたときも `\|>` は**左**へ寄ります(全体の寄せが右なので、その反対)。
  `align: center` のときは**寄りません** ── 中央に「反対側」は無いからです。
  どうしても**物理的に左**へ寄せたいときは `:::paragraph{align=left}` と書いてください
  (`align=end` / `align=start` / `align=center` / `align=right` も書けます。
  `:::format{align=…}` も同じ値を受けます)
- **frontmatter**(先頭の `---` で囲んだ領域)── todo の `status` などはここに入る。
  文書全体の**書き方**もここで宣言します

  | 書くもの | 値 | 何が変わるか |
  |---|---|---|
  | `writing` | `horizontal`(既定)/ `vertical` | 縦書きにします |
  | `direction` | `ltr`(既定)/ `rtl` | 右から左へ流します(アラビア語・ヘブライ語)。縦書きでは**段の進む向き**(右起こし / 左起こし)になります |
  | `align` | `left` / `right` / `center`(縦書きは `top` / `bottom` / `center`) | **寄せの既定**(何も書かない段落がどこへ寄るか)を決めます |

  ⚠ **流れの起点と逆の `align`**(左から右の文書での `align: right` など)を書くと、
  `\|>`(全体の寄せの反対側)の寄る先も**反対に**変わります ──
  `align: right` の文書では、何も書かない段落は右へ、`\|>` は**左**へ寄ります
  (横書き・左から右の文書の場合)。`align: left` を書いても、流れの起点と同じ側なので
  `\|>` は右のままです。`align: center` の文書では `\|>` は**寄りません**
  (中央に反対側は無いので、何も起きません)。
  ⚠ この入れ替えが効くのは**行頭の記号**(`\|>` `<\|` `\|<` `>\|`)だけです。
  `:::paragraph{align=end}` / `{align=start}` のように**言葉で書いた指定**は
  入れ替わりません ── 書いたとおり(流れの終わり側 / 起点側)に出ます。
  🔑 記号は**絵**なので、向きを描き間違えても意図が通ります(だから 4 形が同じ意味です)。
  言葉の指定は書いたことがそのまま意味なので、寛容さがありません ── 別のものです。
  ⚠ `direction: rtl` を書くと、何も書かない段落は**右**(= 行頭)から始まり、
  `\|>` は**左**に寄ります。
  ⚠ 縦書き(`writing: vertical`)では `direction` は**段が右から並ぶか左から並ぶか**を
  決めます。本文はどちらでも**上から下**へ流れます。
  ⚠ 縦書きの `align: top` / `bottom` も効きます(上下は縦書きでの「行頭 / 行末」です)。
  `align: bottom` の文書では `\|>` は**上**へ寄ります(全体の寄せの反対側)。
- **添付参照** `![名前](asset:<key>)` ── 添付は**独立したノート**になります。本文から
  参照したいときは、その添付の画面に出ている **参照をコピー** を押して貼ってください。
  画像なら本文の中にそのまま出ます。画像以外は**ダウンロードのリンク**(`[名前](asset:<key>)`)
  になります
- **ノートへのリンク** `[題名](entry:<lid>)` ── 押すと**そのノートが開きます**。
  ⚠ 開かないときは理由が画面の下に出ます(見つからない / 編集中 / 書き方が読めない)。
  ⚠ **編集中は移れません**(保存するか取り消してください)。⚠ PKC2 から取り込んだ
  本文の `entry:…#…`(見出しまで指す形)も、**そのノートまでは開きます**。
- **カード参照** `@[card](entry:<lid>)` ── ノートへのリンクを**カードの形**で置きます。
  いまは `@card` という札が出るだけで、押すとそのノートが開きます。
  ⚠ **キーボードでも押せます**(Tab で移動して Enter か Space)。
- **携帯参照** `[題名](pkc://<コンテナ>/entry/<lid>)` ── どの PKC のものかまで書く形です
  (PKC2 から取り込んだ本文に出てきます)。**いま開いている PKC あて**なら、
  ノートへのリンクと同じように押すと開きます。
  ⚠ **別の PKC あては押せない印**(参照先を書いた札)として出ます ── いまは開く手段が
  ありません。**いま開いている PKC の添付あて**(`pkc://<コンテナ>/asset/<key>`)は、
  押すと**その添付を持つノート**が開きます(見つからないときは理由が出ます)。

### 区切りと改ページ

| 書き方 | 画面 | 紙・PDF |
|---|---|---|
| `---` | 横の罫線 | 罫線のまま(ページは変わりません) |
| `+++` | 区切りの線 | **ここでページが変わります** |
| `:::break{kind=page}` | `+++` と同じ | `+++` と同じ |
| `:::break{kind=rule}` | `---` と同じ | `---` と同じ |

### この画面をそのまま印刷する

ブラウザの印刷(Ctrl+P など)で、**いま開いているノートの全文**が紙に出ます。
**PDF に保存**を選べば PDF になります。紙・PDF では:

- 左の一覧と右の情報は出ません(本文だけになります)
- 「編集」などの操作ボタン、コードのコピーボタン、切替のボタンは出ません
- 見出しがページの最後で独りにならないようにし、コード・表・引用・画像は途中で切りません
- `+++` の位置でページが変わります
- **紙の大きさは設定の「紙面」に従います**(A4 / A3 の縦横。→ §4-2)。
  画面用の紙面(フル HD / 4:3)を選んでいるときは指定しないので、
  お使いのブラウザの既定の紙で出ます

⚠ **書き出した閲覧用 HTML の印刷とは別です**。あちらは目次が本文の先頭に付き、
「全体を印刷」で全件を続けて刷れます(§5 の「目次と印刷」)。

## 4. 画面のならび

🔑 **どの列も、自分が扱うものの操作を自分で持ちます。** 探す・出す・消すの導線が
2 か所に散ることはありません。
⚠ 例外は**編集中の出口**だけです ── 中央の **保存** / **キャンセル** と同じものが、
追記欄の場所にも(**保存して解放** / **編集を破棄** として)出ます。追記できない
理由をそこで説明しているので、**その場から抜けられる**ようにしてあります(→ §2)。
どちらを押しても結果は同じです。

| 場所 | 扱うもの | そこにある操作 |
|---|---|---|
| 左の列 | ノート全体 | 探す・作る・入れる・出す・片づける + **集計** / **設定** / **フラグ** / **ヘルプ** |
| 中央 | いま開いているノート | **編集** / **保存** / **キャンセル** |
| 右の列 | 選んでいるノート | **書き出す** / **履歴** / **削除** |

左の列のいちばん下に、ノート全体に対する操作が並びます。

| 操作 | 何が起きるか |
|---|---|
| **取り込む** | PKC2 の書き出しや Markdown を読み込みます |
| **バックアップ** / **閲覧用 HTML** / **Markdown** | 書き出します(→ §5) |
| **使っていない添付を消す** | どのノートからも参照されていない添付を消します(戻せません) |
| **集計** | 本文の先頭に書いた項目でノートを束ねて数えます(→ §4-5) |
| **設定** | 見た目や、外へ何が伝わるかの判断(→ §4-2) |
| **フラグ** | 開発中の切り替え。いつか畳まれます(→ §4-3) |
| **ヘルプ** | 版・これまでのお知らせ・このマニュアル(→ §4-4) |

⚠ **集計**だけは**編集中は開けません**(ノートを並べる面なので、かんばんや
カレンダーと同じ扱いです)。保存するか取り消してから開いてください。
⚠ 下の 3 つは**編集中でも開けます**。寄り道して戻っても、打ちかけの本文も
取り消し(Ctrl+Z)もそのまま残ります ── 書きながらマニュアルを読むためです。
⚠ ただし**別のノートに移ることはできません**(保存するか取り消してください)。

### 4-2. 設定

左の列のいちばん下の **設定** から開きます。画面は 4 つに分かれています ──
**表示**(見た目の好み)/ **外部の画像**(外へ何が伝わるかの判断)/
**Office 表示**(この端末に置くかどうか)/ **処理**(読むだけの計器)です。

#### 表示

##### 配色

配色を選べます。**ライト** / **ダーク** / **GitHub** /
**GitHub ダーク** / **Solarized** / **Solarized ダーク** / **Dracula** /
**Nord** / **端末** の 9 つ。
⚠ 最初は **OS の設定に従います**。一度選ぶと、この端末ではそちらを覚えています。

##### 紙面

**本文の読み幅**と、**印刷したときの紙の大きさ**を選べます。

| 選ぶもの | 本文の読み幅 | 印刷の紙 |
|---|---|---|
| **A4 縦**(最初はこれ) | 42rem(全角 約 51 文字) | A4 縦 |
| **A4 横** | 62rem | A4 横 |
| **A3 縦** | 62rem | A3 縦 |
| **A3 横** | 91rem | A3 横 |
| **フル HD(16:9 横)** | **上限なし**(画面の幅いっぱい) | 指定しません(お使いのブラウザの既定) |
| **フル HD 縦(9:16)** | 64rem | 同上 |
| **4:3 横** | 60rem | 同上 |
| **4:3 縦** | 45rem | 同上 |

- 上限が掛かるのは**散文**(段落・見出し・箇条書き・引用・注意書きなど)だけです。
  **表・図・コード・添付は、どの紙面でも幅いっぱい**のままです。
- 読む面・添付の説明・編集のプレビュー・1 面のライブエディタは**同じ幅**で出ます。
- 書き出した閲覧用 HTML には、**書き出したときの紙面**が焼かれます(→ §5)。
- ⚠ ヘルプ(この画面)は紙面の対象外です。
- 一度選ぶと、この端末ではそちらを覚えています。**A4 縦**を選べば元に戻せます。

##### 編集の仕方

編集画面の形を選べます。**1 面で編集(ライブ)**(最初はこれ)と
**2 ペイン(原文とプレビュー)** の 2 つです。
切り替えは、**次に編集を開いたときから**効きます(開いている編集はそのままです)。
一度選ぶと、この端末ではそちらを覚えています。

##### お知らせ

**起動したときに新しいお知らせを出す**かを選べます(最初は出します)。
⚠ お知らせの帯の **今後は出さない** を押したときも、ここから戻せます。
⚠ 出さなくても、**過去のお知らせはヘルプから読めます**(→ §4-4)。

#### 外部の画像

本文に `![絵](https://…)` と書かれた画像や、`html` ブロックの中の画像を
**読み込むかどうか**を選びます。

| 選択肢 | どうなるか |
|---|---|
| **常にオン** | いつでも読み込みます |
| **常に確認**(既定) | 読み込まずに置き、ノートごとに聞きます |
| **常にオフ** | 読み込みません(聞きません) |

🔴 **読み込むと、相手のサーバーに「この端末がいまこれを開いた」ことが伝わります。**
画像の中身が見えなくても伝わります(1×1 の透明な画像でも同じです ── いわゆる
追跡用の画像)。本文は人からもらったものや AI が書いたものでもあるので、
書いた本人が意図していないこともあります。

**常に確認** のときは、外部の画像があるノートを開くと本文の上に帯が出ます。
**このノートで読み込む** / **読み込まない** のどちらかを押してください。
答えは**タブを閉じるまで**覚えます(ノートごとです)。

⚠ 読み込んでいない画像は、**破線の四角**として置かれます(消えたのではありません)。
⚠ 設定を変えると、ノートごとの答えは**消えます**。
⚠ **書き出した HTML に画像が入るのは「常にオン」のときだけ**です。書き出した
   ファイルは別の人が開くものなので、既定では入れません(URL は残っているので、
   後から取り出せます)。
⚠ 図(mermaid)は手元で描いているので、外へは何も出ません。

#### Office 表示

Word / Excel / PowerPoint の添付を、**別の窓で開いて読める**ようにします(→ §7-3)。
そのために、**約 77MB のひとそろい**をこの端末に入れます。
一度入れれば、次からは**この端末の中から**起動します(毎回ダウンロードしません)。

| 押すもの | どうなるか |
|---|---|
| **取得して入れる** | 配布元(PKC3 と同じ場所)から取って入れます |
| **ファイルから入れる** | 手元の `lo-wasm-qt6.zip` を選んで入れます |
| **削除** | この端末から消します(ノートや添付は消えません) |

⚠ **勝手に取りに行きません。** 押した人にだけ入ります。
⚠ 入れている間は、進み具合が 1 行で出ます。終わるまで**入れる導線は押せません**。
⚠ **ファイルから入れる**は保険ではありません ── 配布元に届かない場所で PKC3 を
   開いているときは、これが唯一の道です。
⚠ 入っていても、**この環境で動くか**は別です。設定の 2 行目に
   「この環境では動きます / 動きません」と出ます。動かない場合は
   足りないもの(**JSPI** など)を名指しします。いまのところ Chrome / Edge など
   Chromium 系でだけ動きます(→ §7-3)。

#### 処理(ワーカー)── 開発者向け

重い処理(markdown の描画・添付の展開とハッシュ)は**別スレッド**で動きます。しばらく使われないと
自動で終了し、次に必要になったら作り直します。この画面で、いま動いているか・
待っている件数・1 件あたりの時間・直近のログが見られます。
⚠ ここに**変えられるものはありません**(読むだけです)。
⚠ ログに本文の中身は出しません(**文字数だけ**)。

### 4-3. フラグ

左の列のいちばん下の **フラグ** から開きます。ここは **開発中の切替**で、
設定とは分けてあります。

| | 設定 | フラグ |
|---|---|---|
| 誰のもの | あなた | 開発者・詳しい方 |
| 約束 | 正式な機能。消えません | **いつか畳まれます**(条件を各行に書いています) |

畳まれるとき、その切替は消えて、**中身は正式な機能か既定の挙動のどちらか**になります。
いま何も並んでいなければ、切り替えられるものがまだ無いということです。

うまく動かなくなったら **すべて既定へ戻す** を押してください。
一部の切替は**起動のときに決まる**ため、押すと**読み込み直します**
(そう書いてある行がそれです)。

`?pkc-flag=名前` を URL に付けると、**保存せずに**その場だけ試せます
(URL を外せば元に戻ります)。その間もその行は**押せます** ── 押すと保存して
読み込み直し、URL の指定は落ちます。

### 4-4. ヘルプ

左の列のいちばん下の **ヘルプ** から開きます。3 つが並びます。

| | 中身 |
|---|---|
| **この版** | いま動いている PKC3 の版(不具合の報告に添えてください) |
| **これまでのお知らせ** | 過去のお知らせを新しい順に、最大 10 件 |
| **マニュアル** | このマニュアルの全文 |

⚠ マニュアルは**アプリの中に入っています** ── オフラインでも読めますし、
**いま動いている版のマニュアル**が必ず出ます(外のページを見に行きません)。
⚠ **編集中でも開けます**。戻れば打ちかけはそのままです。

### 4-5. 集計(項目ごとに束ねて数える)

左の列の **集計** から開きます。**本文の先頭に書いた項目**でノートを束ね、
値ごとに何件あるかを出す面です。

書き方は、本文のいちばん上を `---` で囲むだけです。

```
---
author: 佐藤
status: 未着手
tags: [設計, 実装]
---

ここから本文
```

こう書いたノートが何件かあると、**束ね方**に `author` / `status` / `tags` が
出てきます。選ぶと、その項目の値ごとにノートが束ねられます。

| | 何が起きるか |
|---|---|
| **束ね方** | 何で束ねるかを選びます。⚠ 一覧に出るのは**実際に書かれている項目**だけです |
| **数え直す** | 書き換えたあとの中身で数え直します(自動では数え直しません) |
| 組の見出し | 値と件数。押すと畳めます |
| 組の中の行 | ノートです。押すと**選ばれます**(面はここに留まります ── 本文は右の列と、面の切替 1 回で見られます) |

⚠ `tags: [設計, 実装]` のように**並べて書いた値**は、**どちらの組にも入ります**
(1 件のノートが 2 つの組に数えられます)。
⚠ その項目を書いていないノートは **(未設定)** の組にまとまり、**いちばん下**に出ます。
⚠ 数がとても多いときは上から順に切ります。切ったときは
「あと N 組」のように**画面に出します**(黙って減らしません)。
⚠ **編集中は開けません**(保存するか取り消してから開いてください)。

### 探し方を変える(左の列の上のタブ)

| タブ | 何が並ぶか |
|---|---|
| **一覧** | 全部のノートを並べます(絞り込みが効きます) |
| **フォルダ** | フォルダの階層をたどります(ゴミ箱もここ) |
| **アプリ** | 「アプリとして登録」した添付を並べます(→ §7-2) |

⚠ どのタブでも**行の作りは同じ**です ── 行の頭に**種類の図案**、右端に**更新日**。
探し方が変わっても、行の読み方を覚え直さなくていいようにしています。

### フォルダに入れる・出す・並べ替える(**フォルダ**タブ)

パンくず(いま何処に居るか)のすぐ下に、**選んでいるものの居場所**の帯が出ます。

| 操作 | やり方 |
|---|---|
| フォルダに入れる | 行を選び、帯の**選ぶ欄**で入れ先のフォルダを選ぶ(選んだ瞬間に動きます) |
| フォルダから出す | 同じ欄で **ルート(いちばん上)** を選ぶ |
| 並べ替える | 帯の **上へ** / **下へ** を押す(**同じフォルダの中**で隣と入れ替わります) |
| フォルダの中に作る | そのフォルダを選んでから **+ ノート**(帯の下に「どこに入るか」が出ます) |

⚠ 行ごとにボタンは付けません ── **いつも同じ場所**(帯)に出します。フォルダ自身も
選べば動かせます(行に付けると、フォルダは選んだ瞬間に一覧から消えるので動かせません)。
⚠ 先頭・末尾では **上へ / 下へ が押せなくなります**(押せるのに何も起きない、を作りません)。
⚠ 並べ替えは**同じフォルダの中だけ**です。別のフォルダへ動かすのは「居場所」の欄です
(1 つの操作に 2 つの意味を持たせないため)。

⚠ 探し方を変えても**中央はそのまま**です ── 中央は常に「いま開いているノート」を
出します(場所を覚え直さなくていいように)。
⚠ **かんばん**と**カレンダー**は今はお休み中です(Todo と一緒に畳んでいます)。

### 右の列(情報)

選んでいるものの**題名・種類・居場所・作成日・更新日**と、それに対する操作
(**書き出す** / **履歴** / **削除**)が出ます。⚠ 画面が狭いときは**本文の下へ回ります**
(隠れません)。⚠ 編集中は押せません(確定するか取り消してください)。

⚠ **居場所**は入っているフォルダです(入れ子なら `親 / 子` の順)。どのタブから
選んでも出るので、**一覧タブのままでも所属フォルダが分かります**。どこにも入って
いなければ **ルート** と出ます。フォルダを移すとその場で変わります。

## 5. 書き出す・取り込む

### 書き出す(左の列のいちばん下)

| ボタン | ファイル | 可逆? | 用途 |
|---|---|---|---|
| **バックアップ** | `<題名>-<日付>.pkc3.zip` | ✅ **可逆** | これさえあれば全部戻る。**定期的にこれを取る** |
| **閲覧用 HTML** | `<題名>-<日付>.html` | ❌ 片道 | 1 ファイルで渡す・見せる。単体で開いて読める |
| **Markdown** | `<題名>-<日付>.md.zip` | ❌ 片道 | PKC3 を捨てても読める形。1 ノート = 1 `.md`、添付は `assets/` |
| **書き出す**(右の情報ペイン) | `<ノート名>-<日付>.pkc3.zip` | ✅ 可逆 | 1 件だけ。消す前の退避に |

⚠ いまはファイルの**ドラッグ&ドロップは受けません**(取込・添付ともボタンから選びます)。

🔴 **バックアップだけが可逆**です。「閲覧用 HTML」と「Markdown」は
frontmatter に居場所の無いもの(relations / 履歴)が落ちます。
「Markdown」は**落ちたものを書出し後に件数つきで画面に出します**。
「閲覧用 HTML」は件数を出さず、「取り込み直せません」とだけ言います。

#### 閲覧用 HTML の見え方

本文は**書いたとおりの形**(見出し・箇条書き・表・コード・リンク・添付)で出ます。
書き出すときに PKC3 の中で描いて焼き込むので、開く側には何も要りません。

**本文の幅もアプリの画面と同じ**です。散文(段落・見出し・箇条書き)には読みやすい幅の
上限が掛かり、**表・図・コードは横幅いっぱい**を使います(横に広いほど読めるため)。
紙に印刷したときも同じ組み方です。

- **図(mermaid)とグラフ(chart)は原文のまま**出ます(絵にはなりません)。絵で渡したいときは、
  図の右上の **図を保存** で SVG を出してください
- **履歴・relations・アプリの登録**は入りません(→ 上の表)

#### 目次と印刷

左の列は 2 つの**折りたたみ**に分かれています。見出し(▸)を押すと畳めます。

| 器 | 中身 |
|---|---|
| **ノート** | 入っているノートの一覧 |
| **この文書の目次** | 開いているノートの見出し(`#`〜`###`)。行を押すとその場所へ移ります |

見出しが 1 つも無いノートでは「**見出しがありません**」と出ます(空の器は残しません)。

印刷は 2 通りです。

| ボタン | 出るもの |
|---|---|
| **この文書を印刷** | 開いているノート 1 件。先頭にそのノートの目次が付きます |
| **全体を印刷(N 件)** | 全体の目次 → ノート 1 件ずつ(ノートごとにページが変わります) |

ブラウザの印刷から **PDF に保存**を選べば PDF になります。紙・PDF では:

- 左の列は出ません(**目次は本文の先頭に付きます**)
- 折りたたんでいた器は**開いた状態で**出ます。印刷が終わると畳んだ状態に戻ります
- 見出しがページの最後で独りにならないようにし、コード・表・引用・画像は途中で切りません

⚠ **全体を印刷**は全件をいったん組み立てます。印刷が終わる(またはノートを選び直す)
と組み立てたものは捨てます ── ノートが数千件あると、組み立ての間だけ重くなります。

### 取り込む

左の列のいちばん下の **取り込む** から選びます。

- **PKC2 の書出し全 9 形式**(単一 HTML + ZIP 8 種)→ §移行ガイド
- **素の `.md` / `.markdown`** ── 複数選択できます(1 件ずつノートになります)
- **PKC3 のバックアップ**(`.pkc3.zip`)

判別は**拡張子ではなく中身**(先頭バイトと manifest)で行います。
判別できないものは**推測せずに断ります**。

⚠ 取込で落ちたもの・書き換えたものは、**画面に全件出ます**(1 行の status に
埋もれません)。閉じるまで残ります。

### 添付の画像を別の窓で見る

添付が画像のとき、詳細に **別の窓で見る** が出ます。押すと画像だけの小さな窓が開くので、
**本文を書きながら見られます**。

⚠ 対応しているブラウザでは、常に手前に留まる小窓(ピクチャーインピクチャー)で開きます。
⚠ 窓を閉じると、その画像のために使っていたメモリはすぐに返します。
⚠ ポップアップを止めている設定だと開けません(そのときは画面に理由が出ます)。

### ノート同士をつなぐ(関係)

右の情報ペインの **関係** に、そのノートが持つつながりが出ます。

- 足すには、下の欄に**相手の題名**を打ち(候補が出ます)、種類を選んで **関係を足す**
- 種類は **関連 / 分類 / 時系列 / 出典** の 4 つです
- 相手の題名を押すと、そのノートへ移ります
- 消すには、その関係の **消す** を押します(⚠ ノート自体は消えません)

⚠ **居場所(フォルダの親子)はここでは作れません** ── あちらは **フォルダ** タブで
移動すると付きます。同じことを 2 通りで作れると、どちらが本当か分からなくなるためです。
⚠ 同じ題名のノートが複数あるときは、**どれか分からないので足せません**(題名を分けてください)。

## 6. 履歴とゴミ箱

- **履歴** … 右の情報ペインの **履歴** ボタン。過去の版に**復元**できます。
  ⚠ 戻す前の状態も履歴に積まれるので、**戻したことも取り消せます**
- 履歴は 1 ノートあたり**最新 100 件**まで保たれます
- **ゴミ箱** … 左の列の **フォルダ** タブの中。消したノートはここに入り、**戻せます**
- **ゴミ箱を空にする** … ⚠ **不可逆**。確認を出します

## 7. 添付

左の列の上にある **添付** からファイルを入れます(複数選択できます)。
実体は IndexedDB に入り、**1 ファイル = 1 ノート**(種別「添付」)になります。

添付の画面には、画面に出せるものはその場で出ます(画像・音声・動画・PDF・
文字のファイル)。**出せない種類**(zip など)は、そう書いてあります ──
「この種類は画面に出せません。上の**ダウンロード**で保存して開いてください」。
⚠ 何も出ないまま黙っていることはありません(中身が空なのか出せないのかが
分からない、という状態を作らないため)。

左の列のいちばん下の **使っていない添付を消す** で、**どのノートからも参照されていない**添付を消せます。
⚠ 自動では消しません(明示操作のみ)。⚠ 不可逆なので確認を出します。

⚠ 整理・取込・書出しの最中は、削除などの壊す操作は止まります
(走査中に消えると「書き出したつもりでファイルが 1 個も落ちていない」状態になるため)。

### 7-2. ランチャー

左の列の **アプリ** タブに、アプリとして登録した添付が並びます。

| タイル | 押すと |
|---|---|
| アプリ(HTML の添付) | **新しいタブ**で、隔離した器の中に開きます |
| URL(行き先のホスト名が右に付きます) | **新しいタブ**でそのサイトを開きます |

**アプリとして登録する** ── HTML のファイルを添付し、その添付の画面にある
**アプリとして登録** にチェックを入れます。チェックを入れると、同じ場所に
**グループ** と **目印** の欄が出ます。

- グループ名を付けると見出しでまとまります(**名前順**に並びます)。付けないものは先頭
- 目印は絵文字 1〜2 字。付けると行の左に出ます
- PKC2 から取り込んだ順番(`app_order`)はそのまま引き継ぎます
- サイドバーの **絞り込み** がここでも効きます

🔑 URL タイルを押しても、**相手のサイトにはあなたがどこから来たか伝わりません**
(リンク元も、開いた元のページへの参照も渡していません)。

🔒 **取り込んだ HTML は、あなたのノートに手が届きません**。アプリのタイルは
隔離した器(サンドボックス)の中で動くので、中の HTML から保存済みのノート・
添付・設定を読むことはできません。

**アプリは状態を保存できます**。器の中では、そのアプリ専用の保存領域が
`localStorage` として見えます ── 同じタイルを開き直すと続きから使えます。
⚠ 保存できるのは **1 アプリ 2MB** までです(超えるとアプリ側に
`QuotaExceededError` が返り、画面の下にも 1 行お知らせが出ます)。
⚠ この保存領域は**ノートの書き出しに含まれません**(バックアップから戻しても
アプリのデータは戻りません)。⚠ ノートを消すと、そのアプリのデータも消えます。
#### 素のまま起動する(PKC3 と同じ場所で動かす)

⚠ 囲いの中では **IndexedDB / cookie / Cache / Service Worker が使えません**。器の中は
「どこにも属さない場所」なので、これらは**触ることすら**できません。

これらに触ったアプリは、**画面の上に 1 行**出します ──
「このアプリは IndexedDB を使おうとしましたが、囲いの中では使えません」。
⚠ 触っても**そこで止まりません**(2026-08-06 に直しました)── 「無い」ものとして
見えるので、代わりの保存(囲いの中の 2MB)へ切り替えられるアプリはそのまま動きます。
それでも動かないアプリは、**画面の下に 1 行**理由が出ます。

そういうアプリは、その添付の画面の **素のまま起動** で開きます ── PKC3 と**同じ場所**で
動くので、上のものが全部使えます。⚠ そのかわり **そのアプリは PKC3 の保存内容
(ノート・添付・設定)にも手が届きます**。押すと 1 度だけ確認が出ます
(このタブを閉じるまでは聞きません。次に開いたときはまた聞きます)。
⚠ 許可は**保存しません** ── 素のままのアプリは保存領域に手が届くので、
保存した許可はそのアプリ自身が書き換えられてしまうからです。
⚠ 保存先も変わります ── 囲いの中で貯めた内容は、素のままでは**見えません**。

⚠ HTML の添付は、**その添付の画面から** **起動** / **素のまま起動** で開けます ──
「アプリとして登録」しなくても開けます(登録はランチャーに並べるための設定です)。

⚠ アプリのタイルを開いたタブは、**PKC3 の画面を閉じると一緒に使えなくなります**
(中身は PKC3 が渡しているためです)。

⚠ ランチャーに出るのは **HTML の添付** と **URL タイル**、それに下の
**Office のタイル**だけです(PDF や画像は一覧から開いてください)。

**Office のひとそろい(→ §4-2)を入れてある端末**では、ランチャーの先頭に
**Office** のタイルが並びます。押すと Office の窓(スタート画面)が開き、
新しい文書・表計算・プレゼンテーションを作れます。ノートの添付ではないので、
一覧には出ません。入れていない端末にはタイル自体が出ません。

### 7-3. Office の添付を読む(Word / Excel / PowerPoint)

`.docx` / `.xlsx` / `.pptx`(および古い `.doc` / `.xls` / `.ppt`、`.odt` などの
OpenDocument)を添付すると、その添付の画面に **Office で開く** が出ます。
押すと**別の窓**が開いて、そこに文書が組み上がります。

🔑 **別の窓なので、PKC3 の編集を続けたまま資料を読めます。**
⚠ 窓は **1 つだけ**です。開いている状態でもう一度押すと、その窓に表示し直します。
⚠ 窓を閉じると、使っていたメモリはまるごと返ります。

**縦書き・禁則・ルビ・圏点**を含む日本語の組版がそのまま出ます(日本語フォントを
同梱しています)。

#### 使うには、先に「ひとそろい」を入れます

初めは **設定 → Office 表示** から入れてください(約 77MB / → §4-2)。
入れる前の添付の画面には、ボタンではなく理由が出ます ──
「Office 表示にはひとそろい(約 77MB)が要ります。まだ入っていません。」

⚠ **押しても何も起きないボタンは出しません。** 開けないときは必ず理由が出ます。

#### 動くブラウザ

いまのところ **Chromium 系(Chrome / Edge など)** でだけ動きます。
Firefox / Safari では「この環境では動きません」と、足りないもの
(**JSPI** ── WebAssembly の Promise 統合)を名指しで出します。
⚠ Office 以外の機能は、どのブラウザでもこれまでどおり使えます。

#### ひとそろいの版

設定の **Office 表示** に、いま入っている版が出ます。
**配布元に別の版があるとき**は、そこに 1 行増え、起動したときにも 1 度お知らせします ──
**「取得して入れる」から入れ直せます**。

⚠ **勝手に取りに行くことはありません。** 起動時に読むのは版の目録(数百バイト)だけで、
77MB のひとそろいは**あなたが押したときだけ**取りに行きます。
⚠ 「新しい / 古い」ではなく「**別の版**」と出ます ── 版に前後の順序が無いためです
(手元のほうが新しいこともあります)。

#### 窓が固まったとき

Office の中身が固まると、**その窓のタブは何も受け付けなくなります**
(クリックもキーも通らず、窓の中には何も出せません)。

🔑 PKC3 の画面に戻ってくると、**下の行に「Office の窓が応答していません」**と
出ます。窓のタブを閉じて、もう一度 **Office で開く** を押してください。

⚠ 出るのは**戻ってきたとき**です ── 固まっている間はその窓を見ているので、
PKC3 側に出しても目に入らないためです。

---

⚠ **いま入っているのがどのビルドか**は、設定の Office の欄に出ます(版の文字列の下に、
LibreOffice の識別子の先頭・焼いた日時・ビルド番号)。不具合を報告するときは、この行を
そのまま添えてください ── **版の名前だけでは中身を見分けられないことがあります**。
前に入れた一式は素性を持っていないので「不明」と出ます(入れ直すと出ます)。

## 8. お知らせと更新

### お知らせ

新しいお知らせがあると、起動したときに**本文の下の帯**に出ます。

- **閉じる** … 読んだことにします(同じお知らせは次から出ません)。**見出しの右端**にあります
- **今後は出さない** … 以後は出しません。⚠ **設定の「表示」から戻せます**(→ §4-2)

⚠ お知らせが多いときは、帯の**中だけ**が送れます。**閉じる**は見出しに在るので、
どれだけ送っても画面から出ません。

⚠ かぶせる窓では**ありません** ── 帯が出るだけで、そのまま作業を続けられます。
⚠ 閉じても消えません。**過去のお知らせはヘルプから読めます**(→ §4-4)。

### 更新

新しい版が配られると、画面に **「新しい版があります(再読込 / あとで)」** が出ます。

- **再読込** … その場で新しい版に入れ替わります
- **あとで** … 案内だけ消えます。**次に開いたときにまた出ます**

🔴 **勝手には入れ替わりません。** 押したときだけ、**押したタブだけ**が再読込します
── 別のタブで編集中の下書きを巻き込まないためです。

## 9. 困ったとき

| 症状 | 見るところ |
|---|---|
| 「別のタブで開いています」から進まない | 相手のタブが古い版のままの可能性。**そのタブを一度読み直す**と、以後は 2 枚同時に使えます(§1「複数タブで開ける」) |
| 「このノートは別のタブで編集中です」と出る | 他のタブで同じノートの編集を開いたままです。そちらで保存(または取消)してください |
| status に `⚠` だけの警告(「エラー:」が付かないもの)が出る | 保存先を確保できていない(= **再読込で消える**)。他タブを閉じて開き直す |
| status に `⚠ エラー: …` が出る | **操作が断られただけ**です(保存先とは無関係)。書いてある理由に従ってください。⚠ **開き直さないで** ── 編集中の下書きが消えます |
| オフラインで白紙 | その版をまだ保存していません。一度オンラインで開き直してください |
| 取り込めない | 判別できない形式です。PKC2 の書出し / PKC3 のバックアップ(`.pkc3.zip`)/ 素の `.md` かを確認してください |

画面下の status は、**知らせることがあるときだけ**出ます(何も無いときは
高さ 0 で、地の文を占めません)。

**バージョン**は **ヘルプ**(左の列のいちばん下)のいちばん上に出ています。
不具合を報告するときは、その行の内容を添えてください。
