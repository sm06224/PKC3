対象: $ARGUMENTS(未指定なら「このセッションで得た教訓すべて」)

> 🔑 **キーワード「`.claude更新`」**(user 指示 2026-07-26)。
> 「**この活動自体も教訓コマンドとして残してください**」(user 指示 2026-08-07)── 本コマンドがそれ。

手順は `.claude/skills/knowledge-reflection/SKILL.md` に従ってください。
以下はその上に置くガードレールです。

- **拾うのは 4 種類だけ** ── 踏んだ罠 / 覆った前提 / user 裁定 / 実態との乖離。
  「うまくいったこと」は拾わない
- 🔴 **分ける基準を守る**:原則と user 由来の指示は `CLAUDE.md`、手順はスキル、
  観点はエージェント、呼ぶ瞬間の注意はコマンド、file 固有の罠はコード。
  **user 由来の金言的プロンプトを `.claude/` へ移さない**
- 🔴 **裁定は Issue にも起票する** ── 会話に流すと消える。2026-08-07 に GO 済みの件を
  起票せず、**user に聞き直す事故**になった(#91)
- **足すだけでなく削る** ── 実態と食い違う記述は、在ることが害
- **実体と導線を同じ commit に入れる**(導線だけ先に入れると壊れたポインタが残る)
- 最後に導線を検算する:
  ```bash
   # ⚠ `PKC2:.claude/…` は PKC2 側(read-only 参照)を指す規約なので除く ──
   #    除かないと検算が偽陽性を出し、次から無視される
   grep -rhoE '(PKC2:)?\.claude/[A-Za-z0-9./_-]*' CLAUDE.md .claude docs \
     | grep -v '^PKC2:' | sed 's/[.,)。]*$//' | sort -u \
     | while read p; do [ -e "$p" ] || echo "無い $p"; done
   ```
