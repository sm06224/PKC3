割る対象: $ARGUMENTS(未指定なら「いまの主題」を 1 文で定義してから始める)

手順は `.claude/skills/subagent-scale/SKILL.md` に従ってください。
以下はその上に置くガードレールです。

- 🔴 **割り方を先に決める** ── 観点で割る / 面で割る / 案で割る / 敵対で割る。
  「調べて」を N 本投げるのは物量ではなく**同じ見落としを N 回すること**
- 🔴 **書くエージェントは `isolation: "worktree"`**。read-only なら同居してよい
- **プロンプトに 5 つ入れる**:範囲(base の sha)/ 済んでいること / read-only の明示 /
  CONFIRMED と未検証の区別 / 「無ければ無いと言え」
- 🔴 **返ってきたものを 1 件ずつ自分で再現する。** これが「思考」の側である ──
  2026-08-07 の実測で、指摘 15 件のうち **2 件は前提か結論がずれていた**。
  鵜呑みにしていたら正しい実装を壊していた
- **直したら 2 巡目を投げる** ── 修正コード自体はまだ誰も読んでいない。
  🔑 とくに「**片側を直したら対称の反対側**」を見させる(PKC3 で最頻の型)
- 🚫 検算していない主張を PR 本文へ貼らない / 儀式的な定期実行にしない /
  PR gate へ足さない
