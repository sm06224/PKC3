description: 主張を数字で示す(対照群 → 被覆と感度 → 測定 → 主張してよい範囲)
---

対象: $ARGUMENTS(未指定なら「この PR が数字で主張していること」を列挙してから始める)

手順は `.claude/skills/perf-measurement/SKILL.md` に従ってください。
以下はその上に置くガードレールです。

- **測る前に主張を 1 行で書く。** 書けないなら、その測定は読めない
- 🔴 **対照群は「効かないはずの条件」で組む。** 「効きが薄いはずの条件」では足りない ──
  2026-08-07 に実際に間違え、対照群でも最適化が効いていて**効果を過大に見積もる**
  ところだった
- 🔴 **差分ハーネスで「相違 0」を出す前に、被覆と感度を確かめる**
  - **被覆**: 当たり先が 0 件の次元は「測っていない次元」(1 巡目は 10 次元が空だった)
  - **感度**: **生きていると分かっている値**を変えて差分が出ることを見る。
    死んでいる規則で試すと 0 点が返り、鈍いのか死んでいるのか区別できない
- **面を変えて測る** ── 画面 light / 画面 dark / **紙**(`@media print`)。
  紙を落とすと `@media print` の退行を丸ごと見逃す
- 🔴 **倍率を書かない**(向きだけ)。**百分率は分母を書く**。**測った場所を書く**
  ── node の測定は実機の体感ではない
- ⚠ **一時ハーネスは測り終えたら消す**(`git status` で確かめる)。
  `@playwright/test` を使うなら **repo 直下**に置く(`/tmp` からは解決できない)
