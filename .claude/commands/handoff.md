description: セッション引き継ぎ用の PR を作る(引き継ぎ事項 + 最初の仕事の有無)
---

引き継ぎの主題: $ARGUMENTS(未指定なら「このセッション全体」)

手順は `.claude/skills/session-handoff/SKILL.md` に従ってください。
以下はその上に置くガードレールです。

- 🔴 **先に `/claude-update` を回す** ── 罠を引き継ぎ doc に書き溜めるのではなく、
  **資産へ入れてからポインタを書く**。doc は要約とポインタだけ持つ
- 🔴 **最初の仕事の有無を PR 本文の冒頭に書く**(あり / なし・指示待ち / なし・裁定待ち)。
  曖昧にすると次のセッションが**勝手に仕事を作る**
- **状態は実測してから書く** ── `git log --oneline -5` / open PR / CI の結論 / 未 push。
  2026-08-04 の doc は「open PR 無し」と書きながら当の PR が実在した
- **裁定待ちは Issue に起票してから** PR で参照する(会話に流すと消える)
- **導線を検算する**(指すパスが実在するか)
- 完成は「**PR の URL を user に渡した時点**」。doc を書いただけ・会話に要約を
  書いただけでは完成していない
- 最後に作業ツリーが clean であることを確かめる ── **コンテナは揮発する**
