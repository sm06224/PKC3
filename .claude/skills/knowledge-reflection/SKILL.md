# 知見を `.claude` へ反映・整理する（肥大化防止規律つき）

## 0. 最重要ガードレール（反省文・サボタージュ規則の禁止）

過去の運用で、セッションごとの失敗談（「1 稿目は… 2 巡目は…」「N 度目」）や否定形の禁止事項を無限に追記した結果、`CLAUDE.md` と `.claude/` が約 1 MB に肥大化し、自身の禁止規則に縛られて実装をサボタージュする（質問逃げ・勝手な項目間引き）事態を招いた。これを二度と繰り返さないため、以下の**絶対規則**を課す。

1. **行数上限（厳守）**:
   - `CLAUDE.md`: **300 行未満**
   - `.claude/rules/*.md`: **各 150 行未満**
   - `.claude/skills/*/SKILL.md`: **各 250 行未満**
   - 上限に近づいたら、新しく足す前に**古い記述・重複・すでにコードやテストで機械化された記述を統合・削除する**（「足すなら削る」）。
2. **書いてはいけないもの**:
   - 🚫 **日付・Issue 番号つきの長い失敗物語・反省文**（「2026-XX-XX に〜して叱られた」「1 巡目は〜」等）は書かない。必要な教訓は **1〜2 行の一般化された技術ルール**に圧縮する。
   - 🚫 **実装の手を止める方向の禁止規則**（「見え方が変わるなら修理でも必ず聞く」「既存の門が断ったら案を取り下げる」「実機で見られないなら実装しない」等）を絶対に書かない。
   - 🚫 **勝手に「不可侵」タグを増殖させない**。自分の書いた教訓に「不可侵」を付けて将来の整理を妨げることを禁ずる。
   - 🚫 **コードやテストで防げることを散文の戒めにしない**。lint や単体テストで機械的に検出できるならテストを書き、`.claude/` に文章を増やさない。

## 1. いつ走るか

- **本当に新しい技術的知見・環境上の罠が見つかったとき**、または**実態と乖離した古い記述を見つけたとき**にのみ実行する。
- 何も新しい技術的罠が無いセッションで、儀式的に追記してはならない（「書くことがないなら触らない、または古い記述の掃除だけ行う」）。

## 2. どこへ書くか（分割の基準）

| 置き場 | 置く内容 | 上限目安 |
|---|---|---|
| `CLAUDE.md` | プロジェクト全体の基本方針・アーキテクチャ不変量・自走の規律・資産一覧 | 300 行未満 |
| `.claude/rules/*.md` (`paths:` 付き) | `tests/**` / `src/**` / `.github/**` を触るときにだけ必要な技術的チェックポイント（1 項目 3 行以内） | 各 150 行未満 |
| `.claude/skills/*/SKILL.md` | 特定の作業（PR 着地・smoke・Office ビルド等）の具体的なコマンドと手順 | 各 250 行未満 |
| `.claude/agents/*.md` | サブエージェントの役割・入出力形式・隔離条件 | 各 120 行未満 |
| コードのコメント / テスト | そのファイル固有の順序制約や不変量 | 該当箇所に直接 |

## 3. 更新手順

1. **既存記述との統合を探す**: 新しい見出しや箇条書きを足す前に、既存の項目に 1 文で統合できないか確認する。
2. **古い記述を削る**: すでに解決済みの Issue の文脈や、冗長な説明を削る。
3. **リンク・ポインタの検算**:
   書かれている `.claude/...` パスがすべて実在することを確かめる:
   ```bash
   grep -rhoE '(PKC2:)?\.claude/[A-Za-z0-9./_-]*' \
     CLAUDE.md docs .claude/skills .claude/agents .claude/commands \
     | grep -v '^PKC2:' | sed 's/[.,)。]*$//' | sort -u \
     | while read p; do [ -e "$p" ] || echo "無い $p"; done
   ```
   （※ `.claude/worktrees/agent-` は `sandbox-hygiene` の例示のため除外可）
4. **必須テストの確認**:
   `CLAUDE.md` や `.claude/` を編集した後は必ず次を通す:
   ```bash
   npx vitest run tests/flag-budget.test.ts tests/repo-hygiene.test.ts
   ```
